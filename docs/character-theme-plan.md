# 캐릭터 테마 작업안 — P12

2026-10-04 사용자 요청. 오늘·시간표·내 보석에 색 변경만 하는 기존 테마보다 확실히 다른 캐릭터 테마를 추가한다.

## 두 방향

- **시나모롤 구름:** 하늘색·흰색·구름, 가로로 긴 귀·파란 눈·작은 입. 사용자가 독자 캐릭터 시안보다 원래 캐릭터와 최대한 가까운 디자인을 요청했다.
- **쿠로미 별:** 연보라 배경과 검정 후드·분홍 장식·별. 같은 요청에 따라 캐릭터의 얼굴과 실루엣을 유지한다.

캐릭터는 제목을 가리지 않는 인사 그림, 보석 카드, 빈 화면, 목표 달성 칭찬에 배치한다.
시간표의 과목 의미 색과 아이콘은 유지하고 배경·프레임·장식으로 테마 분위기를 구분한다.

## 작업

- P12.1: 두 캐릭터 그림과 배경·장식·팔레트 시안 및 번들 자산.
- P12.2: 테마 레지스트리·선택 미리보기·오늘·시간표·내 보석 적용과 선택 저장.
- P12.3: 두 테마의 가독성·대비·터치 영역·큰 글씨·세로/가로·빈 화면·재시작 선택 유지 확인.

2026-10-04 P12 개발 착수. Claude는 보석 기능을 동시 개발하며 Codex는 테마 계층만 변경한다. 커밋·푸시는 사용자 후속 지시로 보류한다.

## 번들 캐릭터 자산

- `assets/characters/cinnamon-cloud.png`: 투명 PNG, 하늘색 보석을 든 시나모롤과 구름.
- `assets/characters/kuromi-star.png`: 투명 PNG, 보라색 보석을 든 쿠로미와 별.
- built-in image_gen 사용. 첫 독자 캐릭터 시안은 사용자가 외형 차이를 지적해 폐기했고, 앱에는 위 최종 두 자산만 사용한다.
- 최종 프롬프트 방향: 원래 캐릭터의 얼굴·실루엣을 유지하는 평면 2D 파스텔 스티커, 투명 배경, 전체 귀와 몸이 보이는 전신, 작은 보석, 글씨·로고 없음. 시나모롤은 파란 눈과 가로 귀, 쿠로미는 검정 후드와 분홍 해골 장식으로 구분한다.
- 구름 테마 팔레트: 배경 `#F0F9FF`, 주요색 `#075985`, 본문 `#172554`, 장식 `#BAE6FD`.
- 별 테마 팔레트: 배경 `#F8F3FF`, 주요색 `#6B21A8`, 본문 `#2E1065`, 장식 `#DDD0F4`.
- 두 화면 시안: `docs/character-theme-preview.html`. 캐릭터·배경·카드·보석 컬렉션 배치를 함께 보여 준다.
- 사용자 후속 요청으로 별 하나/두 개 기호를 폐기하고 `gem-small.png`(파란 다이아몬드), `gem-large.png`(금색 테두리의 넓은 보라 보석)를 사용한다. 메인 우측 장식은 보석을 든 캐릭터로 바꾼다.
- P12/P12.1의 최초 '독자 캐릭터' 설명은 사용자 후속 요청(원래 캐릭터와 최대한 비슷하게) 및 두 최종 시안 승인으로 대체된다. 추가 승인 gate는 없다.

## 구현 범위와 추가 사용자 요청

- 사용자 최종 요청으로 테마 레지스트리는 `cinnamon-cloud`, `kuromi-star` 두 개만 제공한다. 햇살·하늘 구름 테마는 제거하고 기존 저장값은 시나모롤로 전환해 저장한다. 과목 의미 색·아이콘은 보존한다. 선택은 기존 로컬 저장소를 사용한다.
- 오늘 카드와 시간표 제목의 캐릭터는 글자와 별도 영역에 배치한다. 가로 시간표에서는 기존처럼 제목을 숨겨 표 공간을 확보한다.
- 보석 컬렉션의 별 하나/두 개 표시는 실제 일반·큰 보석 PNG로 대체한다. 메인 우측은 테마 캐릭터 또는 기본 테마의 보석 그림으로 표시한다.
- 그림 변화 계산만 일반 보석 1점·큰 보석 5점으로 환산한다. 0점 빈손, 1~4점 첫 반짝임, 5~14점 반짝반짝, 15~29점 보석이 한가득, 30점 이상 눈부신 보석함. 고정된 최대 장식 개수로 렌더링한다.
- `cinnamon-empty.png`, `kuromi-empty.png`는 승인한 최종 캐릭터에서 손의 보석만 제거한 0점 자산이다. built-in image_gen 편집 사용.
- 그림 계산은 저장 수량·자동 지급·보석 권리·보상 목표·환산 로직을 변경하지 않는다. 이 부분은 동시 Claude 작업의 범위다.
- 오늘 제목과 작은 응원 문구는 로컬 날짜 기준 20개 쌍을 순환한다. 같은 날짜에는 재시작 후에도 같고, 자정·앱 복귀 시 기존 갱신 흐름으로 바뀐다. 칭찬·휴식·도움 요청·자기 속도 등 부담을 주지 않는 문장으로 구성한다.
- 하단 탭에는 아이콘과 글자, 현재 테마의 선택 배경을 함께 표시한다. 내 보석 아이콘은 일반 보석 PNG를 사용한다.
- Claude가 추가한 보석 받기 카드의 요청·자격 계산은 유지하며 진행 모양만 테마에 맞춘다. 사용자 최종 선택: 시나모롤은 하늘색 구름, 쿠로미는 귀여운 분홍 해골. 완료는 색 채움, 남은 칸은 옅은 색/윤곽이며 화면 읽기에는 숫자 진행값을 제공한다.

## 추가 완료 체크리스트와 검증 경계

P12.2는 다음 구현과 저장 동작을 확인하고, P12.3은 실제 화면 크기·글씨·빈 상태의 가독성을 확인한다.

- 선택지는 시나모롤·쿠로미 두 개이며 제거된 햇살/하늘 테마 저장값은 시나모롤로 이전한다.
- 두 캐릭터·팔레트·미리보기가 구분되고, 각각 선택 후 앱을 완전히 종료하고 다시 열어 선택을 유지한다.
- 컬렉션은 작은/큰 보석 PNG를 표시한다. 그림만 작은 보석 1·큰 보석 5점으로 계산하며 0 / 1~4 / 5~14 / 15~29 / 30 이상 다섯 단계로 바뀐다.
- 제목과 작은 응원 문구 모두 로컬 날짜에 따라 바뀌고 같은 날짜 재시작에는 유지된다.
- 하단 탭의 아이콘과 선택 표시, 구름/분홍 해골 진행 모양과 숫자 접근성 정보를 제공한다.
- 과목 의미 색과 보석 장부·자격·요청·보상 목표 기능을 보존한다.
- 세로·가로·글씨 배율 1.5, 보석 0개 및 일정 없는 상태에서 글자/체크/선택 영역을 가리지 않는다. 대비·영속 저장·날짜 경계·그림 단계 테스트와 전체 검사를 확인한다.

## Claude 동시 작업 인계 기록

사용자 최신 설명에 따라 보석 정책 기준은 `docs/backlog/P4.13.md`의 확정된 정책이며 아래 사항이 그 문서 이후 변경됐다. 향후 커밋 설명에서도 이 기준을 사용한다.

- 오늘 화면 수량 문구는 '작은 보석 · 큰 보석'이다.
- 목표 달성의 `markRewardAchieved`는 달성 상태만 기록하고 보석을 차감하지 않는다.
- 새 할 일은 생성한 날부터 완료·연속 판정에 반영한다. 과거 날짜 테스트용 할 일은 테스트에서 `created_at`을 앞당긴다.
- 장부 개수를 바꾸는 경로는 딸이 직접 입력하는 `gemCountRepository`뿐이다. 체크·자격·요청·지급·목표 달성은 자동 증감하지 않는다.
- 테마 그림의 큰 보석 5점 환산은 시각 표현이며 장부나 자격의 가치 계산을 바꾸지 않는다.
