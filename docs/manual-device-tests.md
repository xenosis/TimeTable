# 실기기 확인 안내

실제 앱 화면 확인은 사용자가 수행하거나, 사용자가 기기 조작을 맡긴 경우 Codex가 수행한다. 직접 관찰한 결과와 사용자가 알려 준 결과를 구분하고, 기기 모델·앱 버전·확인 범위를 백로그 근거에 기록한다. 동시 입력이 감지되면 터치를 멈춘다.

## P0.5 · P0.8 잠금 화면 알람

### 준비

- 새 Android 개발 빌드를 설치한 뒤 TimeTable 알림 권한을 허용한다.
- 관리자 PIN 뒤 `기타 → 기기 테스트 (알림·알람)`을 펼쳐 테스트 버튼에 접근한다. 일반 알림과 재부팅 테스트도 같은 경로에 있다.
- Android 설정의 `특별한 앱 액세스`에서 TimeTable의 `전체 화면 알림`과 `알람 및 리마인더`가 허용인지 확인한다.
- 전체 화면 알림이 꺼져 있으면 알람 예약 버튼은 비활성화되고 `전체 화면 알림 허용하기` 버튼만 사용할 수 있어야 한다.

### 확인

1. 위 기기 테스트 영역의 `15초 뒤 잠금 화면 알람`을 누른다. 예약 완료 문구가 보이는지 확인한다.
2. 5초 안에 전원 버튼으로 화면을 잠근다. 앱을 열어 두거나 잠금을 풀지 않는다.
3. 약 15초 뒤 TimeTable의 전용 알람 화면이 잠금 화면 위에 표시되는지 확인한다. 시간표·편집 화면이 보이면 실패다.
4. 반복음이 계속 나는지 확인한다.
5. `끄기`를 눌러 소리와 전용 화면이 함께 사라지고 잠금 화면으로 돌아가는지 확인한다. 상단 상태 표시줄의 TimeTable 진행 중 알림도 사라지는지 확인한다.
6. 실패하면 화면이 켜졌는지, 알림 배너만 보였는지, 소리만 났는지, 아무 반응이 없었는지를 함께 적는다.
7. **[폰 사용 중 알람]** 잠그지 않고 다른 화면(예: 홈 화면 앱 목록)을 보고 있는 상태에서 같은 방식으로 알람을 예약한다. 전용 알람 화면이 안 뜨더라도 반복음이 나는지, 화면 위 배너 알림에 `끄기` 버튼이 있는지, 그 버튼으로 소리가 완전히 멈추는지 확인한다.

### 보고 형식

`P0.5·P0.8 통과` 또는 `P0.5·P0.8 실패: [실제 결과]`로 알려 준다. 실패 때는 Android 버전과 전체 화면 알림·알람 권한 상태도 함께 적는다.

## P0.7 재부팅 뒤 일반 알림

### 예약 시각 전 복구

1. `3분 뒤 재부팅 복구 확인`을 누른다.
2. 1분 안에 기기를 다시 시작한다.
3. 부팅이 끝나면 한 번 잠금을 풀되 앱은 열지 않는다.
4. 처음 예약한 시각까지 기다린다.
5. 일반 TimeTable 알림이 정확히 한 번 도착하는지 확인한다. `재부팅 중 놓친 일반 알림이에요.`는 표시되면 안 된다.

### 재부팅 중 예약 시각 경과

1. `1분 뒤 알림 예약`을 누른 뒤, 20초 안에 기기를 다시 시작한다.
2. 부팅이 끝나면 앱을 열지 말고 1분 예약 시각 전후 30초를 기다린다.
3. 예약 시각 전에 부팅이 끝났으면 일반 알림이 한 번 도착하는지 확인한다.
4. 예약 시각이 재부팅 중 지났다면 알림 목록에 `재부팅 중 놓친 일반 알림이에요.`가 남는지 확인한다.
5. 같은 알림이 중복으로 오거나, 아무 알림도 없으면 실패다.

## P3.7 알림을 눌러 일정 열기

1. PIN 뒤의 시간표 편집에서 현재 시각보다 2~3분 뒤인 새 항목을 만든다. 직접 시간 입력 항목 하나와 교시를 고른 항목 하나를 만들고, 제목에 각각 `P3.7 직접`, `P3.7 교시`를 넣는다.
2. 일반 알림과 전용 알람을 각각 한 번씩 고른다.
3. 각 알림 유형을 앱을 보고 있는 상태, 홈 화면으로 보낸 상태, 최근 앱 목록에서 쓸어 종료한 상태에서 차례로 확인한다.
4. 알림이 오면 TimeTable 알림 항목을 누른다. 전용 알람은 `끄기` 대신 `일정 보기`를 눌러 알람을 끄면서 바로 이동하는지 확인한다.
5. 매번 `알림 일정` 화면에 해당 제목과 시간이 보이는지 확인한다. 교시 항목도 실제 교시 시간이 보여야 한다.
6. 테스트 항목 하나를 삭제한 뒤 이전 알림 항목을 누른다. `이 일정은 변경되었거나 삭제되었어요.`라고 안내되고 앱이 멈추지 않아야 한다.

## P4.4 아이 화면과 관리자 화면 분리

1. TimeTable을 처음 열었을 때 `오늘도 해보자!` 아래에 오늘 시간표, 오늘의 할 일, 보석판, 주간 시간표, 테마 선택만 보이는지 확인한다.
2. 첫 화면에서 `관리자 설정`을 누른다.
3. 관리자 화면에는 권한 안내와 PIN 입력이 보이고, PIN을 열기 전에는 편집 항목이 보이지 않는지 확인한다.
4. PIN을 열어 할 일이나 시간표를 바꾼 뒤 뒤로 가기 버튼으로 첫 화면에 돌아온다.
5. 바꾼 오늘 할 일·시간표가 첫 화면에 반영되는지 확인한다.

### 보고 형식

## P4.3 할 일 편집(PIN)

### 준비

- 첫 화면의 `관리자 설정`을 누르고 `편집 PIN`을 연다.
- PIN이 잠겨 있으면 5분이 지난 뒤 올바른 PIN으로 `편집 열기`를 누른다.
- 테스트에 쓰는 항목 이름에는 `P4.3`을 넣어 나중에 지울 수 있게 한다.

### 1. 반복 할 일 추가·수정·삭제

1. 관리자 `할 일` 영역에서 목록 위 `추가`를 누른 뒤 `할 일 이름`에 `P4.3 반복`을 입력한다.
2. 오늘 요일 하나를 고르고 `추가`를 누른다.
3. 아이 화면 `오늘` 탭의 `오늘의 할 일` 카드에 즉시 나타나는지 확인한다.
4. 편집 목록에서 `P4.3 반복`을 눌러 이름을 `P4.3 반복 수정`으로 바꾸고 `수정 저장`을 누른다.
5. 오늘 카드의 이름도 즉시 바뀌는지 확인한다.
6. 같은 항목을 다시 선택해 `삭제`를 누른다.
7. 오늘 카드와 편집 목록에서 사라지는지 확인한다.

반복 할 일은 추가한 날부터 적용된다. 그래서 새 반복 할 일을 만들더라도 이전 날짜의 완료·보석 기록은 바뀌지 않는다.

### 2. 특정 날짜 할 일 추가·수정·삭제

1. 관리자 `할 일` 영역의 목록 위 `추가`를 누른다.
2. `할 일 이름`에 `P4.3 날짜`를 입력한다.
3. `특정 날짜 고르기`를 눌러 달력에서 오늘 날짜를 선택하고 `추가`를 누른다.
4. 오늘 카드에 즉시 나타나는지 확인한다.
5. 편집 목록에서 항목을 선택해 이름을 `P4.3 날짜 수정`으로 바꾸고 `수정 저장`을 누른다.
6. 오늘 카드의 이름도 바뀌는지 확인한다.
7. 같은 항목을 `삭제`하고 오늘 카드와 편집 목록에서 사라지는지 확인한다.

### 3. PIN 차단과 백그라운드 잠금

1. PIN을 입력하지 않은 상태에서 `할 일 편집` 영역이 보이지 않는지 확인한다.
2. 틀린 PIN을 한 번 넣고 `편집 열기`를 누른다. `PIN이 맞지 않아요.`가 보이고 편집 영역이 열리지 않아야 한다.
3. 틀린 PIN을 다섯 번 연속 넣는다. `5분 동안 잠갔어요.`가 보이고 입력 및 편집 열기 버튼이 잠겨야 한다.
4. 5분이 지난 뒤 올바른 PIN을 입력한다. 다시 편집이 열려야 한다.
5. 잠금이 풀린 직후 틀린 PIN을 한 번 넣는다. 다시 즉시 잠기지 않고 `PIN이 맞지 않아요.`만 보여야 한다.
6. 편집을 연 채로 시간이 지나도(5분 자동 잠금은 v1.39.0에서 제거됨) 편집이 닫히지 않아야 한다. 대신 앱을 백그라운드(홈 화면)로 보냈다 돌아오면 편집이 닫히고 PIN 입력 화면으로 돌아가야 한다.

### 완료 이력 보존

한 번이라도 완료 표시된 할 일은 과거 완료·보상 기록을 보존하기 위해 수정과 삭제를 막는다. 새 일정이 필요하면 새 항목으로 만든다.

### 4. 완료 이력 보호

1. 오늘 요일의 새 반복 할 일을 `P4.3 완료 이력`으로 만든다.
2. 오늘의 할 일 카드에서 이 항목을 완료로 체크한 뒤 다시 체크를 풀어 미완료 상태로 만든다.
3. 관리자 할 일 영역에서 이 항목이 수정·삭제 가능한 일반 목록에 나타나지 않는지 확인한다.
4. 더보기: 오늘까지만 하고 그만두기를 펼치면 항목과 이력 보호 안내가 보이는지 확인한다.
5. 종료 검증용 항목에서 그만두기를 누르고 확인하면 오늘까지 유지되고 내일부터 제외되는지 확인한다. 이전 완료 이력은 남아야 한다.

### 보고 형식

각 단계가 끝나면 `P4.3 1 통과`부터 `P4.3 4 통과`처럼 알려 준다. 오류가 있으면 누른 버튼, 화면 문구, 실제 결과를 함께 적는다.

## P4.7 보석판 · P4.13 실물 보석 자격과 수동 장부

### 준비

- 오늘 반복 할 일을 두 개 이상 준비한다. 이미 완료 기록이 있는 항목은 수정할 수 없으므로, 테스트용 새 항목을 만든다.
- P4.6·P4.9의 주간·월간 자동 적립 정책은 폐기됐다. 최신 기준은 `docs/backlog/P4.13.md`의 확정된 정책이다. 할 일을 모두 끝낸 날이 5일 연속되면 실물 보석을 받을 자격이 생긴다. 할 일이 없는 날은 건너뛰며, 새 할 일은 생성일부터 계산한다.
- 장부 개수는 딸이 직접 입력한다. 완료 체크·자격 생성·요청·지급·목표 달성은 보석 개수를 자동으로 바꾸지 않는다. 검증 전 원래 작은/큰 보석 개수를 기록하고 수동 입력 검사 뒤 원래 값으로 돌린다.

### 1. 오늘 완료 기록과 화면 갱신

1. 오늘의 할 일을 하나만 체크한다. 진행률만 바뀌고 보석 수는 바뀌지 않아야 한다.
2. 남은 할 일을 모두 체크한다. 완료 축하와 연속 달성 표시가 갱신되고, 작은 보석·큰 보석 장부는 그대로여야 한다.
3. 마지막 체크를 다시 해제한다. 축하 문구가 사라지고 연속 달성도 다시 계산되어야 한다.
4. 앱을 나갔다가 다시 열어도 실제 체크 상태와 보석판이 같아야 한다.

### 2. 보상 목표

1. PIN으로 편집을 연다.
2. `보상 목표`에서 이름(예: `주말 영화`)과 필요한 보석 수를 넣고 `보상 목표 저장`을 누른다.
3. 보석판에 `주말 영화: 보석 N개 더 모으면 돼요.`처럼 남은 개수가 보이는지 확인한다.
4. PIN 뒤 보상 영역에서 목표 달성을 처리한다. 완료된 목표가 반영되고 작은 보석·큰 보석 장부가 차감되지 않는지 확인한다.

### 보고 형식

각 부분은 기기 모델·앱 버전·누른 버튼·실제 결과를 적는다. 5일 자격의 실제 기간을 확인하기 전에는 통과로 기록하지 않는다. 자격 생성 후 요청→관리자 보상 영역의 지급 처리까지 확인하며 각 단계에서도 장부가 그대로인지 확인한다. 체크 취소에 따른 자격 처리 기준은 확정된 정책을 따른다.

## P9.7 관리자 화면 회귀

1. 기기·앱 버전·폭을 기록한다. 360/393dp는 `wm density`(딸 폰 450dpi 기준 480=360dp, 440≈393dp)로 바꿔 세로로 보고, 끝나면 `wm density reset`으로 원복한다. 사용자 결정(2026-10-08): 관리자·편집 화면의 가로 확인과 확대 글자(1.3배 포함) 확인은 하지 않으며 폰 글자 배율은 바꾸지 않는다.
2. PIN 뒤 시간표·할 일·보상·기타 영역을 차례로 열고 기본 선택 버튼의 줄바꿈과 밀도를 확인한다.
3. 시간표 세트 목록 3행은 기본 글자에서 180dp 이내인지, 요일 7칸은 한 줄인지 확인한다. 교시와 요일 복사, 기타의 진단을 펼친 상태도 확인한다.
4. 별도 검증용 세트에 평일 하루 4개(총20개), 긴 제목·메모, 주말 일정을 준비해 요일 필터와 세트 분리를 확인하고 원래 세트로 복구한다.
5. 키보드가 열린 상태에서 요일·교시·색·아이콘을 한 번 누른 결과를 확인한다. 저장 버튼을 키보드 위로 스크롤해 저장하고, 입력 중 취소 및 영역 이동에서는 버림 확인을 확인한다.
6. 특정 날짜 달력에서 6주가 있는 달을 세로로 연다. 월 이동·닫기 버튼이 보이고 마지막 날을 선택할 수 있어야 한다(가로 확인은 사용자 결정으로 제외).
7. 입력·저장·취소, 반복 종료·완료 이력 보호, 앱 복귀 후 PIN 잠금, 아이 화면 갱신을 확인한다. 검증용 데이터만 정리한다.
8. 직접 관찰한 캡처·XML과 자동 검사 로그를 기록한다. 미검증 실기기·알림·위젯·날짜 경계는 통과로 적지 않는다.
