# TimeTable 실기기 수동 테스트

이 문서는 딸 폰에서 사용자가 직접 확인하는 절차다. 각 항목은 **한 번에 하나씩** 실행하고 결과를 알려 주면 된다. 실패하면 화면 상태와 실제 결과만 간단히 기록한다.

## 준비

1. `Device-arm64-v8a` APK를 설치하고 TimeTable을 연다.
2. 앱 상단의 `알림 준비`에서 알림, 정확한 알람, 전체 화면 알림을 허용한다.
3. 배터리 최적화 예외는 휴대폰 설정 화면이 열리는지만 먼저 확인한다.

## 1. 권한 안내와 재안내

1. 홈 화면에서 `관리자 설정`을 열지 않은 상태로 앱을 한 번 종료했다가 다시 연다. 네 권한이 모두 허용된 경우에는 아이 화면에 `알림 준비` 카드가 보이지 않아야 한다.
2. 아래 네 항목을 **한 번에 하나씩** 휴대폰 설정에서 끈다. 매번 앱을 홈 화면으로 돌아오게 한 뒤 다음 항목을 진행한다.
   - TimeTable의 `알림`
   - `알람 및 리마인더`의 정확한 알람
   - `특별한 앱 액세스`의 `전체 화면 알림`
   - 배터리 설정의 TimeTable `최적화 안 함` 예외
3. 매 항목마다 홈 화면 맨 위에 `알림 준비` 카드와 해당 항목의 `확인이 필요해요`, `허용하기`가 나타나는지 확인한다.
4. `허용하기`를 눌러 **해당 항목의** Android 설정 화면이 열리는지 확인한다. 다시 허용한 뒤 TimeTable로 돌아온다.
5. 카드의 해당 줄이 즉시 `허용됨`으로 바뀌는지 확인한다. 네 항목을 모두 복구하면 홈 화면의 `알림 준비` 카드는 사라져야 한다.
6. 네 항목이 모두 허용된 상태에서 관리자 설정을 열어, 권한 상태를 확인하는 카드가 계속 보이는지도 확인한다.

**통과:** 네 권한 각각에서 설정 이동과 앱 복귀 후 상태 갱신이 된다. 홈 화면에서는 하나라도 꺼지면 카드가 다시 나타나고, 모두 허용되면 숨겨진다.

## 2. 일반 시간표 알림

1. PIN 뒤의 시간표 편집에서 오늘 요일이 선택된 것을 확인하고, 현재 시각보다 2~3분 뒤인 항목을 만든다. 시간은 `0930`처럼 숫자 네 자리만 입력하면 `09:30`으로 바뀐다.
2. 알림 방식을 `화면 알림`으로 고르고 저장한다. 편집 카드에 `시간표 항목을 저장했고 알림 예약도 새로 만들었어요.`가 표시되는지 확인한다.
3. 화면을 끄고 예약 시각까지 기다린다.

**통과:** 해당 제목의 일반 알림이 한 번만 도착한다. 화면을 다시 켜거나 앱을 열어도 같은 알림이 추가로 나타나지 않는다.

## 3. 전용 알람

1. 오늘 요일이 선택된 상태에서 현재 시각보다 2~3분 뒤인 시간표 항목을 만들고 알림 방식을 `소리·화면 알람`으로 고른다.
2. 저장 뒤 편집 카드에 예약 성공 문구가 보이는지 확인하고 화면을 잠근다.
3. 예약 시각에 전용 알람 화면, 항목 제목, 반복음이 나타나는지 확인한다.
4. `끄기`를 누른다.

**통과:** 잠금이 유지된 상태로 전용 알람만 표시되고, `끄기` 뒤 반복음·전용 화면·상단의 TimeTable 진행 중 알림이 모두 사라진다.

**추가 확인(폰 사용 중):** 화면을 잠그지 않고 앱을 쓰고 있는 상태에서 같은 방식으로 알람을 예약한다. 전용 화면이 뜨지 않더라도 반복음이 나야 하며, 화면 위 배너 알림의 `끄기` 버튼으로 소리가 멈추는지 확인한다.

## 4. 같은 항목을 두 번 저장한 경우

1. 아직 오지 않은 알림 또는 알람 항목을 만든다.
2. 같은 내용을 수정 저장한다.
3. 다시 한 번 수정 저장한 뒤 예약 시각까지 기다린다.

**통과:** 일반 알림 또는 알람이 정확히 한 번만 발생한다.

## 5. 알림을 눌러 일정 열기

1. 현재 시각보다 2~3분 뒤인 시간표 항목을 만든다. 직접 시간으로 만든 항목과 교시를 고른 항목을 각각 준비하고, 제목에는 `P3.7`을 넣는다.
2. 일반 알림과 전용 알람을 각각 한 번씩 고른다.
3. 각 알림 유형을 아래 세 앱 상태에서 각각 예약한다: 앱을 보고 있는 상태, 홈 화면으로 보낸 상태, 최근 앱 목록에서 쓸어 종료한 상태.
4. 각 알림이 도착하면 알림 항목을 누른다. 전용 알람은 `끄기` 대신 `일정 보기`를 눌러 알람을 끄면서 바로 이동하는지 확인한다.
5. 항목 하나를 삭제한 뒤 이전 알림을 다시 누른다.

**통과:** 여섯 가지 조합(일반·전용 알림 × 실행 중·백그라운드·종료) 모두 앱이 `알림 일정` 화면을 열고, 직접 시간·교시 항목 각각의 제목과 시간을 보여 준다. 삭제된 항목의 예전 알림은 앱이 멈추지 않고 `이 일정은 변경되었거나 삭제되었어요.`를 보여 준다.

## 6. 할 일 알림과 재알림

1. 오늘 반복 할 일을 만들고 알림 방식을 `알림`, 시간을 현재 시각보다 2~3분 뒤로 저장한다.
2. 첫 알림을 확인하되 할 일을 완료하지 않고 30분을 기다린다.
3. 같은 제목의 재알림이 한 번 더 오는지 확인한다.
4. 새 할 일로 같은 과정을 반복하되, 첫 알림을 받은 뒤 오늘의 할 일 카드에서 완료를 누른다.
5. 30분 뒤 재알림이 오지 않는지 확인한다.

**통과:** 미완료 할 일은 첫 알림과 30분 뒤 재알림을 한 번씩 받는다. 첫 알림 뒤 완료한 할 일은 재알림을 받지 않는다.

## 7. 앱 복귀와 백그라운드 재예약

1. 이 문서 상단의 최신 `Device-arm64-v8a` APK를 설치하고 앱을 한 번 연다.
2. PIN 뒤에서 현재 시각보다 3분 뒤인 시간표 항목을 만들고 `알림`으로 저장한다.
3. 홈 화면으로 나간 뒤 10초 이상 기다렸다가 TimeTable로 돌아온다.
4. 같은 항목 제목을 바꿔 다시 저장하고, 처음 예약 시각까지 기다린다.
5. 홈 화면으로 나가되 최근 앱 목록에서 강제 종료하지 말고, Android가 백그라운드 작업을 실행할 수 있도록 20분 이상 둔다. Android가 절전 상태에 따라 더 늦게 실행할 수 있다.
6. 다시 앱을 열고 알림 시간을 아직 오지 않은 시각으로 바꿔 저장한다.

**통과:** 3~6단계 뒤에는 예전 제목이나 예전 시각의 중복 알림이 없고, 마지막으로 저장한 제목·시각의 알림만 한 번 도착한다. 앱 복귀나 백그라운드 대기 뒤에도 저장한 시간표가 사라지지 않아야 한다.

## 실패 기록

- 항목 종류: 권한 / 일반 알림 / 알람 / 중복 / 알림 탭 / 할 일 알림 / 백그라운드 재예약
- 예약 시각과 실제 발생 시각
- 화면이 잠겨 있었는지
- 실제 결과: 미발생 / 한 번 / 두 번 이상 / 소리만 / 알림만
- `끄기` 뒤 남아 있는 것: 소리 / 전용 화면 / 상단 알림
