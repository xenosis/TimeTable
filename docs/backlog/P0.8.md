## 목적

잠금 상태의 딸 폰에서 일반 앱 화면이나 일정 전체 내용을 노출하지 않고 전용 알람 화면만 보여 주는 네이티브 알람 경로를 검증한다. 화면은 잠금을 유지한 채 최소 알람 내용과 `끄기` 버튼을 제공해야 한다. `P0.5`의 notify-kit PoC를 대체하는 자체 Kotlin 경로를 확인한다.

## 쉬운 설명

알람 시간이 되면 폰 화면이 켜지고 알람 전용 화면이 나타난다. 아이가 잠금을 풀지 않아도 시간표나 관리자 화면은 보이지 않는다. `끄기`를 누르면 반복 소리와 알람 화면이 끝나고 잠금 화면으로 돌아간다.

## 필요한 입력

- 대상 실기기: `SM-A245N`, `Android 16`
- Android 네이티브 프로젝트 및 자체 Kotlin 알람 코드
- `AlarmManager` 예약 경로
- 전체 화면 알림 경로와 `CATEGORY_ALARM`
- 전체 화면 알림 특별 접근 허용 여부
- 일반 알림 권한과 전체 화면 알림 특별 접근 허용 여부
- 반복 알람음과 `끄기` 동작
- 잠금 상태에서 수동으로 확인할 테스트 절차

## 결과물

- `android/`의 자체 Kotlin 알람 경로
- `AlarmManager` broadcast가 전체 화면 알림을 게시하는 구현
- 잠금 상태에서 표시되는 전용 `AlarmActivity`
- 잠금을 유지하는 최소 알람 화면
- 반복 알람음과 소리·화면을 함께 종료하는 `끄기` 동작
- 직접 `Activity PendingIntent` 방식의 `BAL_BLOCK` 한계와 대체 경로를 기록한 검토 근거
- 전체 화면 알림 권한 또는 일반 알림 권한이 없을 때 예약을 차단하고 설정 화면으로 안내하는 경로

## 수행 순서

1. 자체 Kotlin 알람 경로를 구현한다.
2. 초기 직접 `Activity PendingIntent` 방식에서 잠금 상태 표시가 가능한지 확인한다.
3. `BAL_BLOCK`으로 실패할 경우 `AlarmManager broadcast → 전체 화면 알림 → AlarmActivity` 경로로 보완한다.
4. 전체 화면 알림 특별 접근, 높은 중요도의 알림 채널, `CATEGORY_ALARM` 경로를 설정한다.
5. 실기기에서 알람을 예약하고 즉시 화면을 잠근다.
6. 알람 시각에 전용 화면, 잠금 유지, 반복음을 확인한다.
7. `끄기`를 눌러 소리와 화면이 모두 종료되고 잠금 화면으로 돌아가는지 확인한다.
8. 전체 화면 알림 특별 접근을 끈 상태에서 예약이 차단되고 설정 안내가 표시되는지 확인한다.
9. 일반 알림 권한을 허용하지 않은 상태에서도 예약이 차단되는지 확인한다.

## done_when 확인 방법

다음 세 가지를 모두 같은 실기기에서 확인한다.

1. `SM-A245N` 잠금 상태에서 전용 알람 화면이 표시된다.
2. 잠금이 유지되어 시간표·관리 기능·일정 전체 내용이 노출되지 않는다.
3. `끄기` 버튼으로 반복 알람음과 알람 화면이 종료된다.

추가 보호 동작도 확인한다.

4. 전체 화면 알림 권한이 없으면 예약이 차단되고 설정 안내가 표시된다.
5. 일반 알림 권한이 없으면 예약이 차단된다.
