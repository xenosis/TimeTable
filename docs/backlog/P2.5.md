- 기준 백로그 SHA-256: `3019ba6681269fb9fa3f75a223a588fc7aa75906a3f023afa963f0e81eb7ed56`
- 기준 백로그 항목: `P2.5`
- 백로그 개발 상태: `done`
- 선행 작업: `P2.2`, `P1.9`
- 문서 상태: 2026-09-30 재설계(요일×교시 그리드 → 요일별 시간+제목 목록)를 반영해 갱신. 문서화 완료와 개발 작업 완료는 별도로 관리한다.

## 목적

주간 시간표를 아이가 스크롤 없이, 무엇이 언제 있는지 바로 알아볼 수 있게 보여 준다. 기본은 오늘 요일이 선택된 요일 탭 + 하루 전체 일정 목록이고, `주간 한눈에 보기`를 누르면 월~금 5개 컬럼에 그날 일정을 시작시간순으로 나열하는 보기로 전환된다. 일정에는 활성 테마의 의미 색과 아이콘을 적용한다. 백로그의 완료 기준은 “요일 탭 기본 보기와 주간 한눈에 보기 토글로 주간 시간표를 확인할 수 있고, 두 보기 모두 활성 테마의 의미 색·아이콘이 적용됨”이다.

## 쉬운 설명

시간표 탭을 열면 오늘 요일이 미리 선택된 요일 탭(월~금)과 그날 하루 전체 일정 목록이 나온다. 지난 시간은 흐리게, 지금 시간에는 "지금" 표시가 붙는다. 화면 위쪽의 `주간 한눈에 보기` 버튼을 누르면 월~금 5개 컬럼으로 바뀌는데, 각 컬럼 안에 그날 일정이 "09:30 국어"처럼 시작시간+제목 텍스트로 시작시간순 나열된다(일정 없는 요일은 "-"). 컬럼은 화면 폭에 flex로 균등 배치돼 가로 스크롤이 없고, 항목이나 요일 머리글을 누르면 그 요일의 하루 전체 목록으로 이동한다.

> 이전 두 버전 모두 실사용 피드백으로 교체됐다: 1차(가로 스크롤 요일×교시 격자, 제목 텍스트 표시)는 세로 화면에서 옆으로 밀어야 해서 제거(`src/components/WeeklyTimetable.tsx` 삭제). 2차(무스크롤 요일×교시 격자, 아이콘 칩만 표시)는 화면 폭 계산이 상위 컨테이너 패딩을 못 빼 칸이 잘리는 버그와, 제목·시간이 전혀 안 보이는 문제로 재교체. 셀 배치 유틸 `src/utils/weeklyTimetable.ts`와 그 테스트는 더 이상 쓰이지 않아 삭제했다.

## 필요한 입력

- SQLite DB 연결: `getDatabase()`가 제공하는 DB.
- `timetable_items`의 요일, 시작·종료 시각(교시 지정이면 `periods`와 결합), 제목, `color_key`, `icon_key`.
- 조회 범위: 기본 `familyId`인 `local-family`.
- 활성 테마: `ThemeDefinition`과 의미 색·아이콘 해석 함수.
- 앱의 핵심 목적(평일 학교-학원 일정 확인)에 따른 월~금 제한: `src/utils/weekdays.ts`의 `SCHOOL_WEEKDAYS`, `defaultSchoolWeekday`.

### 2026-09-30 재설계 (현재)

3. 셀 배치 계산 유틸 `src/utils/weeklyTimetable.ts`(`makeWeeklyTimetable`)와 그 테스트가 더 이상 필요 없어 삭제한다.
4. `WeekdayTabs`도 `SCHOOL_WEEKDAYS`로 월~금만 표시하도록 바꾸고, `app/(tabs)/timetable.tsx`의 초기 선택 요일은 `defaultSchoolWeekday(오늘)`로 계산한다(주말 접속 시 월요일 기본 선택).
5. `npm run check` 전체 통과 후 실기기(SM-A245N)에서 화요일 09:30 국어 항목이 화 컬럼에 "09:30 국어"로 정확히 표시되는지 시각 확인한다.

## done_when 확인 방법

다음 근거로 백로그의 완료 기준을 대조한다.

- `WeekdayTabs`가 월~금만 표시하고 오늘 요일을 기본 선택하며, `DailyScheduleList`가 해당 요일의 하루 전체 일정을 지난/지금/예정 상태로 표시하는지 확인한다.
- `주간 한눈에 보기` 토글 시 `WeekOverviewGrid`가 월~금 5개 컬럼을 가로 스크롤 없이 표시하고, 각 컬럼에 그날 일정이 시작시간순 "HH:MM 제목"으로 나열되는지 확인한다.
- 요일 매핑이 실제 요일과 정확히 일치하는지 확인한다(예: 화요일 등록 항목이 화 컬럼에 표시).
- 항목·요일 머리글 탭 시 해당 요일의 하루 보기로 이동하는지 확인한다.
- 두 보기 모두에서 일정에 `resolveThemeColor`, `resolveThemeIcon`으로 해석한 활성 테마의 의미 색·아이콘이 적용되는지 확인한다.
- 저장 후 새로고침 신호가 바뀌면 두 보기 모두 DB를 다시 조회해 최신 시간표를 표시하는지 확인한다.
- 마지막 `npm run check`가 통과했다: 지침 동기화, 파일 길이, lint, typecheck, Jest, Android x86_64 debug build.
- 실기기(SM-A245N)에서 월~금 표시, 요일 탭 기본 선택, 주간 목록 전환, 화요일 항목 정확한 컬럼 표시를 시각 확인했다.
- 최종 확인 결과, 재설계 후 `done_when` 조건과 선행 작업·검증 근거가 모두 확인되어 백로그 개발 상태가 `done`으로 유지된다.
