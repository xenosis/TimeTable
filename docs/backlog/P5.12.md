## 목적

일정 위젯과 별개로 오늘 할 일을 보여주는 위젯을 만듭니다. 앱을 열지 않아도 홈 화면에서 오늘의 할 일 현황(몇 개 완료/전체)을 볼 수 있습니다.

---

## 쉬운 설명

위젯 선택 화면에 "오늘 일정"과 "오늘 할 일" 두 종류가 따로 보여서, 원하는 것을 하나 또는 둘 다 선택해 올릴 수 있습니다.

- 크기: 기본 2x2 (가로 2칸, 세로 2칸), 최대 4x2
- 내용: 제목 "오늘 할 일 2/6" + 할 일 목록 (완료·미완료) + 상태 문구
- 특징: 미완료 먼저, 완료한 것은 흐리게

---

## 필요한 입력

- 위젯 데이터: `widgetDataV2.ts`의 7일치 데이터 (오늘 날짜·할 일 목록 포함)
- 테마 정보: `theme` 객체의 색 (배경, 글자, primary 색)
- 기기 높이: 위젯이 차지하는 dp 단위 높이

## 수행 순서

1. 오늘 날짜의 할 일 목록 조회 (widgetDataV2에서)
2. 미완료 먼저, 완료는 뒤로 정렬 (`WidgetTaskView.kt`)
3. 완료 상태에 따라 글자 색/opacity 다르게 설정 (흐리게)
4. 상태 문구 (없음/다 했음/데이터 없음) 구분
5. 보일 줄 수 계산 (기본 2줄, 최대 4줄)
6. `RemoteViews`로 각 줄 그리기 (체크 상자 아이콘·글자)
7. 새 `TaskWidgetProvider` 클래스 생성
8. `task_widget_info.xml` 등록 (기본 2x2, 미리보기)
9. `AndroidManifest.xml`에 공급자 등록
10. `WidgetUpdater.updateAll`에 `TaskWidgetProvider` 호출 추가
11. JUnit 테스트 12개 작성
12. 에뮬레이터 위젯 선택 화면에서 두 위젯 확인
13. 에뮬레이터 홈 화면에 올려 표시 확인
14. 실기기에서 기본 2x2 배치 및 상태 확인
15. `npm run check` 통과

## 한계와 제약

- **RemoteViews 제약**: `View` 사용 불가. 완료 상태를 체크 아이콘(☐/☑)으로만 표현 (앱처럼 체크박스 위젯 불가).
- **줄 수 한정**: 최대 4줄이므로 할 일이 4개를 넘으면 '+ N개'로 표시. 줄이 모자라면 완료한 것부터 뺌.
- **제목 형식**: 앱이 하루 상한(5개) 때문에 못 담은 할 일이 있으면 개수를 모르므로 "오늘 할 일"만 쓰고 "n/m" 형식 생략.
- **체크 동작**: P5.3에서 따로 구현 (이 작업은 표시만, 탭 기능은 나중).
- **데이터 갱신**: 7일이 지나면 위젯이 "앱을 열어 새로고침해 줘"만 보임.
