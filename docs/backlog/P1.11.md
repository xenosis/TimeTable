# P1.11 테마 선택 · 미리보기 화면

## 기준

- backlog schema version: `1.1`
- 기준 CLI 조회 스냅샷 SHA-256: `fcf1a0d72d4d0e3f604bef3df9227af081193151eff58dc8fb27de88fc2f3ad5`
- 기준 상태: `in_progress`
- 범위 결정: D8 — 딸 폰에서 로컬로 선택하고, 번들된 아이용 테마를 사용하며, 앱 안 UI만 변경한다.

## 목적

아이가 번들된 테마를 미리 보고 원하는 테마를 직접 선택할 수 있는 화면을 제공한다. 테마를 고르는 화면에서도 큰 글씨, 최소 터치 영역, 선택 상태를 확인할 수 있어야 한다.

## 쉬운 설명

테마 카드마다 실제 화면을 짐작할 수 있는 미리보기를 보여준다. 아이가 카드를 누르면 선택한 카드와 현재 선택 상태가 분명하게 표시되고, 선택 결과는 딸 폰의 로컬 테마 선택 상태에 적용된다.

문서화 완료는 이 화면의 요구사항을 기록한 것이며, 개발 작업 완료를 뜻하지 않는다.

## 필요한 입력

- P1.9에서 제공하는 `ThemeDefinition` 및 번들 테마 목록
- P1.10에서 제공하는 로컬 테마 선택·복원 상태와 선택 함수
- `app/index.tsx`에서 사용하는 활성 테마 컨텍스트
- D8 범위와 `docs/research.md`, `docs/tasks.md`의 1-11 요구사항

## 결과물

- `src/components/ThemePicker.tsx`: 번들 테마별 미리보기와 접근 가능한 선택 UI
- `app/index.tsx`: 현재 활성 테마와 테마 선택 UI를 화면에 연결
- `src/theme/provider.tsx`: 선택된 테마를 앱 UI에 적용
- `src/theme/selection.ts`: 선택 결과의 딸 폰 로컬 저장 및 복원 연결
- `src/theme/index.ts`: 미리보기에 사용할 테마 정의·목록·의미 키

앱 UI의 테마만 바꾸며, 운영체제 아이콘·스플래시·알림 아이콘 같은 운영체제 자산은 이 작업의 결과물에 포함하지 않는다. `app.json`, `package.json`, `android/app/build.gradle`은 관련 기준 확인 대상이며, 이 문서 작업에서 수정하지 않는다.

## 수행 순서

1. 기준 schema version과 SHA-256, D8 범위, 선행 작업 상태를 확인한다.
2. P1.9의 번들 테마 정의와 P1.10의 로컬 선택 API가 제공하는 입력·출력을 대조한다.
3. 테마마다 배경·카드·강조색·과목 색·장식이 보이는 미리보기와 이름·설명을 구성한다.
4. 아이가 누를 수 있는 영역을 충분히 크게 만들고, 선택된 카드의 테두리·표시·접근성 선택 상태를 함께 제공한다.
5. 선택 결과가 `ThemeProvider`를 통해 앱 UI에 적용되고, P1.10의 로컬 저장으로 다시 열었을 때 복원되는지 확인한다.
6. 테마 선택 화면에서 큰 글씨와 최소 터치 영역을 확인하고, 운영체제 자산이나 개발 작업 완료 상태를 이 작업의 완료로 기록하지 않는다.

## done_when 확인 방법

다음 조건을 모두 확인한다.

- 번들 테마 각각에 대해 실제 색상·장식·과목 색을 보여주는 미리보기가 렌더링된다.
- 테마 카드를 눌러 선택할 수 있고, 선택된 테마가 테두리·선택 표시·접근성 선택 상태로 구분된다.
- 제목·설명·선택 UI의 글씨가 아이가 읽기 쉬운 크기이고, 카드와 선택 요소가 최소 터치 영역을 충족한다.
- 선택 결과가 앱의 활성 테마에 적용되고, 앱을 다시 열어도 딸 폰 로컬 선택값으로 복원된다.
- 선택 화면과 적용 결과가 앱 안 UI에만 영향을 주며 D8 범위를 벗어난 운영체제 자산 변경이 없다.

- `app/index.tsx`는 활성 테마와 선택 UI를 연결하고 테마 색을 화면에 적용하도록 구성되어 있다.
- 실제 기기에서 아이가 읽는 글씨 크기와 체감 터치 영역을 확인하는 것은 이 기록만으로 완료 처리하지 않는다.
- 개발·검사 완료 및 backlog 상태 변경은 이 문서의 범위에 포함하지 않는다.
