## 목적

완료 이력이 있는 반복 할 일(예: 끝난 학원 숙제)은 현재 수정·삭제가 차단되어 아이의 오늘 목록에 영구히 남는 문제를 해결합니다. `effective_until` 컬럼과 '오늘까지만 하고 그만두기' 동작을 추가해 과거 완료 이력은 보존한 채 앞으로만 멈출 수 있게 합니다.

---

## 쉬운 설명

끝난 학원 과제처럼 더 이상 반복할 필요가 없는 할 일에 대해, 관리자(아빠)가 '오늘까지만 하고 그만두기' 버튼을 누르면 그날부터는 아이의 목록에 나타나지 않습니다. 과거에 완료한 기록은 사라지지 않으므로 "지난주 목표 달성"처럼 통계를 낼 때도 정확합니다.

### 실기기 미확인 범위

| 항목 | 사유 | 대체 검증 |
| --- | --- | --- |
| 내일부터 목록 제외 실제 확인 | 딸 폰 데이터가 초기화되어 당일 다음 날 재접속 불가 | 실제 SQLite 테스트: 오늘 목록 필터(`task-end-real-sql.test.ts`) |
| 다음 날 주간 완료율 변화 | 위와 동일 | 실제 SQLite 테스트: 일간 전체 완료 + 주간 보석(`hasTasksOn`) 필터, 종료 조건을 지우면 실패하는 것을 확인 |
| 다음 날 할 일 알림 미발송 | 위와 동일 | 실제 SQLite 테스트: `buildTaskNotificationsFromDatabase`가 종료일 다음 날부터 알림을 만들지 않음 |

### 기술적 제약

1. **날짜 비교 기준**: effective_until >= 오늘 조건이므로, 오늘 날짜로 설정된 할 일은 오늘까지만 목록에 나타남. 자정이 지나면 자동으로 다음 날 조회에서 제외됨 (날짜 변경 로직이 아니라 DB 쿼리 기준).

2. **보상 동기화**: `editTaskWithRewards`로 감싸서 종료 시 보상 계산이 반영되게 함. 하지만 이미 적립된 보석은 회수하지 않음 (과거 완료 이력과 같은 원칙).

3. **알림 경로**: `taskRollingSchedule.ts`에 필터 추가했으나 실제 앱 내 알림 실행 상태는 앱 ANR 문제로 에뮬레이터에서 검증 불가.
