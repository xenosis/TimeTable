## 작업 목적

완료 이력이 있는 반복 할 일(예: 끝난 학원 숙제)은 현재 수정·삭제가 차단되어 아이의 오늘 목록에 영구히 남는 문제를 해결한다. `effective_until` 컬럼과 `오늘부터 그만두기` 동작을 추가해 과거 완료 이력은 보존한 채 앞으로만 멈출 수 있게 한다.

## 쉬운 설명

끝난 학원 과제처럼 더 이상 반복할 필요가 없는 할 일에 대해, 관리자가 `오늘부터 그만두기` 버튼을 누르면 그날부터는 아이의 목록에 나타나지 않는다. 과거에 완료한 기록은 사라지지 않으므로 "지난주 목표 달성"처럼 통계를 낼 때도 정확하다.

## done_when 확인 방법

**요구사항:**
완료 이력이 있는 반복 할 일을 딸 폰 실기기에서 `오늘부터 그만두기`로 종료하면 **종료일 이후** 오늘의 할 일·주간 완료 계산에서 더 이상 나타나지 않고, 과거 완료 이력은 그대로 남는다.

**검증 방법:**

1. **실기기 확인 (2026-09-28 완료):**
   - 완료 이력이 있는 반복 할 일(예: P44check)에서 `오늘부터 그만두기` 실행
   - 결과: 할 일 편집 목록에서 즉시 사라짐(수정 불가 상태 해제됨 ✓)
   - 오늘의 할 일 목록: 오늘 날짜까지는 그대로 남음 (코드상 `effective_until >= 오늘` 조건 ✓)
   - 과거 완료 이력: 보존됨 ✓

2. **남은 검증 사항 (실기기 관찰 불가, 코드 검토로 확인):**
   - **"종료일 이후"(내일부터) 실제 제외**: 하루가 지나야 관찰 가능하므로 이번 세션에는 실기기에서 직접 확인하지 못함
   - 대신 SQL 조건 `effective_until >= 오늘 날짜`를 코드 검토로 확인했으며, 종료일이 오늘이면 내일부터는 자동으로 제외됨을 논리적으로 검증

3. **단위 테스트:**
   - `getEndableTasks()` 반환값 검증 (완료 이력 있는 항목만)
   - `endRecurringTask()` 호출 후 `effective_until` 설정 확인
   - `getTodayTasks()` 필터: `effective_until`이 NULL 또는 오늘 이후인 항목만 반환
   - 3개 테스트 추가

4. **코드 검사:**
   - `npm run check`: lint, typecheck, Jest 통과
   - 의존 작업 P4.3 done 확인

## 확인 질문

**Q1: "종료일 이후 실제 제외" 검증 방법**
- 도_when의 "종료일 이후 오늘의 할 일·주간 완료 계산에서 더 이상 나타나지 않고"를 검증하려면 내일 날짜에 실기기를 다시 확인해야 한다.
- 현재(2026-09-28): 오늘 날짜까지는 목록에 남음 (의도된 동작) ✓
- 내일(2026-09-29): 실제로 목록과 계산에서 빠져야 함 (아직 미확인)
- 이 검증은 다음 세션에서 진행하거나, 만약 사용자가 지금 당일 자정까지 대기해 다음 날을 확인할 수 있다면 그때 추가 테스트 가능

**Q2: 주간 완료 계산에서의 제외**
- 종료일 이후 주간 완료 계산에서도 빠져야 하는데, 이는 hasTasksOn(rewardRepository)의 필터로 적용되었다.
- 내일부터 실기기에서 주간 완료율이 정확히 감소하는지도 함께 확인하면 좋다.
