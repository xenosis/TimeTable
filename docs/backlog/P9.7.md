## 목적

기본 폭과 글자 크기에서 관리자 화면이 짧고 한눈에 읽히는지, 키보드가 열린 상황에서도 입력·저장·취소가 가능한지 확인한다. PIN 보호, 시간표·할 일 기능, 알림·위젯, 아이 화면이 관리자 화면 변경으로 깨지지 않았는지도 함께 회귀 확인한다.

## 쉬운 설명

관리자 화면을 작은 화면(360dp)과 큰 화면(393dp), 세로와 가로에서 실제로 살펴본다. 평일 일정이 많고, 이름이 긴 시간표와 완료 이력이 있는 할 일을 넣어도 필요한 내용을 찾고 편집할 수 있는지 확인한다. 글자를 크게 설정해도 저장 버튼이 보이는지 확인한다. PIN을 다시 요구하는지와 저장한 내용이 아이 화면·알림·위젯에 그대로 이어지는지도 확인한다. 테스트하는 기기(에뮬레이터인지 어느 실기기인지)를 명확히 기록한다.

## 현재 확인 기록

### 수정 이력

#### 1. 시간표 항목 편집 모달 키보드 가림 문제 (커밋 a10f777, v1.55.3)

- **문제**: 모달에서 시작·종료 시간 입력 시 키보드가 열리면 아래 '저장·취소·삭제' 버튼이 완전히 가려짐. 스크롤해도 닿지 않음.
- **원인**: 이전 버전(1.55.2)에서 관리자 화면 하단 여백 추가 방식이 모달의 KeyboardAvoidingView에 전파되지 않음.
- **해결**: 저장·취소 버튼을 모달의 맨 위 제목 줄로 옮김 (고정 위치, 키보드 열림 무관 항상 보임)
- **근거**: `docs/device-verification-2026-10-08.md` "관리자 화면 밀도·입력·회귀" 섹션

#### 2. 관리자 화면 하단 및 가로 화면 탐색 막대 가림 (커밋 49340c3, v1.55.2)

- **문제**: 관리자 화면의 마지막 영역(요일 시간표 복사 등)이 3버튼 탐색 막대 뒤에 반쯤 가려짐. 가로 화면 오른쪽 끝 버튼(열기, 바꾸기, 추가 등)이 탐색 막대에 가림.
- **해결**: 관리자 화면의 아래, 좌우 시스템 여백(`paddingBottom`, `paddingRight` 등)을 추가하여 탐색 막대 공간 확보.
- **근거**: `docs/device-verification-2026-10-08.md` "관리자 화면 밀도·입력·회귀" 섹션

#### 3. 교시 시간 영역 제목 중복 및 색 고정 (수정 기록 확인 필요)

- **문제**: 교시 시간 영역에서 제목이 중복되거나 테마 색이 아닌 고정 보라색으로 표시됨.
- **상태**: 수정 완료 — PeriodSettings가 테마 색을 쓰고 안쪽 제목을 없앰 (커밋 49340c3, v1.55.2)
