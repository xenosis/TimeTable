## 목적

기본 폭과 글자 크기에서 관리자 화면이 짧고 한눈에 읽히는지, 키보드가 열린 상황에서도 입력·저장·취소가 가능한지 확인한다. PIN 보호, 시간표·할 일 기능, 알림·위젯, 아이 화면이 관리자 화면 변경으로 깨지지 않았는지도 함께 회귀 확인한다.

## 쉬운 설명

관리자 화면을 작은 화면(360dp)과 큰 화면(393dp), 세로에서 실제로 살펴본다. 평일 일정이 많고, 이름이 긴 시간표와 완료 이력이 있는 할 일을 넣어도 필요한 내용을 찾고 편집할 수 있는지 확인한다. PIN을 다시 요구하는지와 저장한 내용이 아이 화면·알림·위젯에 그대로 이어지는지도 확인한다. 테스트하는 기기(에뮬레이터인지 어느 실기기인지)를 명확히 기록한다.

## 현재 확인 기록

### 형태 변경 (P9.6, 1.55.5)

#### 사항: 시간표 항목 편집 형태 변경 (모달 → 관리자 화면 안 폼)

- **계획 기준과의 차이**: `docs/admin-compact-plan.md` 49행에서 "선택 항목을 누르거나 추가를 누를 때만 편집 폼을 연다. 폼은 선택 항목에 집중하는 모달로 두어..."라고 규정했으나, 1.55.5에서는 편집 폼을 **모달이 아닌 관리자 화면 안(목록이 있던 자리)**에서 펼치도록 변경함.
- **변경 이유**: 모달에서 시간표 항목 편집 중 선택 필드(예: '미리 알림 분')를 누르면 키보드가 열리며 아래 입력칸이 키보드 뒤에 가려짐. 모달의 KeyboardAvoidingView가 제대로 작동하지 않아 스크롤해도 닿지 않는 문제 발생. 관리자 화면 안 폼으로 변경하면 화면 전체가 스크롤되어 모든 입력칸과 버튼이 키보드 위로 올라옴.
- **확인 근거**: `docs/device-verification-2026-10-08.md`의 'P9.7 리뷰 보완 실기기 확인' 섹션에서 실제 구현 동작 확인

### 수정 이력

#### 1. 시간표 항목 편집 폼 위치 변경 및 키보드 가림 개선 (커밋 a10f777 이후, v1.55.5)

- **문제**: 1.55.4 이하에서 모달 내 입력칸 선택 시 키보드가 열려도 아래 버튼이 보이지 않으며 스크롤로도 접근 불가.
- **해결**: 1.55.5에서 편집 폼을 모달에서 **관리자 화면 안(목록 자리)**로 변경. 폼이 열리면 목록이 사라지고 폼이 그 자리에 펼쳐지며, 화면 전체가 스크롤 가능해짐. 입력 중 키보드가 열려도 화면이 올라가 모든 입력칸과 '추가'/'수정 저장' 버튼이 키보드 위에 보임.
- **확인 근거**: 딸 폰 SM-A245N 1.55.4 → 1.55.5 (2026-10-08 21:05~21:40) 실기기 확인: 시간표 항목 편집 중 '미리 알림 분' 칸 선택 시 화면이 올라가고 입력값(05)이 키보드 위에 표시됨. 휴대폰 뒤로 가기는 "작성 중인 내용이 있어요" 확인 필요.
