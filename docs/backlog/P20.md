## 목적과 쉬운 설명

주간·요일별 시간표가 실제로 사용할 수 있는 표 높이를 활용하게 한다. 기본 배율은 시간에 비례하며, 짧은 실제 일정은 두 줄 제목의 최소 높이를 우선한다. 모든 요일이 같은 시간축을 공유하고 빈 시간도 남긴다. 오전 수업과 점심을 접어도 5교시 이후가 남아야 하며, 모든 최소 높이가 들어가지 않을 때만 표 안을 스크롤한다. 2026년 11월 세트의 `일루스티` 표기를 `일루스터`로 정정한다.

## 입력·결과물·선행 조건

- 입력: 실제 표시 viewport, 시간표 상단 컨트롤과 안내 높이, 일정 경계·텍스트, 학교 접힘 상태, 공통 시간축.
- 결과: 실제 남은 높이를 측정해 표에 배분하고 마지막 종료 시각까지 보이는 시간표, 짧은 일정 내부 가독성, 접기·펼치기, 현재 강조와 공통 시간 칼럼, 11월 세트의 이름만 정정한 데이터.
- 관련 소스: `app/(tabs)/timetable.tsx`, `src/components/WeekTimeGrid.tsx`, `src/components/WeekOverviewGrid.tsx`, `src/utils/scheduleGridLayout.ts`, `src/utils/schoolGridDays.ts`.
- 선행 작업: P19 `done`; 별도 승인 gate 없음. 폰 설치·조작은 별도 확인으로 취급한다.

## 수행 순서

1. 실제 viewport와 시간표 상단 컨트롤·안내 영역을 측정한다.
2. 표 여백·상단 컨트롤·안내·마지막 시각 라벨을 차감해 남은 높이를 계산한다.
3. 일정 제목 최대 두 줄과 짧은 일정 최소 높이를 보장하고, 합계가 작은 화면에 넘칠 때만 내부 스크롤한다.
4. 오전 수업·점심만 접고 5교시 이후를 유지하며 펼침 시 원본 시간표를 복원한다. 현재 강조와 시간 칼럼을 유지한다.
5. 실제 11월 세트 이름만 수정했는지 확인하고 회귀·전체 검사 및 같은 입력 리뷰를 수행한다.
