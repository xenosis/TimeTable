## 작업 목적

TimeTable 앱이 Supabase 서버에 시간표·할 일·완료 기록·보석·보상 데이터를 안전하게 저장하고 아빠 폰에서 원격으로 관리하게 할 기반이 됩니다.

---

## 쉬운 설명

서버 데이터베이스(Supabase의 Postgres)에 앱이 필요한 테이블(families, periods, timetable_items 등)을 만듭니다. 이미 작성된 13개 테이블의 정의를 마이그레이션 SQL 파일로 정리하고, 로컬 앱의 SQLite 구조와 맞춰 동기화가 쉽게 합니다.
