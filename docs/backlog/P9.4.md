## 수행 순서

1. 현재 시간표 세트와 기본 오늘 요일 필터를 제공하고, 선택한 하루의 일정만 실제 시작 시각 기준으로 정렬한다.
2. 추가를 눌렀을 때 새 항목 폼의 초기 반복 요일을 현재 목록에서 선택한 요일로 설정한다. 수정 폼의 요일 규칙은 기존 단일 요일 규칙을 유지한다.
3. 폼을 연 뒤 목록 필터와 폼 반복 요일을 독립 상태로 유지한다. 필터 변경이 폼 값이나 저장 데이터를 바꾸지 않는지 확인한다.
4. 평일 총 20개 예시에서 선택 하루 4개만 표시되는지와 CRUD·세트 분리·알림/위젯 갱신을 확인한다. 토·일 및 빈 요일에서도 추가와 편집을 확인한다.

## 완료 조건 및 확인 방법

백로그 done_when 원문:

> 평일 하루 4개 총20개 데이터에서 선택 하루 4개만 보이고 교시/직접 입력 시각순 정렬. 토·일/빈 요일도 추가·편집 가능. 목록 필터는 폼 반복값을 바꾸지 않으며 신규는 다중/수정은 단일 요일 규칙 유지. 세트 분리, CRUD, 저장 후 선택 요일 유지, 미저장 변경 확인·중복 저장 차단과 알림/위젯 갱신을 회귀 검증. 목록 아래로 내려가지 않고 모달에서 편집 가능.

확인 방법: 평일 각 4개씩 총 20개를 준비해 선택한 요일의 4개만 표시되고 교시 시작 시각과 직접 입력 시각으로 정렬되는지 확인한다. 월~일 각 필터에서 추가 폼을 열어 초기 반복 요일이 목록 선택 요일인지 확인한 다음 폼을 연 상태에서 목록 필터를 바꾸어 폼 값은 유지되는지 확인한다. 신규 다중 요일과 수정 단일 요일, 토·일/빈 요일, 세트 분리, CRUD, 저장 뒤 선택 요일 유지, 미저장 변경 확인, 중복 저장 차단 및 알림·위젯 갱신도 대조한다. 폼은 목록 아래로 이동하지 않고 모달에서 접근 가능한지 확인한다. 개발 검증 전에는 문서화 완료와 기능 완료를 구분한다.
