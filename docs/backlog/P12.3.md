## 목적

캐릭터가 글씨와 체크 영역을 가리지 않도록 두 테마의 세로·가로·큰 글씨·빈 화면과 로딩 화면을 확인한다.

## 쉬운 설명

두 캐릭터 테마를 화면 크기와 글자 크기를 바꿔 보며 읽기와 조작이 모두 편한지 확인한다. P12.2 중 이미 모인 화면과 자동 검사 근거는 이어받아 조건별로 대조하지만, P12.3의 검증과 상태 기록을 완료했다.

## 필요한 입력

- P12.2 구현 및 리뷰 완료
- [최신 character-theme-plan.md 체크리스트](../character-theme-plan.md)
- 이미 모인 에뮬레이터 캡처와 `.tmp/p12-quality-resumed.log`

## 결과물

- 의미 색·대비·터치 영역·선택 저장 및 두 화면 캐릭터 차이를 조건별로 확인한 근거
- 두 테마의 세로/가로/배율1.5, 빈 상태/로딩 화면 확인 기록
- 전체 검사 및 리뷰 상태 기록

## 수행 순서

1. 선행 작업 P12.2의 현재 상태를 확인한다.
2. 두 테마의 세로·가로·배율1.5 화면과 오늘/내 보석/시간표 의미 색을 비교한다.
3. 0/0 및 일정 없음의 빈 상태, 로딩 상태에서 캐릭터·글씨·체크·선택 영역이 겹치지 않는지 확인한다.
4. 대비·터치 영역·선택/재시작 유지·그림 단계·날짜 경계의 실제 근거와 전체 검사·리뷰를 대조한다.

## done_when 확인 방법

> 의미 색·대비·터치 영역·선택 저장·두 화면의 캐릭터 차이와 전체 검사 및 리뷰를 확인한다.
