# P2.18 — 메모 표시: 오늘·요일별·주간 화면에 메모 보이기

## 기준 입력

- 백로그 schema version: `1.1`
- 백로그 SHA-256: `a4bf31fc91c2cd4ca36b8122d025cf0f792c54f31842a35de1e0f961e3e26110`
- 기준 항목: `P2.18`
- 백로그 상태: `in_review`
- 우선순위: P3 (핵심 기능 아님)
- 부모 작업: 없음 (최상위)
- 선행 작업: P2.16 (메모 저장), P2.17 (메모 입력)

## 목적

저장된 메모를 오늘 화면, 요일별 화면, 주간표 칸에 보여준다. 오늘·요일별 화면은 시간 아래에 메모를 한 줄로 표시하고, 주간표는 칸이 좁으므로 메모 마커(📝)만 표시한다. 접근성을 위해 주간표의 메모 전문은 라벨에 포함한다. 미결정(사용자 확인): 알림 본문, 잠금 화면 알람, 홈 화면 위젯에도 메모를 보여줄지.

## 쉬운 설명

저장한 메모가 아이가 보는 화면(오늘, 요일별, 주간)에 함께 나타난다. 예를 들어 "수학 학원 14:00"과 함께 "과제 테스트"라는 메모가 작게 표시된다. 메모가 없으면 지금처럼 제목만 보인다.

## 필요한 입력

- P2.16에서 저장한 메모 데이터
- P2.17에서 입력한 메모 기능
- 기존 화면 컴포넌트
  - 오늘 화면 (`app/(tabs)/index.tsx` 또는 `src/components/TodayScheduleCard.tsx`)
  - 요일별 화면 (`src/components/DailyScheduleList.tsx`)
  - 주간 화면 (`app/(tabs)/timetable.tsx` 또는 `src/components/WeekTimeGrid.tsx`)

## 결과물

### UI 화면 수정

**오늘 화면 (`TodayScheduleCard.tsx`)**
- 항목 시간 아래에 메모 한 줄 표시
- 메모가 있으면: "14:00 - 수학 학원\n과제 테스트"
- 메모가 없으면: 기존대로 "14:00 - 수학 학원"
- 메모 글씨: 작은 크기, 회색 색상 (구별 용이)
- 한 줄을 넘으면 말줄임표 (...)

**요일별 화면 (`DailyScheduleList.tsx`)**
- 각 항목의 시간 아래에 메모 한 줄 표시
- 메모 글씨: 작은 크기, 회색 색상
- 레이아웃: 시간(제목), 메모(부제목)
- 한 줄을 넘으면 말줄임표 (...)

**주간 화면 (`WeekTimeGrid.tsx`)**
- 셀에는 메모 마커(📝) 아이콘만 표시
- 메모가 있으면 셀에 작은 📝 아이콘 표시
- 접근성: 주간표 셀의 접근성 라벨에 메모 전문 포함
  - 예: "14:00 수학 학원. 메모: 과제 테스트"

### 구현 방식

1. **데이터 조회**: 기존 `getTimetableItems...` 함수는 이미 메모를 포함
2. **조건부 렌더링**: 메모가 있으면 (`memo && memo.trim().length > 0`) 표시
3. **오늘·요일별 화면 스타일**: 
   - 메모 글씨 크기: 제목보다 작음 (12-14pt)
   - 메모 색상: 회색 또는 보조 색상 (테마에서 정의)
   - 한 줄 (numberOfLines={1})
   - 말줄임표: true
4. **주간표 스타일**:
   - 메모 마커: 📝 아이콘 (1개 표시)
   - 마커 크기: 작음 (12-14pt)
   - 접근성 라벨: 메모 전문 포함

## 완료 기준

완료 조건: 메모가 있는 항목에 한해 오늘·요일별 화면에 메모가 한 줄로 표시되고 주간 화면에는 메모 마커(📝)가 표시됨. 메모가 없는 항목은 지금과 같음. 세로 화면에서 겹치거나 깨지지 않음(에뮬레이터 확인). 주간표 접근성 라벨에 메모 전문 포함. 가로 화면은 미확인 (사용자 결정 대기). 알림·잠금 화면 알람·위젯 표시 여부가 사용자 결정으로 기록됨. npm run check 통과

| 조건 | 확인 방법 |
|---|---|
| 오늘 화면 메모 표시 | 메모가 있는 항목에서 시간 아래에 메모가 한 줄로 표시되는지 확인 |
| 요일별 화면 메모 표시 | DailyScheduleList에서 메모가 한 줄로 표시되는지 확인 |
| 주간 화면 메모 마커 | WeekTimeGrid에서 메모가 있는 항목에 📝 마커가 표시되는지 확인 |
| 접근성 라벨 | 주간표 셀의 접근성 라벨에 메모 전문이 포함되는지 확인 |
| 메모 없는 항목 | 메모가 없는 항목은 기존과 동일하게 표시되는지 확인 |
| 세로 화면 | 세로 전체 높이에서 텍스트가 겹치거나 잘리지 않는지 확인 |
| 메모 줄 수 제한 | 메모가 2줄 초과일 때 말줄임표(...)가 표시되는지 확인 |
| 메모 길이 극단 | 긴 메모(100글자 최대)가 어떻게 표시되는지 확인 |
| 단위 테스트 | 메모 표시 관련 테스트 모두 통과 |
| npm run check | 전체 검사 통과 |

## 수행 순서

1. P2.16·P2.17 완료 확인 (메모 저장·입력)
2. 기존 화면 컴포넌트 구조 검토
   - `TodayScheduleCard.tsx`: 오늘 화면 항목 렌더링
   - `DailyScheduleList.tsx`: 요일별 항목 렌더링
   - `WeekTimeGrid.tsx`: 주간 화면 셀 렌더링
3. 오늘·요일별 화면에 메모 표시 로직 추가
   - 조건: `item.memo && item.memo.trim().length > 0`
   - 렌더링: `<Text numberOfLines={2} ellipsizeMode="tail">{item.memo}</Text>`
   - 스타일: 작은 크기, 회색 색상
4. 주간 화면에 메모 마커 추가
   - 메모 마커: 📝 아이콘
   - 조건: 메모가 있으면 마커 표시
   - 접근성 라벨에 메모 전문 포함
5. 스타일 정의
   - 메모 글씨 크기 (12-14px)
   - 메모 색상 (테마의 회색/보조 색상)
   - 메모 줄 높이 (한 줄)
6. 단위 테스트 작성
   - 메모 유무에 따른 렌더링 테스트
   - 메모 줄 수 제한 테스트
   - 주간표 마커 테스트
   - 접근성 라벨 테스트
7. 에뮬레이터에서 세로 화면 확인
   - 오늘 화면 메모 표시 확인
   - 요일별 화면 메모 표시 확인
   - 주간표 메모 마커 확인
8. `npm run check` 실행

## 미결정 사항 (사용자 확인 필요)

사용자가 결정해야 할 사항을 다음과 같이 정리:

1. **가로 화면 메모 표시 여부**
   - 현재: 세로 화면만 확인 완료
   - 미결정: 가로 화면에서도 메모 표시할 것인지 → 사용자 결정 대기

2. **알림 본문에 메모 포함 여부**
   - 예: "수학 학원 - 과제 테스트"
   - 아니오: 제목만 ("수학 학원")
   - → 사용자 결정 대기

3. **잠금 화면 알람에 메모 포함 여부**
   - 예: 전체 화면 알람 화면에 메모 함께 표시
   - 아니오: 제목만 표시
   - → 사용자 결정 대기

4. **홈 화면 위젯에 메모 포함 여부**
   - 예: 위젯에 메모도 표시
   - 아니오: 위젯에는 제목만
   - → 사용자 결정 대기
