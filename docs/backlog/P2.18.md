## 목적

사용자 결정(2026-10-01)에 따라 저장된 메모를 앱 전역의 아이 화면에 표시한다. 오늘 화면과 요일별 시간표 화면에는 시간 아래 한 줄로 메모를 표시한다. 주간 시간표 칸에는 📝 마커만 표시하여 메모 여부를 나타낸다(메모 내용은 숨김). 알림과 잠금 화면 알람 본문에도 메모를 표시한다. 홈 화면 위젯에는 메모를 포함하지 않는다. 메모 길이는 최대 100글자로 제한하고, 오늘 카드·요일별 목록에서는 한 줄로 표시한다.

## 쉬운 설명

시간표 항목에 메모를 저장하면, 아이가 보는 화면 곳곳에 함께 나타난다.

1. **오늘 화면** — "수학 학원 14:00" 아래에 메모를 한 줄로 표시
2. **요일별 시간표 화면** — 각 항목의 시간 아래에 메모를 한 줄로 표시
3. **주간 시간표** — 메모가 있는 칸에만 📝 마커 표시 (메모 내용은 보이지 않음)
4. **알림 본문** — 알림 메시지 아래에 메모 한 줄 추가
   - 예: "수학 학원 시간이에요.\n📝 과제 확인"
5. **잠금 화면 알람** — 알람 본문에 메모 포함
6. **홈 화면 위젯** — 메모를 표시하지 않음 (위젯 크기 제약)

메모가 없는 항목은 현재와 같이 표시된다.
