아이가 할 일을 체크하면 스티커를 얻고, 모은 스티커의 개수와 보상까지 남은 개수를 보는 기능이다. 할 일마다 정한 시간에 알림도 준다.

  - P4.2: 할 일 완료 기록

  - P4.7: 보석판·보상 화면
  - P4.8: 할 일 알림

## 결과물

할 일 관리·스티커 적립·스티커판·알림이 모두 동작하는 상태.

## 선행 작업

- `P3` — 3단계: 시간표 + 알림 (deps에 명시)

P3이 완료되어야 P4의 알림 체계와 네이티브 교체 경계를 연동할 수 있다.

## 수행 순서

1. P3 완료 후 할 일 기능 개발 시작
2. P4.1 ~ P4.5를 차례로 진행
3. P4.7 (스티커판·보상 화면)
4. P4.8 (할 일 알림)
5. 각 작업의 done_when 조건 확인
6. 실기기 검증 (필요한 경우)

## done_when 확인 방법

P4 완료 기준: **"할 일 체크와 스티커가 동작함"**

확인할 사항:
- 할 일 체크: 아이가 할 일 항목을 체크했을 때 저장된다.
- 스티커 적립: 실물 보석(작은/큰 보석 따로) 개수를 수동으로 관리한다.
- 스티커판: 모은 보석, 보상 목표까지 남은 개수, 5일 연속 진행이 화면에 표시된다.
- 할 일 알림: 설정된 시간에 알림이 와서, 미완료 시 30분 뒤 재알림이 온다.
