# P6.3 — RLS 정책

## 기준
- 백로그 schema: 1.1
- 백로그 sha256: 86894def7f03d9e5155fca3e3ecfbd1a32bb7f6fda8dc9cb25145da30a139496
- 백로그 bytes: 51194
- 개발 상태: todo
- 문서화 상태: 작성됨

## 작업 목적
아빠는 전체 쓰기, 딸은 읽기와 오늘 완료 체크 정책을 적용한다.

## 쉬운 설명
쉽게 말해, RLS 정책을 백로그 범위에서 수행한다.

## 필요한 입력
기준 백로그 P6.3와 관련 요구사항 문서. 백로그에 없는 값은 임의로 정하지 않는다.

## 결과물
역할별 RLS 정책이 테스트로 검증됨

## 선행 작업
백로그에 기록된 상위 작업과 deps의 완료 결과를 확인한다.

## 수행 순서
1. 범위와 입력을 확인한다.
2. 선행 작업 결과를 준비한다.
3. 백로그 범위만 수행하고 결과를 기록한다.
4. done_when을 확인한다.
5. 개발 완료와 문서화 완료를 구분해 기록한다.

## done_when 확인 방법
역할별 RLS 정책이 테스트로 검증됨를 결과와 대조하고 확인 근거를 남긴다.

## 확인 질문
백로그에 없는 세부 구현값이나 운영 조건이 필요하면 어떤 값으로 결정할지 확인이 필요하다.
