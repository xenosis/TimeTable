# P14: 상단 앱 제목 제거와 하단 설정 접근

## 기준 입력

- Backlog schema version: `1.1`
- Backlog SHA-256: `041354100fd1d54ecc995e08d0da22bb3c28a60176675171eb8851ff5511c940`
- 현재 기준 백로그 상태: `done` (최신 CLI get P14 입력). 이전 `in_review`는 당시 상태를 기록한 것이다.

## 목적

아이 화면에서 상단 `TimeTable` 제목줄을 없애 화면 공간을 확보하고, 오늘·시간표·내 보석·설정으로 하단에서 이동할 수 있게 한다. 오늘 탭 아이콘은 해로 표시한다. 설정은 계속 PIN으로 보호하며, 가로 주간 시간표 몰입 화면은 전체 화면 표시를 유지한다.

## 쉬운 설명

화면 위쪽의 앱 이름을 치우고 아래쪽에 네 가지 이동 버튼을 둔다. 아이는 오늘 화면의 해 아이콘을 누르고, 설정 버튼으로 들어가더라도 PIN을 통과해야 한다. 주간 시간표를 가로로 크게 볼 때는 아래 메뉴가 숨겨지고 화면 가장자리 여백도 중복으로 붙지 않아야 한다.

## 필요한 입력

- 요구사항: 아이 화면 제목 제거, 상태 표시줄 안전 영역, 하단 오늘·시간표·내 보석·설정 접근, 오늘 해 아이콘, 관리자 PIN 및 뒤로 복귀 유지, 가로 주간 몰입 화면 이중 여백 방지.
- 변경 위치: `app/(tabs)/_layout.tsx`, `app/_layout.tsx`.
- 프로젝트의 기존 화면 규칙: 아이가 보는 화면은 큰 글씨와 큰 터치 영역을 사용하고 설정은 PIN 뒤에 둔다.

## 결과물

- 아이 화면에 상단 앱 제목줄이 없는 레이아웃.
- 상태 표시줄 아래 안전 여백을 확보하는 화면 배치.
- 오늘·시간표·내 보석·설정의 하단 접근 경로와 오늘 탭 해 아이콘.
- 설정 진입 시 기존 PIN 보호 및 뒤로 돌아오는 동작.
- 가로 주간 몰입 화면에서 하단 메뉴가 감춰지고 안전 영역 여백이 중복 적용되지 않는 동작.
- 기능 변경 버전이 `app.json`, `package.json`, 존재하는 경우 `android/app/build.gradle`에 함께 반영된 상태.
- 검사·화면 확인·병렬 리뷰 근거가 기록된 작업 결과.

## 선행 작업

- 명시된 직접 의존성은 없다 (`deps: []`).
- 기존 동작을 보존할 기준으로 관리자 PIN 게이트와 주간 시간표의 가로 몰입 모드를 확인한다.

## 수행 순서

1. 아이 화면의 상단 제목을 제거하고 상태 표시줄 안전 여백을 확인한다.
2. 하단 메뉴에서 오늘·시간표·내 보석·설정에 접근할 수 있게 하고, 오늘 아이콘을 해로 표시한다.
3. 설정 메뉴가 기존 PIN 게이트를 거치며 뒤로 아이 화면에 복귀하는지 확인한다.
4. 가로 주간 시간표 몰입 모드에서 메뉴 숨김과 안전 영역 여백을 확인해 이중 여백이 없는지 점검한다.
5. 앱 버전 관련 파일을 함께 갱신하고 전체 검사 및 화면 확인을 수행한다.
6. 같은 기준 입력의 SHA-256으로 등록된 병렬 리뷰를 수행하고, 확인된 지적을 반영한다.
7. 각 완료 조건의 증거와 미확인 사항을 이 문서 및 작업 기록에 남긴다.

## done_when 확인 방법

| 완료 조건 | 확인 방법 |
|---|---|
| 아이 화면 제목줄 없음 | 아이 화면 캡처에서 상단 앱 제목줄이 없는지 본다. |
| 상태 표시줄 안전 영역 확보 | 세로 화면에서 콘텐츠가 상태 표시줄과 겹치지 않는지 확인한다. |
| 하단 오늘·시간표·내 보석·설정 접근 | 각 하단 항목이 보이고 눌러 해당 화면으로 이동하는지 확인한다. |
| 오늘 해 아이콘 | 오늘 탭의 아이콘이 해인지 화면에서 확인한다. |
| 관리자 PIN 및 뒤로 복귀 유지 | 설정 진입 시 PIN 게이트가 보이고, PIN 통과 후 뒤로 돌아오면 아이 화면으로 복귀하는지 확인한다. |
| 가로 주간 몰입 화면 이중 여백 없음 | 가로 주간 보기에서 메뉴가 숨겨지고 콘텐츠 가장자리에 중복된 안전 여백이 생기지 않는지 확인한다. |
| 버전 동시 갱신 | `app.json`, `package.json`, 존재하는 경우 `android/app/build.gradle`의 버전명과 Android 버전 코드가 정책에 맞게 함께 바뀌었는지 대조한다. |
| 전체 검사와 병렬 리뷰 | 전체 검사 결과와 동일 SHA 입력의 등록 critical-reviewer 및 backlog-explainer 실행·반영 근거를 확인한다. |
| 화면 확인 | 에뮬레이터 화면 근거와 필요한 기기 확인을 구분해 기록하고, 확인하지 않은 경우 미확인으로 남긴다. |

## 현재 확인 기록

- 과거 기준 입력은 `in_review`였으며 착수/갱신 로그는 2026-10-05 01:13:51.668Z와 01:20:57.630Z에 남아 있다. 최신 CLI 입력에서는 상태가 `done`이다.
- 제공된 작업 로그는 상단 제목 제거·하단 설정·오늘 해 아이콘·안전 영역 구현을 기록한다.
- 제공된 초기 로그에는 에뮬레이터 PIN/뒤로 복귀·한 줄 메뉴와 53 suites/324 tests 및 Android 빌드 결과가 있다. 최신 검사는 아래 54 suites/326 tests 기록으로 갱신한다.
- 위 로그는 최초 리뷰 반영 전과 가로 몰입 최종 점검 전의 중간 기록이다. 해당 시점의 진행 중 표기는 아래 최종 보완 근거로 갱신한다.
- 읽을 수 있는 현재 코드에서는 탭 레이아웃이 `headerShown: false`, 자체 하단 메뉴, `useSafeAreaInsets`, 몰입 모드 중 메뉴 및 여백 비활성화를 사용한다. 설정 경로는 `/manage`이고 `PinGate`를 포함한다. 이는 코드 구조 확인이며 P14의 최종 화면·리뷰 완료 증거를 대신하지 않는다.

## 확인 질문

- 별도의 기능 범위 질문은 기준 입력에 없다. 필요한 연결 실기기 검증은 수행하지 않아 에뮬레이터 결과와 구분한다.

## 화면 검증과 리뷰 보완

- 에뮬레이터에서 오늘의 해 아이콘과 네 하단 메뉴를 확인했다. `p14-today-final-stable.png`, `p14-timetable-bottom-settings.png`, `p14-gems-bottom-settings.png`는 `.tmp/`의 검증 캡처다. 실기기 설치·검증으로 간주하지 않는다.
- 설정 버튼으로 관리자 PIN 화면에 진입하고, PIN을 통과한 뒤 시간표 편집 영역이 표시되는 것을 확인했다. 관리자 데이터는 변경하지 않았다. `p14-settings-pin.png`, `p14-settings-unlocked.png`와 대응 XML에 기록했다. 뒤로 복귀와 탭 전환도 확인했다.
- 가로 주간 시간표에서 하단 메뉴가 숨겨지고 세로로 돌아오면 복구됐다. `p14-week-landscape-final.png`와 XML은 보완한 소스의 가로 화면이다. 에뮬레이터 회전 설정은 원래 값으로 복원했다.
- 최초 dispatcher 리뷰는 두 에이전트가 exit 0으로 완료했다. `.tmp/reviews/P14-236b9b159d64-1791163286040/`에 결과가 있다. 리뷰의 안전 여백 적용 시점 불일치를 반영해 상단·좌우 여백을 부모 탭 레이아웃 한 곳에서 일관되게 적용하고 시간표 자식의 중복 처리를 제거했다. 안정 상태뿐 아니라 전환 중에도 적용 주체가 하나다.
- 버전은 `1.45.2 / 108`로 갱신됐다. 최종 전체 검사와 보완 리뷰 결과는 아래 최신 기록을 따른다.

## 리뷰 지적 반영과 최종 에뮬레이터 확인

- 초기 dispatcher `.tmp/reviews/P14-236b9b159d64-1791163286040/`는 critical-reviewer와 backlog-explainer가 모두 exit 0으로 끝났다. critical-reviewer는 안전 영역 여백의 부모/자식 적용 시점 불일치 Medium 1건을 지적했고 Critical/High는 없었다.
- 수정에서는 상단·좌우 안전 여백을 부모 탭 레이아웃에서 한 곳이 일관되게 적용하도록 정리하고, 시간표 자식의 중복 여백 처리를 제거했다. 가로 전환의 안정 상태뿐 아니라 전환 중에도 적용 주체가 하나가 되도록 고쳤다.
- 최종 검사 `.tmp/p14-quality-final.log`: 54 suites/326 tests 및 전체 품질 검사 통과 (`QUALITY_CHECKS_OK`); Android debug build 성공 (1m10s). 앱 버전은 1.45.2 / 108이다.
- `.tmp/p14-today-final-stable.png`에서 날짜·해 아이콘·오늘/시간표/내 보석/설정 네 메뉴를 확인했다.
- 설정 PIN 진입은 `.tmp/p14-settings-pin.png`, PIN 통과 후 설정 화면은 `.tmp/p14-settings-unlocked.png` 및 XML로 확인했다. 뒤로 돌아간 뒤 각 탭 이동과 아이 화면 복귀도 확인했다. 편집 데이터는 변경하지 않았다.
- 최종 가로 주간 화면 `.tmp/p14-week-landscape-final.png` 및 XML에서 하단 메뉴 숨김과 안전 여백을 확인했다. 이전의 가로 화면 진행 중 기록은 이 최종 캡처와 검사 결과로 갱신한다.
- 최종 critical-reviewer는 확인된 Critical/High/Medium 지적이 없다고 보고했고, 초기 중복 여백 지적은 해결됐다. 최신 CLI 상태는 `done`이다.
- 실제 연결 실기기는 없었다. 캡처와 테스트는 에뮬레이터 근거이며 실기기 확인을 주장하지 않는다.
