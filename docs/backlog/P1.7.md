## 목적

새 릴리즈 서명 키를 만들고 안전하게 보관할 수 있는 설정을 준비하며, Doro의 빌드 방식을 참고한 `scripts/build-apk.ps1`을 제공한다. 릴리즈 APK를 서명해 딸 폰에 설치할 수 있게 한다.

## 쉬운 설명

앱을 실기기에 설치할 APK를 반복해서 만들고, 업데이트할 때 같은 서명 키를 사용할 수 있게 준비하는 작업이다. 서명 비밀번호와 키 파일은 공개하지 않는다.

## 구현 결과물

### 빌드 스크립트
- `scripts/build-apk.ps1`: 디버그/릴리즈 APK 생성 스크립트
- 파라미터: `-Debug`, `-Release`, `-Target Device|Emulator`
- 릴리즈 빌드 시 `android/release.properties`에서 키 경로·비밀번호 읽기
- 생성 결과: `TimeTable-v<version>-<mode>-<target>-<abi>.apk`

### 릴리즈 설정
- `android/release-keystore.jks`: 새 서명 키 파일 (`.gitignore`의 `android/*.jks`로 제외되어 저장소에 올라가지 않음, 이 PC에만 있음)
- `android/release.properties`: 릴리즈 설정 (git-ignore, 로컬 전용)
- 인증서 SHA-256: 설정에 기록, APK 설치 시 일치 확인
