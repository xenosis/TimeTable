## 목적

일정 칸에 표시하던 시작·종료 시각을 전부 맨 왼쪽 시간 칼럼에서 읽을 수 있게 옮긴다. 시간|월|화|수|목|금 헤더와 전체 일정의 실제 시작·종료 경계를 반영하는 시간축을 사용하며 일정 칸에는 시간 문자열을 표시하지 않는다. 요일마다 다른 시각과 겹침도 시간 칼럼과 행 경계로 정확하게 표현한다. 여기서 시간 문자열은 일정의 startTime/endTime으로 생성하는 시각 라벨을 뜻한다. 사용자가 제목·메모에 직접 입력한 자유문구는 임의로 삭제하거나 시간 데이터로 재해석하지 않는다.
