## 목적

일정 칸에 표시하던 시작·종료 시각을 전부 맨 왼쪽 시간 칼럼에서 읽을 수 있게 옮긴다. 시간|월|화|수|목|금 헤더와 전체 일정의 실제 시작·종료 경계를 반영하는 시간축을 사용하며 일정 칸에는 시간 문자열을 표시하지 않는다. 요일마다 다른 시각과 겹침도 시간 칼럼과 행 경계로 정확하게 표현한다. 여기서 시간 문자열은 일정의 startTime/endTime으로 생성하는 시각 라벨을 뜻한다. 사용자가 제목·메모에 직접 입력한 자유문구는 임의로 삭제하거나 시간 데이터로 재해석하지 않는다.

## 수행 순서

1. 주간표에 이미 있는 왼쪽 시간축을 조사해 재사용하고, `시간 | 월 | 화 | 수 | 목 | 금` 헤더 및 세로/가로 폭 정렬을 맞춘다.
2. 시간축에 전체 일정의 실제 시작·종료 경계를 반영하고, 일정 칸에는 startTime/endTime에서 생성되는 시각 라벨을 남기지 않는다. 요일별 시각 차이와 겹침도 시간 칼럼과 행 경계에 표현하며, 원본 시간 데이터는 바꾸지 않는다.
3. 병합·경계·겹침·무시각·메모/과목/아이콘·요일 글자 이동을 보존하고, 제목·메모의 사용자 자유문구는 임의 삭제/시간 재해석하지 않는지 비교한다.
4. PNG1~3 형태의 데이터에서 360/393dp 세로, 가로, 배율 1.0/1.3을 확인한다.

확인 시 계획서와 위 조건을 실제 화면·동작·검증 결과에 대조한다. 다른 요일의 현재 시각 기준 미리보기와 오늘 실제 진행 상태를 문구로 구분하며, 주간표는 오늘 실제 일정만 강조한다. 모든 일정의 startTime/endTime에서 생성되는 시작·종료 시각 라벨이 왼쪽 시간 칼럼과 행 경계에 정확히 반영되고 일정 칸 내부 라벨이 0개인지 확인한다. 제목·메모에 사용자가 입력한 자유문구는 임의로 삭제하거나 시간 데이터로 재해석하지 않는지도 확인한다. 사용자의 강조 기준에 대한 별도 응답이 구현 전에 도착하면 계획과 문서를 그 기준으로 조정한다. 개발 검증 전에는 문서화 완료와 기능 완료를 구분한다.
