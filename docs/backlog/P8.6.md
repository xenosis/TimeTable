- 문서 상태: 초안 갱신. P8.5의 저장소 계층을 바탕으로 관리자(아빠) 화면에 시간표 세트 관리 UI를 추가한다.

## 목적

아빠(관리자)가 PIN을 입력해 접근하는 관리 화면에서 여러 시간표 세트를 만들고, 이름을 바꾸고, 복제하고, 삭제하며, 현재 사용 중인 세트를 전환할 수 있게 한다. 세트를 "적용"하면 앱 전체(오늘 화면, 시간표 화면, 알림 예약)가 새 세트의 일정으로 즉시 업데이트된다.

## 쉬운 설명

관리 화면에 "시간표 세트" 섹션이 새로 생긴다. 현재 적용 중인 세트(예: "평소")가 강조 표시되고, 그 옆에 "적용 중" 레이블이 붙는다. 아래에는 다른 세트 목록(예: "방학", "겨울 특강")이 나열된다. 각 세트 오른쪽에는 3개 버튼이 있다:

- **복제**: 그 세트를 카피해 새 세트 만들기 (이름 입력 팝업)
- **이름 변경**: 세트 이름 수정 (이름 입력 팝업)
- **삭제**: 세트 제거 (확인 팝업, 적용 중인 세트는 버튼 비활성)

세트를 탭하면 그 세트가 "적용"되고, 앱이 즉시 그 일정으로 전환된다 (오늘 화면, 시간표, 알림이 모두 새 세트로 갱신).

맨 위에는 **"새 세트 만들기"** 버튼이 있어서 빈 세트를 새로 만들거나, 현재 세트를 복제한 뒤 편집할 수 있다.

## 필요한 입력

- P8.5에서 구현한 저장소 함수들
  - `createTimetableSet`, `duplicateTimetableSet`, `renameTimetableSet`, `deleteTimetableSet`
  - `getActiveTimetableSet`, `setActiveTimetableSet`, `listTimetableSets`
- 현재 관리 화면 구조 (`app/manage.tsx`)
  - 기존 PIN 보호, 설정 UI, 시간표 편집 화면
- Zustand 또는 React Context로 관리되는 앱 상태
  - 현재 적용 중인 시간표 세트 ID
- 알림 재등록 로직 (P8.5 이후)
  - `reScheduleNotifications(setId: string)`: 새 세트 적용 시 예약 알림 갱신

## done_when 확인 방법

완료 기준을 다음 근거로 대조한다.

- `app/manage.tsx`에 "시간표 세트 관리" 섹션이 추가되었다.
- 관리 화면에서 세트 목록이 렌더링되고, 현재 적용 중인 세트에 "적용 중" 배지가 표시된다.
- "새 세트 만들기" 버튼 탭 → 모달 표시 → 이름 입력 → 세트 생성 확인.
- 각 세트의 복제 버튼 탭 → 모달 표시 → 이름 입력 → 새 세트 생성 확인.
- 각 세트의 이름 변경 버튼 탭 → 모달 표시 → 새 이름 입력 → 이름 변경 확인.
- 각 세트의 삭제 버튼 탭 → 확인 팝업 → 삭제 확인. 적용 중인 세트의 삭제 버튼은 비활성화되어 있다.
- 세트 항목 탭 → `getActiveTimetableSet()` 결과가 변경되어 새 세트가 "적용 중"으로 표시된다.
- 세트 적용 직후 오늘 화면이 새 세트의 일정으로 갱신된다 (예: "다음 일정" 정보).
- 세트 적용 직후 시간표 화면이 새 세트의 월~금 일정으로 갱신된다.

## 확인 절차 (실기기 수동 테스트)

P8.5 완료 후 실기기에서 P8.6 완료 조건과 함께 다음 순서로 확인한다:

**① 한 세트에서 만든 항목이 다른 세트의 오늘·주간·편집 목록에 보이지 않음**
- 관리 화면에서 "평소" 세트를 적용하고 월요일 항목 1개를 만든다.
- "겨울방학" 세트로 전환하고, 오늘이 월요일이면 방금 만든 평소 항목이 보이지 않는지 확인한다.
- 주간 보기와 편집 목록에서도 확인한다.

**② 한 세트를 수정한 뒤 다른 세트로 돌아가도 원래 항목이 그대로임**
- "평소" 세트에서 기존 항목을 수정한다.
- "겨울방학" 세트로 전환했다가 "평소"로 돌아간다.
- 수정한 항목이 그 수정 상태로 유지되는지 확인한다.

**③ 요일 복사는 적용 중인 세트 안에서만 대상 요일이 바뀜**
- "평소" 세트에서 월요일 항목을 생성한다.
- 월요일에서 화요일로 복사한다.
- 적용 중인 세트("평소")의 화요일만 월요일 항목이 복사되었는지 확인한다.
- "겨울방학" 세트로 전환하고, 화요일에 기존에 있던 항목만 있는지 확인한다(복사된 항목 없음).

**④ 앱을 완전히 닫았다 열어도 마지막 적용 세트가 유지됨**
- 관리 화면에서 "겨울방학" 세트를 적용한다.
- 앱을 완전히 닫는다 (백그라운드 종료).
- 앱을 다시 열어 적용 중인 세트가 여전히 "겨울방학"인지 확인한다.

필요시 알림이 새 세트 일정으로 재등록된다 (P8.5에서 정의한 로직 확인).
관리 화면이 세로·가로 모두에서 깨지거나 스크롤 불가능하지 않다.
`__tests__/TimetableSetManagement.test.tsx`에 세트 생성, 이름 변경, 복제, 삭제, 적용, 버튼 비활성화 테스트가 있고 모두 통과한다.
`npm run check`가 통과했다(지침, 코드 길이, lint, typecheck, Jest, Android debug build).
