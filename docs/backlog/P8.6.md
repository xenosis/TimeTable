- 문서화 상태: 완료 결과 반영

## 목적

아빠(관리자)가 PIN을 입력해 접근하는 관리 화면에서 여러 시간표 세트를 만들고, 이름을 바꾸고, 복제하고, 삭제하며, 현재 사용 중인 세트를 전환할 수 있게 한다. 세트를 "적용"하면 앱 전체(오늘 화면, 시간표 화면, 알림 예약)가 새 세트의 일정으로 즉시 업데이트된다.

## 쉬운 설명

관리 화면에 "시간표 세트" 섹션이 새로 생긴다. 현재 적용 중인 세트(예: "평소")가 강조 표시되고, 그 옆에 "적용 중" 레이블이 붙는다. 아래에는 다른 세트 목록(예: "방학", "겨울 특강")이 나열된다. 각 세트 오른쪽에는 버튼이 있어서 복제, 이름 변경, 삭제, 적용을 할 수 있다.

## 완료 기준 검증

✓ **관리 화면 컴포넌트 (TimetableSetPanel)**

- 세트 목록 표시, 현재 적용 중인 세트에 "적용 중" 배지 표시

✓ **세트 생성·복제·이름변경·삭제 UI**
- TimetableSetRow: 각 세트 항목

- 이름 변경 입력 폼
- 삭제 확인 절차 (2단계 확인)

✓ **세트 적용 기능**

✓ **확인 절차 (에뮬레이터)**
