# P6.16 — 아빠 원격 관리 추가 검증

## 기준 입력

- Schema version: 1.1
- SHA-256: 34d737010653c0eef51542eaa4d816b2e5b79f4da3c692bbc692b78821c6eec6
- 입력 크기: 442641 bytes
- 기준 시각: 2026-10-07T18:11:48.116Z
- 작업 상태: needs_info; owner codex; updated_at 2026-10-07T16:04:20.589Z

## 목적과 쉬운 설명
P6.8에 추가된 원격 지급과 기기 역할 정책을 실제 두 기기에서 확인한다. 화면 구현·단위 테스트 통과와 실제 아빠 계정 검증을 구분한다. 이 하위 작업이 남아 있는 동안 P6.8을 완료로 기록하지 않는다.

## 필요한 입력과 선행 작업
- P6.6·P6.7 완료.
- 아빠 계정으로 로그인한 기기. 비밀번호는 사용자가 입력하며 에이전트는 읽거나 기록하지 않는다.
- 기존 행 동시 편집에서 마지막 저장을 우선하는 현 정책의 수용 여부는 아직 미확정이다.

## 결과물과 수행 순서
1. 아빠 편집이 딸 폰에 내려오고 딸 완료 체크가 아빠 현황에 나타나는지 확인한다.
2. 아빠의 지급 기록이 딸 폰 지급 상태에 반영되고 보석 장부 수량은 바뀌지 않는지 확인한다.
3. 아빠 기기 로그아웃·재시작 후 딸 일정 예약 차단 유지와 딸 로그인 시 허용을 확인한다. 사용자 지시 없이 딸 폰의 추가 알람 발생 테스트를 재개하지 않는다.
4. 동시 편집 정책, 실제 관찰 근거와 전체 검사·등록 병렬 리뷰를 기록한다.

## 완료 조건 확인
위 네 항목의 코드·자동 시험·실기기 근거를 구분해 모두 대조한다. 아빠 로그인 기기가 준비되지 않아 현재는 needs_info이며 완료 근거가 없다.
