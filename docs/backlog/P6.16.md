## 목적과 쉬운 설명
P6.8에 추가된 원격 지급과 기기 역할 정책을 실제 두 기기에서 확인한다. 화면 구현·단위 테스트 통과와 실제 아빠 계정 검증을 구분한다. 이 하위 작업이 남아 있는 동안 P6.8을 완료로 기록하지 않는다.

## 필요한 입력과 선행 작업
- P6.6·P6.7 완료.
- 아빠 계정으로 로그인한 기기. 비밀번호는 사용자가 입력하며 에이전트는 읽거나 기록하지 않는다.
- 사용자 결정(2026-10-09): 같은 항목의 동시 편집은 가장 늦게 저장한 입력으로 덮어쓴다. P6.16의 2026-10-08T16:13:14.521Z 로그에 수용 근거가 있다. gate의 예전 미확정 문구와 이 결정 로그를 구분한다.

## 결과물과 수행 순서
1. 아빠 편집이 딸 폰에 내려오고 딸 완료 체크가 아빠 현황에 나타나는지 확인한다.
2. 아빠의 지급 기록이 딸 폰 지급 상태에 반영되고 보석 장부 수량은 바뀌지 않는지 확인한다.
3. 아빠 기기 로그아웃·재시작 후 딸 일정 예약 차단 유지와 딸 로그인 시 허용을 확인한다. 사용자 지시 없이 딸 폰의 추가 알람 발생 테스트를 재개하지 않는다.
4. 동시 편집 정책, 실제 관찰 근거와 전체 검사·등록 병렬 리뷰를 기록한다.
