## 목적

스티커 적립과 회수 로직, 연속 달성 계산의 순수 함수들이 모든 경계값과 시나리오에서 정확하게 작동하는지 자동 테스트로 보증한다.

## 쉬운 설명

"이 코드가 실제로 완료/취소/연속 계산을 정확하게 하나?" 확인하는 검사다. 여러 가지 상황(할 일 없는 날, 연속 끊김, 동시에 여러 보상 등)을 테스트한다.

## 필요한 입력

- P4.6 스티커 적립 로직 (`rewardRepository.ts`, `stickerRepository.ts`)
- P4.9 연속 달성 계산 (`src/utils/streak.ts`)
- SQLite 실제 DB 쿼리와 트랜잭션 동작
- 할 일 없는 날(일요일 등) 포함 주간·월간 계산 정책
- 보상 달성 시 보석 소멸(재계산) 정책

## 결과물

- `__tests__/reward-repository.test.ts`: SQLite 실제 동작 검증 (할 일 없는 날, 소멸, 우선순위 등)
- `__tests__/reward-policy.test.ts`: 보상 정책 순수 함수 테스트
- `__tests__/streak.test.ts`: 연속 일수 계산 경계값 테스트
- Jest 99개 이상의 테스트 통과

## 선행 작업

- 직접 의존성: `P4.6` (스티커 적립/회수), `P4.9` (연속 달성 계산)
- `P4.2`(로컬 DB), `P4.4`(완료/취소 흐름)는 기준 입력에서 `done`

## 수행 순서

1. 기존 보상·연속 계산 테스트 파일과 각 순수 함수를 확인한다
2. critical-reviewer에서 지적한 경계값을 정확히 파악한다
3. 각 경계값별 테스트 케이스를 설계한다
4. SQLite 실제 DB에서 트랜잭션·쿼리를 검증하는 테스트를 추가한다
5. Jest 실행 및 `npm run check` 통과를 확인한다
