# P4.10 — 단위 테스트: 스티커 계산 · 연속 달성 계산

## 기준
- 백로그 schema: 1.1
- 백로그 sha256: 86894def7f03d9e5155fca3e3ecfbd1a32bb7f6fda8dc9cb25145da30a139496
- 백로그 bytes: 51194
- 개발 상태: todo
- 문서화 상태: 작성됨

## 작업 목적
스티커 적립/회수와 연속 달성 계산의 순수 함수 테스트를 작성한다.

## 쉬운 설명
쉽게 말해, 단위 테스트: 스티커 계산 · 연속 달성 계산을 백로그 범위 안에서 수행하는 작업이다.

## 필요한 입력
기준 백로그 항목 P4.10와 관련 요구사항 문서를 확인한다. 구체값은 백로그에 명시된 것만 사용한다.

## 결과물
관련 테스트가 통과함

## 선행 작업
백로그에 기록된 상위 작업과 deps 완료 결과를 확인한다. 이 항목에 명시되지 않은 선행 작업은 추정하지 않는다.

## 수행 순서
1. 요구사항과 백로그 범위를 확인한다.
2. 필요한 입력과 선행 작업 결과를 준비한다.
3. 단위 테스트: 스티커 계산 · 연속 달성 계산 범위만 수행하고 결과 또는 확인 기록을 남긴다.
4. done_when을 확인한다.
5. 개발 완료와 문서화 완료를 각각 기록한다.

## done_when 확인 방법
관련 테스트가 통과함 조건을 결과와 대조하고 재현 가능한 근거를 남긴다. 추가 완료 기준은 만들지 않는다.

## 확인 질문
백로그에 없는 세부 구현값이나 운영 조건이 필요하면 어떤 값으로 결정할지 확인이 필요하다.
