# P6.17 — 변경 푸시 외부 설정과 실기기 수신 확인

## 기준 입력

- Schema version: `1.1`
- SHA-256: `b677bb3b2e9880ff7346b50d9f56100156cc16b9dc03a1a8a03562ff8c6c5a1a`
- 입력 크기: `444940` bytes
- 기준 시각: `2026-10-07T19:05:42.945Z`
- 기준 상태: `needs_info`

## 목적

Firebase·Expo·FCM 설정과 서버 발송 작업자 배포 뒤 딸 폰의 실제 변경 알림 표시 및 탭 후 최신 내용 확인

## 완료 조건

외부 설정 및 배포가 승인·완료되고, 서버 시간표 변경 후 딸 폰에서 보이는 알림 도착과 탭 후 최신 내용 적용을 직접 확인한다.

## 남은 입력

Google 인증 화면 접근은 자동 승인 검토에서 거절되어 명시 승인 필요. Firebase·Expo 자격 준비와 함수·발송 작업자 배포 승인, 두 기기의 계정 로그인 및 실수신 확인 필요.

## 개발과 구분

부모 작업 P6.9의 로컬 개발은 계속 진행한다. 함수 접수 응답이나 자동 검사 통과를 실제 알림 도착 근거로 사용하지 않는다. 패키지 이름 변경은 기존 사용자 결정대로 P7에서 진행한다.
