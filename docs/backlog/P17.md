# P17: 아빠 화면에 시간표 탭 추가

**기준:** schema 1.1 · SHA-256 `ba79e9522ee53efa1c4f4e0d3cdd387ff4d6404e9654e4203b547197719f13d6`  
**상태:** in_review  
**담당:** claude  
**gate:** 없음  
**문서 성격:** 문서화 완료 (개발 작업 완료 아님 — 리뷰 반영 후 `done` 처리 대기)

---

## 목적

아빠 폰(부모 계정)에는 원래 현황과 주간 리포트만 있어 딸의 시간표를 볼 수 없었습니다. 다음 두 가지를 만족하도록 합니다.

1. 아빠 화면 하단에 **현황 · 시간표 · 설정** 탭을 둔다. 시간표 탭은 딸 화면과 같은 요일별 · 주간 한눈에 보기 시간표를 보여 준다.
2. (2026-10-18 추가 요청) 설정 화면에서도 하단 탭바가 유지되도록 설정을 탭 그룹으로 옮기고, 아빠 폰은 설정을 PIN 없이 연다.

보석 탭은 딸 화면에만 둡니다. 딸 기기의 PIN과 탭 구성은 바꾸지 않습니다.

(요청 기록: 2026-10-16 사용자 요청 / 2026-10-18 추가 요청)

---

## 쉬운 설명

아빠 폰 아래쪽 메뉴에 "시간표" 버튼이 생겼습니다. 누르면 딸이 어떤 요일에 무슨 수업이 있는지 바로 볼 수 있습니다. 화면 모양은 딸이 보는 시간표와 같습니다.

설정 버튼을 누르면 설정 화면에서도 아래 메뉴가 그대로 보입니다. 아빠 폰은 설정을 열 때 PIN을 묻지 않고, 딸 폰은 기존처럼 PIN을 묻습니다.

아빠 폰 화면이 현황 ↔ 시간표 ↔ 설정을 오갈 때 앱이 멈추던 문제(Maximum update depth 크래시)는 v1.64.1에서 고쳤습니다. 레이아웃이 항상 같은 화면 틀을 유지하도록 바꿨습니다.

## 수행 순서

1. 아빠 기기 여부를 판단해 하단 탭 구성을 나눈다.
   - 아빠 기기: 현황(`/`), 시간표(`/timetable`), 설정 버튼
   - 딸 기기: 기존 탭 구성 그대로 (보석 탭 포함)
2. `/timetable` 외 경로에서는 아빠 기기에 `ParentHome`을 같은 자리에 그린다.
3. `/timetable`에서는 기존 시간표 화면을 그대로 보여 준다 (요일별 · 주간 한눈에 보기).
4. 설정 화면을 탭 그룹(`app/(tabs)/manage.tsx`)으로 옮겨 설정에서도 하단 탭바가 보이게 한다.
5. 아빠 기기는 `PinGate`를 bypass해 설정을 PIN 없이 열고, 딸 기기는 PIN을 유지한다.
6. 탭 전환은 모두 `router.replace`로 처리해 Slot 재마운트로 인한 크래시를 막는다.
7. 버전을 `app.json` / `package.json` / `android/app/build.gradle`에서 동시에 올린다 (1차 minor 1.64.0, 2차 patch 1.64.1).
8. `npm run check` 전체 검사를 수행한다 (v1.64.1 기준 7개 항목 PASS).
9. 아빠 폰 실기기(SM-S918N)에서 release APK로 현황 · 시간표 · 설정을 3회 순환해 크래시 여부를 확인한다 (완료).

## 한계와 제약

- 이 문서는 **문서화 완료**이며, 개발 작업 완료는 재리뷰 반영과 `done` 기록 뒤에 판단합니다.
- 이 문서 작성 환경에서는 Bash 도구를 사용할 수 없어 `npm run backlog -- get P17 --json`으로 SHA-256을 재조회하지 못했습니다. 위 기준 SHA-256 `ba79e952…13d6`, schema 1.1, in_review, owner claude, gate 없음은 요청 메시지로 받은 값입니다. 다음 갱신 때 CLI로 대조해야 합니다.
- 이전 버전 문서의 기준 SHA-256 `927602…117f`는 v1.64.0 시점 값으로, 이 문서가 대체합니다.
- 백로그 JSON의 `done` 전이와 SHA-256 갱신은 메인 에이전트가 CLI로 수행해야 하며, 이 문서 작성 과정에서 JSON은 변경하지 않았습니다.
- 아빠 기기에서 시간표 탭을 열었을 때 동기화 전 데이터가 비어 있는 경우의 표시는 요구사항에 명시되어 있지 않아 확인하지 않았습니다.
