# P17: 아빠 화면에 시간표 탭 추가

**기준:** schema 1.1 · SHA-256 `5f301a5aa6ad18fa8aa363af3da4bf87e4c1970f0669b9aa61a1d2d43a21a3dd`  
**상태:** in_review  
**담당:** claude

---

## 목적

아빠 폰(부모 계정)에서는 현황과 주간 리포트만 볼 수 있어 딸의 시간표를 확인할 수 없었습니다. 아빠 화면 하단에 **현황 · 시간표 · 설정** 탭을 두고, 시간표 탭에서 딸 화면과 같은 시간표를 보게 합니다. 보석 탭은 딸 화면에만 둡니다.

(요청 기록: 2026-10-16 사용자 요청)

---

## 쉬운 설명

아빠 폰 아래쪽 메뉴에 "시간표" 버튼을 추가해서, 아빠도 딸이 어떤 요일에 무슨 수업이 있는지 바로 볼 수 있게 합니다. 화면은 딸이 보는 시간표와 같은 모양(요일별 · 주간 한눈에 보기)입니다. 딸 폰의 메뉴는 바뀌지 않습니다.

---

## 필요한 입력

- 탭 구성: `app/(tabs)/_layout.tsx`
- 아빠 화면: `src/components/ParentHome.tsx`
- 시간표 화면: 기존 `timetable` 화면 (재사용)
- 기준 요구사항: 작업 요약의 done_when (아빠 기기 탭 구성, 딸 기기 탭 구성 불변, 버전 동시 수정, `npm run check` 통과)

1. 아빠 기기 여부를 판단해 하단 탭 구성을 나눈다.
   - 아빠 기기: 현황(`/`), 시간표(`/timetable`), 설정 버튼

3. `/timetable`에서는 기존 시간표 화면을 그대로 보여 준다 (요일별 · 주간 한눈에 보기).
4. 버전을 `app.json` / `package.json` / `android/app/build.gradle`에서 동시에 올린다 (minor, 1.64.0 / versionCode 186).
5. `npm run check` 전체 검사를 수행한다.
6. 아빠 폰 실기기에서 탭 표시와 시간표 탭 내용을 확인한다 (남은 확인).
