# P2.1 — 결정(D5): 시간표 범위

## 기준 입력

- 백로그 schema version: `1.1`
- 백로그 SHA-256: `de2559bc8bf037d9a28276b9343e6500e8780551c21551f2a828052b22a761a6`
- 기준 백로그 경로: `C:\Users\Lenovo\claudeProjects\TimeTable\backlog.json`
- 기준 입력 크기: `54315` bytes
- 기준 입력 수정 시각: `2026-09-15T23:32:29.323Z`
- 기준 작업: `P2.1`
- 현재 상태: `in_review`
- 담당: `codex`
- 상위 작업: `P2`

이 문서는 위 SHA-256의 백로그 입력과 stdin으로 전달된 P2.1 레코드만 기준으로 작성했다. 원본 `backlog.json`은 이 실행에서 읽거나 수정하지 않는다.

## 목적

시간표에 포함할 일정의 범위를 결정한다. 학교 시간표만 지원할지, 학원과 생활 일정까지 포함할지를 확정해 이후 로컬 시간표 설계의 기준으로 삼는다.

## 쉬운 설명

앱의 시간표에 어떤 종류의 일정을 넣을지 정하는 작업이다. 이번 결정에서는 학교 수업뿐 아니라 학원과 생활 일정도 모두 넣을 수 있도록 범위를 정한다.

## 필요한 입력

- P2.1의 작업 요약: 학교 시간표와 학원·생활 일정의 포함 여부 결정
- D5에 대한 사용자 결정
- 관련 요구사항: `docs/tasks.md` 2-1은 학교만 포함할지 학원·생활 일정을 포함할지 결정하도록 한다.
- 관련 설계 근거: `docs/research.md`의 `timetable_items.category`는 학교·학원·생활 범주를 구분한다.
- 완료 기준: `D5 결정 기록`

백로그 입력에 없는 일정의 세부 분류, 화면 방식, 데이터 구조 또는 운영 규칙은 이 작업에서 임의로 정하지 않는다.

## 결과물

- D5 결정 기록: 시간표 범위에 학교·학원·생활 일정을 모두 포함
- 후속 작업(P2.2 이후)에서 사용할 범위 결정의 확인 기록
- 이 문서의 현재 확인 기록

## 선행 작업

- `deps`가 빈 배열이므로 지정된 선행 작업은 없다.
- P2.1은 P2의 하위 작업이다.

## 수행 순서

1. 기준 입력에서 P2.1의 요약과 `done_when`을 확인한다.
2. 학교·학원·생활 일정의 포함 여부에 대한 사용자 결정을 확인한다.
3. 결정 결과를 D5 기록으로 남긴다.
4. 기록이 `D5 결정 기록` 조건을 충족하는지 대조한다.
5. 결정 기록과 현재 검토 상태를 이 문서에 정리한다.

## done_when 확인 방법

`done_when`은 `D5 결정 기록`이다. 따라서 학교·학원·생활 일정의 포함 범위가 하나의 결정으로 명시되어 기록되어 있는지 확인한다. 구현, 화면, 데이터베이스 검증은 이 작업의 완료 조건에 포함되지 않는다.

## 현재 확인 기록

- 기준 입력의 P2.1 레코드에서 상태 `in_review`, 담당 `codex`, `deps: []`, `done_when: D5 결정 기록`을 확인했다.
- `docs/tasks.md` 2-1의 요구사항이 학교만 포함할지 학원·생활 일정을 포함할지 결정하는 것임을 확인했다.
- `docs/research.md` 8장의 `timetable_items.category`가 학교·학원·생활 범주를 구분하므로, 세 범주를 포함한다는 결정과 모순되지 않음을 확인했다.
- `2026-09-15T23:32:19.412Z`: 사용자 결정 기록을 시작했으며, 학교·학원·생활 일정 전체를 시간표 범위에 포함한다고 기록했다.
- `2026-09-15T23:32:29.317Z`: D5 결정을 확정했다. 결정 내용은 학교·학원·생활 일정 모두 포함이며, `D5 결정 기록` 조건을 충족한 것으로 기록되어 현재 `in_review` 상태다.
- 따라서 현재 문서 기준으로 `done_when` 충족 근거는 존재하지만, 최종 상태 변경은 이 실행의 메인 검토 절차에서 판단한다.

## 확인 질문

- 백로그에 명시되지 않은 세부 일정 분류나 우선순위가 필요해질 경우, 어떤 기준을 적용할지 별도 결정이 필요하다.
- 학교·학원·생활 일정의 세부 입력 필드, 화면 표시 방식, 일정 간 충돌 규칙은 P2.1의 완료 조건에 없으므로 후속 요구사항 또는 별도 결정이 필요하다.
