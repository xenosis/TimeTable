## 목적

PIN 뒤 시간표·할 일·보상·기타 한 줄 메뉴를 두고 선택 영역만 표시한다. 기본은 시간표. 교시·요일 복사와 진단·미리보기는 필요할 때 열고 영역/세트 이동 중 미저장 폼 버림 확인을 공통으로 둔다. 상단 알림 준비는 네 권한 모두 허용 시 기본 접힘, 부족/확인 실패 시 재표시한다. 기기 검증용 일반 알림·재부팅 복구·잠금 화면 알람 테스트와 설명/결과는 기본 화면에서 빼고 PIN 뒤 기타→기기 테스트의 접힌 영역으로 이동한다.

## 쉬운 설명

관리자 기본 화면에는 일상 편집에 필요한 선택 영역만 둔다. 상단 알림 준비는 네 권한이 모두 허용되면 접혀 있고, 필요한 경우 작은 버튼으로 직접 펼친다. 기기 검증용 1분 일반 알림, 3분 뒤 재부팅 복구, 15초 잠금 화면 알람 테스트는 PIN 뒤 기타 → 기기 테스트에서 필요할 때 연다. 메뉴 진입이나 영역 펼치기만으로 알림·알람은 예약되지 않는다. 앱 코드 구현은 완료되었으나 기능 동작은 아직 사용자와 함께 확인하지 않았다.

## 1단계: 관리자 메뉴 및 접기 구현 확인

1. PIN 뒤에 시간표·할 일·보상·기타 한 줄 메뉴를 두고 기본 진입은 시간표로 구성한다.
   - AdminSectionMenu 컴포넌트로 구현 완료

2. 교시 설정·요일 복사, 보상 목표, PIN, 관리자 권한 안내, 진단을 필요할 때 여는 보조 영역으로 연결하고 관리자 전용 크기를 실제 적용한다.
   - AdminCollapsible로 접기 기능 구현
   - 해당 영역 크기 기준 적용 대기(일괄 화면 검증)

3. 알림·정확한 알람·전체 화면 알림·배터리 최적화 예외를 조회한다. 모두 허용이면 상세를 기본 접힘으로 두고 작은 수동 열기 경로를 제공한다. 권한 부족이나 상태 조회 실패 시에는 안내를 표시하며 조회 실패를 허용 완료로 간주하지 않는다.
   - PermissionGuide에 collapseWhenReady 적용

4. 초기 확인 전 허용 완료로 단정하지 않는다. 관리자 재진입과 설정에서 돌아올 때 상태를 다시 읽고, 접힌 동안에도 갱신 리스너를 유지해 권한 해제 시 안내가 다시 보이게 한다.
   - 구현 완료, 화면 동작 확인 대기

5. PIN 보호·백그라운드 재잠금·미저장 폼 전환 확인·저장 중 전환 차단을 확인한다.
   - adminSections.decideSectionSwitch로 구현 완료

## 확인 방법: 관리자 기본 화면에서 영역 메뉴와 접힌 편집 폼을 보고 보조 영역의 접근 경로 및 관리자 전용 크기를 확인한다. 네 권한 모두 허용 시 상단 알림 준비 상세가 기본 접힘이며 작은 수동 열기 버튼으로 펼쳐지는지 확인한다. 권한 부족 또는 조회 실패 시 안내가 표시되고, 설정 복귀/관리자 재진입에서 상태가 갱신되며 접힌 동안에도 리스너가 유지되는지 확인한다. 기본 관리자 화면에 1분 일반 알림·3분 재부팅 복구·15초 잠금 화면 알람 테스트 버튼, 설명, 결과, 체크리스트가 보이지 않는지 확인하고 PIN 뒤 기타 → 기기 테스트를 명시적으로 펼쳐 접근한다. 진입/펼치기만으로 예약되지 않고 기존 기능, 권한 확인, 중복 예약 방지, 오류/결과 표시가 유지되는지 확인한다. PIN 보호와 전환 확인 동작도 대조한다. **화면 검증은 미확인(일괄 확인 예정)**.
