## 목적

앱 화면이 없는 주기 백그라운드 작업에서도 저장된 계정을 안전하게 복원해 가족 서버 데이터를 동기화하고, 로컬 알림과 위젯을 갱신한다. 오프라인·서버 실패 때 기존 로컬 데이터와 알림 예약을 보존하고, 사용자의 로그아웃·계정 변경 뒤 늦게 끝난 복원이 새 상태를 덮지 않도록 한다.

## 쉬운 설명

앱을 열지 않아도 정기 작업이 서버의 최신 시간표와 할 일을 가져와 폰의 알림·위젯을 맞춘다. 인터넷이 끊겼으면 이미 있던 내용을 지키고, 작업 도중 로그아웃했다면 이전 계정 정보를 뒤늦게 적용하지 않는다.

## 수행 순서

1. 주기 작업 진입 때 현재 로컬 내용으로 알림 예약을 시도한다. 이 시도의 실패는 기록하되 가족 동기화를 막지 않는다.
2. 계정 상태와 사용자 변경 세대를 확인한다. 로그아웃·계정 변경이 진행 중이면 저장 계정 복원을 시작하지 않는다.
3. 필요한 경우 계정을 복원하고, 복원 중 사용자 변경이 있었다면 늦은 결과를 폐기한다.
4. 유효한 계정으로 서버 데이터를 SQLite에 반영한다. 서버 실패 시 기존 로컬 데이터는 보존하고 해당 내용으로 예약을 다시 시도한다.
5. 서버 반영 성공 시 최신 로컬 데이터로 알림을 재예약하고 위젯을 갱신한다. 예약 등 부가 갱신 오류를 모아 최종 작업 결과에 반영한다.
6. 작업의 성공·실패를 OS에 반환한다. 서버 POST가 끝나지 않을 때 작업 종료가 보장된다고 주장하지 않는다.
7. 자동 검증·전체 검사·등록 리뷰 근거를 확인하고, 딸 폰에서 프로세스가 없는 상태의 실제 주기 실행을 확인한다.

- 예약 권한 오류가 동기화를 막지 않고 최종 결과에는 실패로 반영되는지 확인한다.
