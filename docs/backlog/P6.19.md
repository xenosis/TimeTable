## 목적

## 수행 순서

1. 백그라운드 진입 때 기존 로컬 내용으로 알림 예약을 먼저 시도하고, 실패는 기록하되 서버 동기화를 막지 않는다.
2. 현재 계정 상태와 사용자 변경 세대를 확인한다. 로그아웃·계정 변경이 진행 중이면 저장 계정 복원을 시작하지 않는다.
3. 로그인이 필요하면 저장된 계정을 복원한다. 복원 전후 사용자 변경 세대가 달라졌으면 결과를 적용하지 않는다.
4. 유효한 계정이면 가족 서버 데이터를 SQLite에 동기화한다. 서버 오류 때 기존 로컬 데이터를 보존하고 그 내용으로 알림 예약을 다시 시도한다.
5. 서버 동기화가 성공하면 최신 로컬 데이터로 알림을 재예약하고 위젯을 갱신한다. 예약 권한 오류 등 일부 갱신 실패는 모으되 서버 동기화는 계속하며 최종 작업 결과에 실패를 반영한다.
6. OS 주기 작업에 성공·실패를 반환한다. 선행 로컬 예약 시도는 끝나지 않는 서버 요청이 작업 자체를 반드시 종료시킨다는 보장이 아니다.
7. 자동 검증·전체 검사·등록 리뷰 근거를 확인한 뒤, 딸 폰에서 프로세스 종료 상태의 실제 주기 작업으로 임시 서버 변경 반영을 기록한다.
