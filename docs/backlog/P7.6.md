# P7.6 — 배포 직전: 서명 키 외부 백업

## 기준 입력

- 백로그 schema version: `1.1`
- 백로그 SHA-256: 최신 상태 기준
- 기준 항목: `P7.6`
- 백로그 상태: `todo`
- 우선순위: P2 (배포 직전 필수)
- 부모 작업: P7 (7단계: 배포)
- 선행 작업: P1.7 (빌드 준비: 서명 키 · APK 빌드 스크립트)

## 목적

릴리즈 APK 서명 키(키스토어 파일과 비밀번호)를 PC 밖 안전한 곳(USB·개인 클라우드 등)에 한 부 더 보관한다. 키를 잃으면 딸 폰의 앱을 같은 서명으로 업데이트할 수 없어 앱을 지우고 다시 설치해야 하고, 그러면 폰에 저장된 시간표·할 일·보석 기록이 사라진다.

## 쉬운 설명

앱이 완성되고 실제 배포를 준비할 때, 서명 키 파일과 비밀번호를 별도로 안전하게 보관하는 작업이다. PC가 고장나거나 파일이 손상되어도 키를 복구할 수 있도록 보험을 드는 것이다. 2026-09-30 사용자 결정으로, 앱이 완성된 뒤(배포 직전)로 미루어지게 되었다.

## 필요한 입력

- P1.7에서 생성한 릴리즈 서명 키 파일
  - `android/release-keystore.jks` (키스토어 파일)
  - `android/release.properties` (릴리즈 설정, 비밀번호 포함)
- 외부 백업 위치 결정
  - USB 드라이브
  - 개인 클라우드 스토리지 (Google Drive, One Drive 등)
  - 기타 보안 저장소

## 결과물

- 서명 키 파일과 비밀번호가 PC 밖 두 곳 이상에 보관됨
- 백업 위치 및 접근 방법 기록 (키 내용·비밀번호 자체는 기록하지 않음)
- 백업 복구 확인 (선택사항: 실제 복구 테스트)

## 완료 기준

완료 조건: 서명 키 파일과 비밀번호가 PC 밖 두 곳 이상에 보관됨이 사용자 확인으로 기록됨(키 내용·비밀번호 자체는 기록하지 않음).

## 수행 순서

1. P1.7이 완료되었는지 확인한다 (서명 키 생성, APK 빌드 스크립트).
2. 현재 PC의 `android/release-keystore.jks`와 `android/release.properties` 파일이 존재하는지 확인한다.
3. 외부 백업 위치를 결정한다 (USB, 클라우드, 기타).
4. 두 파일을 선택한 위치로 복사한다 (**비밀번호를 노출하지 않도록 주의**).
5. 백업 복사 완료를 사용자가 확인한다.
6. 필요시 백업에서 파일을 읽어 동작하는지 테스트한다 (선택사항).
7. 메인 에이전트가 이 작업의 상태를 done으로 변경한다.

## 주의사항

- `android/release.properties`에는 키 비밀번호가 평문으로 저장되어 있다. 절대 공유하거나 공개 저장소에 커밋하지 않는다.
- 백업 경로는 사용자만 알고 있어야 한다. 에이전트나 다른 사람이 접근할 수 없는 위치에 보관한다.
- 백업 파일 이름을 변경해 원본 이름으로 식별되지 않도록 한다 (선택사항).

## done_when 확인 방법

| 조건 | 확인 방법 |
|---|---|
| 키 파일 백업 | 사용자가 `release-keystore.jks`를 PC 밖에 복사했는지 확인 |
| 비밀번호 백업 | 사용자가 `release.properties`를 PC 밖에 복사했는지 확인 (비밀번호 노출 X) |
| 두 곳 이상 보관 | 백업 위치가 2개 이상인지 확인 |
| 접근 가능성 | 백업에서 필요할 때 파일을 읽을 수 있는지 확인 (선택사항) |

## 확인 질문

1. 백업 위치로 어느 매체/서비스를 사용할 것인가?
   - USB 드라이브: 물리적 백업 (휴대 가능, 손실 위험)
   - 개인 클라우드 (Google Drive 등): 온라인 백업 (계정 접근 필요, 보안 설정 필수)
   - 기타: 사용자 결정

2. 백업 파일의 이름을 변경할 것인가?
   - 예: `release-keystore.jks` → `timetable-signing-key.jks` (식별 방지)

3. 백업 복구를 실제로 테스트할 것인가?
   - 예: 백업에서 파일을 꺼내 APK 서명 재테스트 (시간소요)
   - 아니오: 복사 완료로 충분

## 참고

- P1.7이 이미 완료되어 서명 키와 빌드 스크립트가 준비되어 있다.
- 앱 배포는 이 작업 완료 후 수행할 수 있다.
