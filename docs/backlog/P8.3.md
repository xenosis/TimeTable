## 취소 사유 및 이월된 내용

2026-09-30 사용자 결정: 평소/방학 2개 고정 모드는 시간표 세트 저장·불러오기(P8.5·P8.6)로 대체된다.

이 작업에서 살려야 할 내용은 다음과 같이 P8.5·P8.6으로 이전되었다:

1. **세트 간 항목 분리** (P8.5, P8.6에서 다룸)
   - "평소" 세트의 항목이 "방학" 세트에 보이지 않아야 함
   - 세트별로 독립적인 항목 저장소 필요

2. **같은 세트 안 요일 복사** (P8.5, P8.6에서 다룸)
   - 요일 복사는 같은 세트 안에서만 동작
   - 다른 세트의 요일은 영향받지 않음

3. **재시작 후 선택 유지** (P8.5, P8.6에서 다룸)
   - 앱을 닫았다가 다시 열어도 마지막으로 적용한 세트가 유지됨

4. **교시 시간 분리 여부** (미결정, P8.5의 확인 질문에서 다룸)
   - 교시 시간(periods)을 세트별로 따로 둘지 공유할지는 요구사항에 없음
   - 사용자의 추가 결정 필요

5. **구현 코드 교체**
