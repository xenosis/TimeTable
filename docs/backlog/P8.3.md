# P8.3 — 방학 모드

## 기준
- 백로그 schema version: 1.1
- 백로그 SHA-256: `a67ef67b545e30ff3302201c2cd6a1217029b9059a9727df578a4e3129b4077d`
- 백로그 bytes: 109475
- 백로그 상태: `in_review`
- 문서화 상태: 작성됨

## 작업 목적
방학 동안 평소 시간표와 분리된 방학용 시간표를 저장하고, 선택한 모드를 앱 전체에 적용한다.

## 쉬운 설명
평소 시간표와 방학 시간표를 각각 따로 보관한다. PIN으로 관리자 편집을 연 뒤 평소 또는 방학 모드를 선택하면 오늘 화면, 주간 화면, 편집 목록, 요일 복사가 같은 모드의 시간표를 사용한다.

## 필요한 입력
- 기준 백로그 P8.3와 관련 요구사항 문서
- 현재 로컬 시간표 데이터베이스
- 관리자 PIN

백로그에 없는 보관 기간, 자동 전환 날짜, 추가 보상 규칙은 이 작업에서 정하지 않는다.

## 결과물
- 시간표 항목이 `regular`(평소)와 `vacation`(방학) 모드로 분리 저장됨
- 관리자 PIN 화면 뒤에서 현재 시간표 모드를 평소/방학으로 전환할 수 있음
- 선택한 모드가 오늘 시간표, 주간 시간표, 편집 화면, 요일 복사에 함께 적용됨
- 앱 버전 `1.19.0`, Android `versionCode 30`

## 선행 작업
백로그에 기록된 상위 작업과 deps의 완료 결과를 확인한다. 이 작업의 직접 deps는 없다.

## 수행 순서
1. 기준 백로그의 schema version과 SHA-256을 확인한다.
2. 평소와 방학 항목을 각 모드로 저장하고, 현재 선택 모드를 저장한다.
3. PIN 관리자 영역에서 평소/방학 모드를 전환한다.
4. 오늘·주간·편집 화면이 선택한 모드로 다시 읽히는지 확인한다.
5. 선택한 모드에서 요일 복사를 실행하고 같은 모드 안에서만 복사되는지 확인한다.
6. `app.json`, `package.json`, `android/app/build.gradle`의 버전이 `1.19.0`/`30`인지 확인한다.
7. `npm run check`를 실행해 lint, typecheck, 테스트, Android debug build를 확인한다.
8. 개발 작업 완료와 문서화 완료를 구분해 기록한다.

## done_when 확인 방법
`done_when`은 “방학 모드 전환 시 별도 시간표가 적용됨”이다. 다음을 모두 확인한다.

- 평소 모드에서 만든 항목이 방학 모드의 오늘·주간·편집 화면에 섞이지 않는다.
- 방학 모드로 전환한 뒤 오늘 화면과 주간 화면에 방학 항목만 표시된다.
- 방학 모드의 편집 목록에서 추가·수정한 항목이 평소 모드로 돌아갔을 때 평소 항목을 덮어쓰지 않는다.
- 방학 모드에서 요일 복사를 하면 방학 시간표 안에서만 대상 요일이 바뀐다.
- 앱을 다시 열어도 마지막으로 선택한 모드가 유지된다.
- 버전 파일이 `1.19.0`이고 Android `versionCode`가 `30`이며 `npm run check`가 통과한다.

## 사용자의 수동 확인 절차
실기기에서 다음 순서로 확인한다. 각 단계에서 화면에 표시된 시간표 제목과 모드 안내 문구를 함께 기록한다.

1. 앱을 열고 관리자 PIN으로 편집을 연다. 평소 모드에서 월요일 항목 하나를 만들고 저장한다.
2. 방학 모드로 전환한다. 오늘 화면, 주간 화면, 편집 목록에 방금 만든 평소 항목이 보이지 않는지 확인한다.
3. 방학 모드에서 같은 요일에 다른 제목의 항목을 만들고 저장한다. 오늘 화면과 주간 화면에 방학 항목이 보이는지 확인한다.
4. 방학 모드에서 편집 목록의 항목을 수정한 뒤 평소 모드로 돌아간다. 평소 항목이 원래 제목과 시간으로 남아 있는지 확인한다.
5. 방학 모드에서 요일 복사를 한 번 실행한다. 대상 요일이 방학 항목으로 바뀌고 평소 모드의 같은 요일은 바뀌지 않는지 확인한다.
6. 앱을 완전히 닫았다가 다시 열고, 마지막으로 선택한 모드와 해당 모드의 시간표가 유지되는지 확인한다.
7. 설정 또는 앱 정보에서 앱 버전이 `1.19.0`인지 확인한다.

확인 중 평소와 방학 항목이 섞이거나, PIN 없이 모드가 바뀌거나, 앱 재실행 후 모드가 초기화되면 해당 단계와 화면 내용을 기록해 수정 대상으로 남긴다.

백로그에 없는 자동 방학 시작·종료 날짜나 방학 모드의 별도 알림 정책이 필요하면 운영 기준을 확인해야 한다.
