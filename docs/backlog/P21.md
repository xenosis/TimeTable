## 목적과 쉬운 설명

'돌봄 → 일루스터'처럼 화살표(→, 또는 ->)가 들어간 일정은 **이동 일정**이다. 학교나 돌봄에서 학원으로 가는 중간 이동을 뜻한다.

- 예전에는 이동 일정도 일반 일정처럼 이름마다 자동 색이 달라져서, 같은 이동인데 칸마다 색이 달랐다.
- 이제 이동 일정은 **회색 한 가지**로 통일해서, 아이가 이동 칸을 한눈에 알아본다.
- 요일별 보기는 칸이 넓으므로 이동 이름을 **한 줄**로 쓴다. 주간 표는 칸이 좁아서 지금처럼 두 줄로 나눈다.
- 글자 크기도 조정한다. 이동 칸 글자는 조금 줄이고, 다른 일정 글자는 칸에 여유가 있을 때만 조금 키운다.

일반 일정(수업, 학원, 돌봄 등)의 **색 키와 색 팔레트는 바꾸지 않는다.**

## 입력·결과물·선행 조건

- 입력: 일정 이름(화살표 포함 여부), 저장된 색 키, 일정 종류(category), 요일별 보기 여부(`focus`), 표 폭·높이(onLayout으로 잰 값), 시스템 글자 배율(`fontScale`).
- 결과물:
  - 이동 일정은 시간표 칸, 오늘 카드, 위젯 데이터, 편집 폼 미리보기에서 모두 같은 회색으로 보인다.
  - 요일별 보기에서 이동 이름은 한 줄, 주간 표는 두 줄 나눔을 유지한다.
  - 편집 폼에서 이동 일정이면 색 선택 대신 "색: 이동 (모두 같은 색)" 안내를 보여 준다(색 목록을 열지 않는다).

  - 이동 칸 최소 높이를 낮춘다(요일별은 한 줄 기준, 주간은 두 줄 기준).

## 추가 요구 반영 기록 (2026-11-04 사용자 요청)

- 이동 일정 글자: 주간 12 → 10.5pt, 요일별 16 → 14.5pt (1.5pt 축소).
- 나머지 일정 글자: +2pt 확대 후보. 줄마다 칸 폭에 들어가고 칸 높이도 될 때만 채택. 예: 과학실험은 커지고, 폭이 좁은 자율·자치활동은 그대로 둘 수 있다. 실제 결과는 기기 화면으로 확인해야 한다.
- 이동 칸 최소 높이: 요일별은 한 줄 기준으로 낮춤. 주간은 두 줄 유지.
- 표 폭은 `onLayout`으로 잰 값을 쓴다. 글자 폭은 어림값(`estimateTextWidth`)을 쓰며 실제 측정은 하지 않는다.
