## 기준 입력

- backlog SHA-256: `bbd1fef8968a5d407bd7fce22d958f03a449d63b3aa54daa576a3fb31caf6324`

- 담당: `claude`
- 마지막 갱신: `2026-10-04T09:33:51.341Z`

## 목적

오늘 할 일을 모두 끝낸 날이 연속으로 몇 일인지 정확하게 계산하고 화면에 표시해 아이의 성취감을 높인다.

## 쉬운 설명

"3일 연속 완료!" 같은 문구를 화면에 보여준다. 언제부터 세는지 정확하게 정하고, 연속이 끊기면 다시 1일부터 센다.

## 필요한 입력

- `task_completions` 테이블의 각 날짜 완료 기록
- 계산 기준: 오늘 할 일을 모두 끝낸 상태를 기준으로 어제까지 연속인 날 수
- 오늘이 미완료면 어제부터 세어야 한다 (설계 원칙: "못 한 일은 아직 남았어요")
- StickerBoard 컴포넌트에 N일 연속 표시

## 결과물

- `src/utils/streak.ts`: `completedDayStreak` 함수가 정확한 연속 일수를 반환
- `StickerBoard` 컴포넌트에서 "N일 연속 완료" 또는 "아직 남았어요" 표시
- Jest 경계 테스트 4개: 오늘 완료/미완료/끊김/정확히 오늘 반영

## 선행 작업

- 직접 의존성: `P4.6` (할 일 없는 날 제외 계산이 먼저 필요)
- `P4.1`(D6 정책), `P4.2`(로컬 DB)는 기준 입력에서 `done`
- `task_completions` 테이블 구조 (P4.2)

## 수행 순서

1. `task_completions` 테이블과 P4.4 완료 조회 방식을 확인한다
2. 연속 일수 계산 기준을 명확히 한다 (오늘/어제 기준, 할 일 없는 날 처리)
3. `completedDayStreak` 함수를 구현하고 경계 테스트를 작성한다
4. `StickerBoard`에 표시 로직을 추가한다
5. `npm run check`로 전체 검사를 통과시킨다

## done_when 확인 방법

연속 달성 일수가 정확히 계산·표시됨:
- SQLite 테스트에서 경계값 검증 (오늘 완료/미완료, 연속 끊김, 정확히 오늘 변경)
- StickerBoard 렌더 테스트에서 표시 확인
- Jest 전체 통과
- `npm run check` 통과
