# P5.13: 위젯 줄 수를 칸 높이만큼 늘리기

**기준:** schema 1.1 · SHA-256 `2b0c9563c89daf10090c1e8fbe36d497b16a0a89294740bf92e9b1ecafc23736`  
**상태:** needs_info  
**담당:** claude

---

## 목적

홈 화면 위젯의 줄 수 상한을 칸 높이에 맞춰 높혀서, 할 일과 일정을 더 많이 표시할 수 있게 합니다. 현재는 할 일 4줄, 일정 5줄로 고정되어 있으나, 기기의 실제 칸 높이가 이보다 크면 할 일 6줄, 일정 7줄까지 보여줄 수 있도록 합니다.

---

## 쉬운 설명

딸 폰(SM-A245N)에서 홈 화면에 올린 위젯을 보니, 아래에 빈 공간이 남아도 "다른 것 더 보려면 앱 열기" 표시('+ N개')로 할 일과 일정을 숨기고 있습니다. 화면 높이가 충분하면 할 일 6줄, 일정 7줄까지 보여줘서 더 많은 정보를 한눈에 볼 수 있게 개선합니다.

---

## 필요한 입력

- 위젯 높이 계산: `WidgetRenderSupport.kt`의 `getHeightDp()`, `calculateVisibleLines()`
- 위젯 자료: `today_widget.xml`, `task_widget.xml` (미리 만든 줄 수)
- 레이아웃 문서: `docs/widget-layout.md` (기준 계산식)

1. `docs/widget-layout.md`의 현재 계산식 검토

   - 할 일: `(높이 - 44 x 배율) / (30 x 배율)` (2~4줄)
2. 최대값을 높이도록 계산식 수정
   - 일정: 최대 7줄 (기존 5줄, "+" 줄 포함)
   - 할 일: 최대 6줄 (기존 4줄, "+" 줄과 칭찬 줄 포함)
3. 경계값 확인 (글자 크기 변화에 따른 줄 높이)

### 2단계: 네이티브 계층 (Kotlin)

1. `WidgetScheduleView.kt` 수정
   - `calculateVisibleLines()` 로직 확인
   - 최대값을 7로 변경
   - JUnit 테스트 추가 (높이 200dp~400dp, 글자 크기 1.0~1.5)
2. `WidgetTaskView.kt` 수정
   - 최대값을 6으로 변경
   - JUnit 테스트 추가 (높이 100dp~300dp, 글자 크기 1.0~1.5)
3. `today_widget.xml` 수정
   - `<LinearLayout>` 내 `<TextView>` 자식 원소 7개 생성 (기존 5개)
   - 각 줄에 id 부여 (예: `schedule_line_1`, `schedule_line_2`, ..., `schedule_line_7`)
   - visibility 기본값 `gone` 설정
4. `task_widget.xml` 수정
   - `<LinearLayout>` 내 `<TextView>` 자식 원소 6개 생성 (기존 4개)
   - 각 줄에 id 부여 (예: `task_line_1`, `task_line_2`, ..., `task_line_6`)
5. `ScheduleWidgetRenderer.kt` 수정
   - 그릴 줄 개수가 7까지 가능하도록 조정
   - 나머지 줄 visibility 제어
6. `TaskWidgetRenderer.kt` 수정
   - 그릴 줄 개수가 6까지 가능하도록 조정
   - 나머지 줄 visibility 제어

### 3단계: 테스트

1. JUnit 테스트 추가 (경계값 포함)

## 한계와 제약

- **기기별 높이 다름**: SM-A245N은 높이가 충분하지만, 다른 기기는 다를 수 있음. 계산식으로 동적 적응.
- **RemoteViews 미리 만든 줄**: 줄을 미리 만들어 둬야 하므로, 최대값을 정해야 함. 7줄, 6줄로 정함.
- **글자 크기 변화**: 사용자 설정 글자 크기에 따라 줄 높이가 변하므로 정확한 계산 필요.
- **"+ N개"와 칭찬 줄**: 일정의 "+ N개" 줄, 할 일의 칭찬 줄이 계산에 정확히 포함되는지 확인 필요.
- **P5.3과의 상호작용**: P5.3의 1분 유지 규칙(setWindow 재그리기)이 줄 수가 늘어난 상황에서도 정확하게 작동하는지 확인 필요.
- **실기기 미확인**: 딸 폰 연결 끊김으로 실기기 최종 확인 미수행, 이후 검증 필요.
