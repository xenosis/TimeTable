## 작업 목적

백로그의 P3 작업을 수행하기 위한 목적과 범위를 설명한다: 3단계: 알림 · 알람.

## 쉬운 설명

쉽게 말해, 3단계: 알림 · 알람 작업이 백로그에 적힌 목표를 충족하도록 준비·수행·확인하는 항목이다.

## 필요한 입력

- 기준 백로그 항목: P3
- 관련 요구사항·설정 기준: docs/research.md, docs/tasks.md, AGENTS.md, CLAUDE.md, package.json, .claude/settings.json
- 구체 입력값: 백로그에 명시된 내용만 사용하며, 없는 값은 임의로 정하지 않는다.

## 결과물

3단계: 알림 · 알람에 대한 개발 결과 또는 확인 기록과 done_when 충족 여부.

## 선행 작업

백로그 항목 P3의 deps와 상위 단계 완료 결과를 확인한다. 구체적인 deps가 전달 문서에 없는 경우 추가로 추정하지 않는다.

## 수행 순서

1. 기준 요구사항과 이 작업의 백로그 범위를 확인한다.
2. 필요한 입력과 선행 작업 결과를 준비한다.
3. 3단계: 알림 · 알람 범위만 수행하거나 확인 기록을 남긴다.
4. done_when 충족 여부를 확인한다.
5. 개발 상태와 문서화 상태를 구분해 기록한다.

## done_when 확인 방법

백로그 JSON에서 P3 항목의 done_when 조건을 기준으로 결과를 대조하고, 조건별 확인 근거를 남긴다. 이 문서에는 백로그에 없는 추가 완료 기준을 만들지 않는다.

## 확인 질문

백로그에 없는 세부 구현값, 입력 데이터, 화면 세부, 운영 조건이 필요하면 무엇으로 결정할지 확인이 필요하다.
