P7.5는 지원하는 테마별로 아이 화면·관리자 화면·위젯이 올바른 색·아이콘·레이아웃을 표시하는지 확인하고 대비·의미 키 fallback이 정상인지 검증하는 작업이다. 
테스트 환경(에뮬레이터, PC)과 실기기(딸 폰)를 구분하여 결과를 기록한다.

## 목적

지원되는 모든 테마에서 앱이 일관되게 동작하고, 색 대비는 접근성 기준을 충족하며, 의미 있는 색(과목별 색상 등)이 손실되지 않도록 확인한다. 테마 변경 시 화면과 위젯이 즉시 반영되고, 시간표 위젯은 모든 테마의 데이터를 정확히 표시하는지 검증한다.

## 쉬운 설명

앱에서 지원하는 여러 테마(예: 시나모롤 구름, 쿠로미 별 등)를 실제로 선택해보고:
- 배경색, 강조색, 캐릭터 그림, 보석 받기 아이콘 등이 제대로 바뀌는지
- 할 일과 시간표 위젯도 테마 색으로 즉시 업데이트되는지
- 글자가 배경과 충분히 구분되는지(대비 4.5:1 이상)
- 과목별 색상 같은 의미 있는 색이 테마마다 같게 유지되는지

확인한다. 에뮬레이터와 실제 폰에서의 결과를 따로 기록한다.

## 필요한 입력

- 지원 테마 목록: `src/theme/index.ts`에서 확인 가능한 모든 테마 항목
- 색 대비 검증: `__tests__/theme.test.ts`에서 확인된 접근성 기준
- 위젯 데이터 테스트: `__tests__/widgets/` 관련 테스트
- 테마 변경 시 화면 즉시 반영 동작 (Zustand 상태 업데이트)
- 검증 환경: PC 에뮬레이터(OfflineTest), 딸 폰(SM-A245N 또는 지정 기기)

## 수행 순서

1. `src/theme/index.ts`에서 지원 테마 목록을 파악한다.
2. 색 대비 검증 기준을 `__tests__/theme.test.ts`와 코드에서 확인한다 (접근성 4.5:1 이상, fallback 의미 키).
3. PC 에뮬레이터에서 테마별 화면을 확인한다:
   - 홈(오늘) 화면: 배경색, 캐릭터, 할 일 위젯
   - 시간표 화면: 시간표 항목 색, 과목별 색 의미 유지
   - 내 보석 화면: 보석 개수 배경, 보석 받기 아이콘 모양
   - 관리자 화면: 배경, 강조색, 버튼 색
   - 위젯: 할 일 위젯의 테마 색 즉시 반영, 시간표 위젯 데이터 테스트
4. 실기기(딸 폰)에서 동일한 항목을 확인한다 (가능할 경우).
5. 색 수정이 필요한 경우(예: 대비 미달), 수정 후 버전 동시 갱신 및 재검증.
6. Jest 테스트 결과(theme.test.ts, widgets)와 npm run check 통과 여부를 확인한다.

## done_when 확인 방법

백로그 완료 조건:

> 지원 테마별 화면·위젯 회귀 체크 결과와 대비·의미 키 fallback 확인을 기록함

완료 판정 기준:

- **테마별 화면 확인**: 지원하는 테마(최소 2개 이상) 각각에 대해 다음 항목을 에뮬레이터에서 최소 1회, 실기기에서 최소 1회 확인하고 기록
  - 홈 화면 배경색, 캐릭터, 강조색 변경
  - 시간표 화면 과목별 색(의미 유지), 시간표 항목 색
  - 내 보석 화면 배경, 보석 받기 아이콘
  - 관리자 화면 배경 및 버튼 색
  - 할 일·시간표 위젯의 테마 색 즉시 반영

- **색 대비 검증**: 
  - 기존 theme.test.ts에서 4.5:1 이상 대비 검증된 항목 확인
  - 수정된 색(예: 위험 색)이 있는 경우, 변경 전후 검증 쌍 기록
  - fallback 의미 키(과목별 색 등)가 모든 테마에서 같은 의미로 해석되는지 확인

- **위젯 데이터 테스트**:
  - 모든 지원 테마에 대한 위젯 데이터 테스트 통과 기록
  - 시간표 위젯은 데이터 테스트 범위 내에서 검증(UI 화면 확인은 에뮬레이터/실기기 동작 테스트로 수행)

- **환경별 기록**: 
  - 에뮬레이터 검증: 환경, 버전, 스크린샷·로그 경로
  - 실기기 검증: 기기명, 환경, 버전, 동작 결과 기록
  - 미확인 항목: 사유 명시(예: 실기기 미접근, 테마 지원 중단 등)

- **버전 동시 갱신**:
  - 색 수정이 있었으면 app.json, package.json, Android build.gradle 버전 동시 수정 확인
  - 버전만 변경된 경우(수정 없음) 기록
