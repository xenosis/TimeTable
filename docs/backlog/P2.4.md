# P2.4 — 오늘 화면

## 기준 입력

- 기준 백로그 schema version: `1.1`
- 기준 백로그 SHA-256: `c292e3e35e08ea0ab3ced574ceba69c4cacfcd783a45b7de2ddd2d1cbd088c60`
- 기준 백로그 항목: `P2.4`
- 백로그 개발 상태: `done`
- 선행 작업: `P2.2`, `P1.9`
- 구현 기준 버전: `1.7.0` (`versionCode 18`)
- 문서 상태: 구현 근거를 반영한 설명 문서 작성 완료. 문서화 완료와 개발 작업 완료는 별도로 관리한다.

## 목적

오늘 요일에 해당하는 시간표를 DB에서 조회하고, 현재 일정과 다음 일정을 구분해 보여 준다. 다음 일정 시작까지 남은 시간과 활성 테마의 의미 색·아이콘을 함께 표시한다. 백로그의 완료 기준은 “현재/다음 일정이 정확히 표시되고 활성 테마의 의미 색·아이콘이 적용됨”이다.

## 쉬운 설명

앱의 오늘 화면은 현재 시각과 오늘 요일을 기준으로 오늘 수업 목록을 읽는다. 지금 진행 중인 일정과 가장 가까운 다음 일정을 각각 제목과 시간으로 보여 주고, 각 일정에 저장된 의미 색과 아이콘을 활성 테마에서 해석해 표시한다. 다음 일정이 있으면 시작까지 몇 분 남았는지도 표시한다. 마지막 일정까지 끝나면 오늘 일정이 모두 끝났다는 문구를 표시한다. 요일 조회에 실패하면 오류 문구를 표시한다. 요일이 바뀌는 동안에는 이전 요일의 일정이 화면에 남지 않도록 숨긴다.

## 필요한 입력

- SQLite DB 연결: `getDatabase()`가 제공하는 DB.
- 조회 범위: 기본 `familyId`인 `local-family`와 현재 날짜의 `weekday` 값.
- `timetable_items`의 일정 제목, 시작·종료 시각, `color_key`, `icon_key`.
- 교시 방식 일정의 시작·종료 시각: `periods` 테이블과 같은 `family_id`, `period_no`로 결합해 조회한다.
- 현재 시각: 화면의 일정 계산에 사용하는 `Date` 값.
- 활성 테마: `ThemeDefinition`과 의미 키 해석 함수.

## 결과물

- `src/db/timetableRepository.ts`
  - 현재 요일과 `familyId`로 오늘 일정을 DB에서 조회한다.
  - 교시 방식 일정은 `periods`의 시작·종료 시각을 사용하고, 직접 시각을 가진 일정은 해당 값을 사용한다.
  - 조회 결과에 일정 제목, 시작·종료 시각, `colorKey`, `iconKey`를 포함한다.
- `src/utils/todaySchedule.ts`
  - 시작 시각 순으로 정렬한다.
  - 현재 시각이 시작 이상·종료 미만인 일정을 `current`로 계산한다.
  - 현재 시각 이후 가장 이른 일정을 `next`로 계산한다.
  - 다음 일정 시작까지의 분을 `minutesUntilNext`로 계산한다.
- `src/components/TodayScheduleCard.tsx`
  - 오늘 일정 DB 조회, 현재 시각 갱신, 현재·다음 일정 표시
  - 현재·다음 일정 각각의 제목·시간과 활성 테마의 의미 색·아이콘 표시
  - 마지막 일정 완료 문구, 오늘 일정 없음·요일 조회 실패 오류 문구 표시
  - 요일 전환 중 이전 요일 일정 숨김
- `app/index.tsx`
  - 오늘 화면 카드와 활성 테마를 앱 화면에 연결한다.

## 수행 순서

1. 선행 작업 `P2.2`의 SQLite 일정·교시 구조와 `P1.9`의 테마 의미 키 해석을 사용한다.
2. 현재 날짜의 요일과 `local-family` 범위로 `timetable_items`를 조회한다.
3. 일정에 교시 번호가 있으면 같은 가족 범위의 `periods` 행과 결합해 시작·종료 시각을 정한다.
4. 현재 시각을 기준으로 일정 목록에서 현재 일정, 다음 일정, 다음 일정까지 남은 분을 계산한다.
5. 현재 일정과 다음 일정을 각각 제목·시간과 함께 표시하고, 각 일정의 `colorKey`와 `iconKey`를 활성 테마의 의미 색·아이콘으로 해석해 적용한다.
6. 다음 일정이 없고 마지막 일정까지 끝난 경우 오늘 일정이 모두 끝났다는 문구를 표시한다.
7. 일정이 없으면 없음 문구를 표시하고, 요일 조회에 실패하면 오류 문구를 표시한다. 요일 전환 중에는 이전 요일의 조회 결과를 숨긴다.
8. 화면 시각을 주기적으로 갱신해 현재·다음 일정 표시가 시간 흐름을 반영하도록 한다.

## done_when 확인 방법

다음 근거로 백로그의 완료 기준을 대조한다.

- 오늘 요일의 일정이 `getTimetableItemsForWeekday`를 통해 DB에서 조회되는지 확인한다.
- 교시 기반 일정은 `periods`의 시각과 결합되고, 직접 시각 일정은 저장된 시각으로 화면에 표시되는지 확인한다.
- `getTodaySchedule`가 시작 시각 순으로 정렬하고 현재 일정과 다음 일정을 계산하는지 확인한다.
- 현재 일정은 시작 시각 이상·종료 시각 미만일 때 선택되고, 다음 일정은 현재 시각 이후 가장 이른 일정으로 선택되는지 확인한다.
- 다음 일정이 있으면 시작까지 남은 분이 `minutesUntilNext`로 표시되는지 확인한다.
- 현재 일정과 다음 일정이 각각 제목·시간으로 표시되는지 확인한다.
- 현재 일정과 다음 일정에 각각 활성 테마의 의미 색·아이콘이 적용되는지 확인한다.
- 마지막 일정까지 끝난 뒤 오늘 일정이 모두 끝났다는 문구가 표시되는지 확인한다.
- 요일 조회에 실패했을 때 오류 문구가 표시되는지 확인한다.
- 요일 전환 중 이전 요일의 일정이 숨겨지는지 확인한다.
- `resolveThemeColor`와 `resolveThemeIcon`을 통해 활성 테마의 의미 색·아이콘이 적용되는지 확인한다.
- 오늘 일정이 없거나 조회가 실패한 경우 화면 안내가 표시되는지 확인한다.
- 구현 기준 버전은 `1.7.0`, `versionCode 18`이다.
- `1.7.0` (`versionCode 18`) 기준으로 최종 전체 품질 검사(`npm run check`)가 통과했다.

위 근거가 확인되면 “현재/다음 일정이 정확히 표시되고 활성 테마의 의미 색·아이콘이 적용됨” 조건을 충족한 것으로 판단한다. 이 문서는 해당 판단을 기록하지만 백로그 상태를 변경하지 않는다.
