# P4.5 — 날짜 전환

## 기준

- 백로그 schema version: `1.1`
- 백로그 SHA-256: `8b3364e1dfe824914a91853a9858f2db5064249d71ab23b5ee99835fc1482213`
- 백로그 bytes: `116381`
- 기준 백로그 항목: `P4.5`
- 개발 상태: `in_progress`
- 문서화 상태: 작성됨

## 작업 목적

자정이 지나거나 앱이 다시 활성화될 때 목록 기준 날짜를 오늘로 갱신한다.

## 쉬운 설명

앱을 오래 켜 둔 채 자정을 넘겨도 어제 목록이 계속 보이지 않게 한다. 앱을 백그라운드로 보냈다가 다시 열 때도 현재 날짜를 다시 확인해 오늘 목록을 보여 준다.

## 필요한 입력

- P4.5 백로그 항목의 요약과 `done_when`
- 선행 작업 P4.4의 오늘 목록 화면 및 목록 갱신 결과
- 자정 경과를 감지할 수 있는 시간 기준
- 앱이 백그라운드에서 다시 활성화되었음을 확인할 수 있는 AppState 복귀 신호

구체적인 타이머 주기, 날짜 상태의 저장 방식, AppState 연결 위치는 기준 백로그에 명시되어 있지 않으므로 구현 전에 확인이 필요하다.

## 결과물

- 자정이 지난 뒤 목록이 현재 날짜 기준으로 갱신된다.
- AppState 복귀 뒤 목록이 현재 날짜 기준으로 갱신된다.
- 문서에는 위 동작의 실기기 수동 확인 절차와 자동 검증 기록이 남는다.

## 선행 작업

- `P4.4` 오늘의 할 일 화면

P4.4의 개발 완료 여부와 실기기 확인 결과는 별도로 확인한다. P4.5 문서 작성은 P4.5 개발 완료를 의미하지 않는다.

## 수행 순서

1. 기준 백로그의 schema version과 SHA-256을 확인하고 P4.5의 `done_when`을 고정한다.
2. P4.4의 오늘 목록이 표시되는 상태에서 현재 날짜를 기준으로 목록을 확인한다.
3. 자정 경과를 감지하면 오늘 날짜를 다시 계산하고 목록을 갱신한다.
4. 앱이 백그라운드에서 다시 활성화되면 오늘 날짜를 다시 계산하고 목록을 갱신한다.
5. 자정 경과와 AppState 복귀 각각에 대해 목록이 오늘 날짜로 바뀌는지 자동 검사와 실기기 수동 절차로 확인한다.
6. 확인 결과를 개발 상태와 문서화 상태로 나누어 기록한다.

## done_when 확인 방법

다음 두 조건을 각각 확인하고 결과를 기록한다.

- 자정 경과: 앱을 켜 둔 상태에서 날짜가 바뀐 뒤 목록을 다시 확인했을 때 새 날짜의 오늘 목록으로 갱신된다.
- AppState 복귀: 앱을 백그라운드로 보낸 동안 날짜가 바뀐 뒤 앱으로 돌아왔을 때 새 날짜의 오늘 목록으로 갱신된다.

두 조건 중 하나라도 확인되지 않으면 P4.5 개발 완료로 기록하지 않는다.

## 실기기 수동 확인 절차

실제 스마트폰에서 각 단계의 결과를 `통과` 또는 `실패`로 기록한다. 실패하면 재현 시각, 기기 날짜·시간, 화면 캡처를 함께 남긴다.

1. P4.4에서 오늘 목록이 표시되는 상태로 앱을 연다.
2. 앱을 켜 둔 채 자정 직전의 현재 날짜와 목록을 기록한다.
3. 자정이 지난 뒤 목록 화면을 다시 확인한다. 목록의 기준 날짜가 새 날짜로 바뀌고 새 날짜의 오늘 목록이 보이는지 기록한다.
4. 앱을 다시 오늘 날짜의 목록이 보이는 상태로 준비한다.
5. 앱을 백그라운드로 보낸다.
6. 백그라운드 상태에서 날짜가 바뀌도록 기다린 뒤 앱을 다시 전면으로 가져온다.
7. AppState 복귀 직후 목록의 기준 날짜가 새 날짜로 바뀌고 새 날짜의 오늘 목록이 보이는지 기록한다.
8. 자정 경과와 AppState 복귀 결과가 모두 `통과`인지 확인한다.

## 자동 검증 기록

- 실행 명령: `npm run backlog -- get P4.5 --json`
- 결과: 성공. 기준 항목 ID가 `P4.5`이고 `schemaVersion`이 `1.1`, SHA-256이 `8b3364e1dfe824914a91853a9858f2db5064249d71ab23b5ee99835fc1482213`임을 확인했다.
- 조회된 개발 상태: `in_progress`
- 조회된 선행 작업: `P4.4`
- 조회된 완료 조건: `자정 경과·AppState 복귀 시 목록이 오늘 날짜로 갱신됨`
- 코드와 원본 `backlog.json`은 이 문서 작업에서 수정하지 않았다.
- 자정 경과와 AppState 복귀 동작 자체의 자동 테스트 실행 결과는 기준 백로그 조회만으로 확인할 수 없으므로, 해당 테스트 결과가 제공되기 전까지 미확인으로 둔다.

## 확인 질문

- 자정 경과를 검증할 때 사용할 기기 시간 변경 방법 또는 대기 시간을 정해야 한다.
- AppState 복귀 때 목록 갱신을 확인할 최소 백그라운드 유지 시간과 테스트 데이터가 기준 백로그에 없으므로 정해야 한다.
