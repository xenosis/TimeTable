# P7.1 — 앱 꾸미기

## 기준

- 백로그 schema version: `1.1`
- 백로그 SHA-256: `8e04299d8bb7080e5b1434807b423a7f08eefe4addf18ef29ccb74a6ebe86c97`
- 기준 작업 상태: `in_progress`
- 상위 작업: `P7`

## 작업 목적

앱의 외형을 최종 확정한다. 홈 화면 아이콘, 스플래시 화면, 알림 영역 아이콘, 앱 표시 이름을 독자적으로 정하고, 앱 안에서 바꾸는 테마와 OS에 등록되는 자산을 분리하여 관리한다.

## 쉬운 설명

사용자가 스마트폰 홈 화면에서 보는 앱 아이콘, 앱을 열 때 나타나는 시작 화면(스플래시), Android 알림 패널에 나타나는 작은 아이콘, 그리고 앱 설정에서 보이는 앱 이름을 모두 확정한다. 앱 안의 밝은색/어두운색 테마는 따로 관리해서 아이콘이나 알림 아이콘을 바꾸지 않는다.

## 필요한 입력

- 기준 백로그의 P7.1 항목
- 기존 앱 이름 및 Expo Android 설정
- 앱 내 테마 설정 코드

백로그에 없는 별도 운영 값이나 임의 값은 이 작업의 입력으로 사용하지 않는다.

## 결과물 및 구현 범위

### 1. 앱 아이콘 (홈 화면)

- 파일: `assets/timetable-icon.png` (컬러 달력 모양)
- 연결:
  - `app.json`의 `expo.icon` 참조
  - adaptive icon 전경(`expo.adaptiveIcon.foregroundImage`)에 연결
  - Android 런처 아이콘: `@mipmap/brand_launcher` 및 `@mipmap/brand_launcher_round`
- 생성된 네이티브 리소스:
  - 레거시(API 25 이하): `android/app/src/main/res/mipmap-*/brand_launcher.png` (컬러)
  - Adaptive(API 26+): `android/app/src/main/res/mipmap-anydpi-v26/brand_launcher.xml`, `brand_launcher_round.xml` (전경+배경 조합)

### 2. Adaptive Icon 배경 및 전경

- 배경: `assets/adaptive-icon-background.png` → `android/app/src/main/res/drawable/brand_icon_background.xml`
- 전경(단색 레이어 용도): `assets/adaptive-icon-monochrome.png` → `android/app/src/main/res/drawable/brand_icon_monochrome.xml`
  - Android 13+ Material You "테마 아이콘" 켰을 때 이 단색 이미지가 시스템 색으로 렌더링됨
  - 모든 path 데이터는 `evenOdd` fillType으로 지정하여 구멍이 뚫려 있는 부분은 투명하게 표시

### 3. 스플래시 화면

- 파일: `assets/timetable-icon.png` (앱 아이콘과 동일)
- 배경색: `#4F46E5` (인디고 색)
- 표시 방식: `contain` (비율 유지, 여백 포함)
- 연결: `expo-splash-screen` 설정에서 관리

### 4. 알림 영역 아이콘

- 파일: `assets/notification-icon.png` (흰색 단색 달력 실루엣)
- 특성: 투명 배경, 흰색(#FFFFFF) 단색
- Android 리소스 밀도별 복사:
  - `android/app/src/main/res/drawable-mdpi/notification_icon.png`
  - `android/app/src/main/res/drawable-hdpi/notification_icon.png`
  - `android/app/src/main/res/drawable-xhdpi/notification_icon.png`
  - `android/app/src/main/res/drawable-xxhdpi/notification_icon.png`
  - `android/app/src/main/res/drawable-xxxhdpi/notification_icon.png`
- 연결: `expo-notifications` 설정에서 `smallIcon` 참조
- 용도: Android 8+ 필수(컬러 아이콘 사용 불가)

### 5. 앱 표시 이름

- **앱 표시 이름**: `채아시간표` (한글)
- **패키지명**: `com.chaea.timetable` (변경됨, 이전: `com.sewoong.kidtimetable`)
- **영어 이름**: `chaea`
- 연결:
  - `app.json`의 `expo.name` = `"채아시간표"`
  - `android/app/AndroidManifest.xml`의 `android:label` = `채아시간표`
  - `android/app/build.gradle`의 `applicationId` = `"com.chaea.timetable"`

### 6. 앱 내 테마와 OS 자산 분리

- **앱 내 테마**: JavaScript 상태(state)로 관리 (밝은색/어두운색 선택)
  - 테마 전환 시 OS에 등록된 아이콘, 스플래시, 알림 아이콘은 변경되지 않음
- **OS 자산**: Expo 및 Android 자산 설정으로 고정 관리
  - 네이티브 리소스는 JS 테마 state와 무관하게 독립적으로 렌더링됨

## 실기기 확인 목록

실제 스마트폰에 설치한 같은 빌드에서 다음 항목을 각각 확인한다.

1. 홈 화면에서 앱 아이콘이 기본 Expo 아이콘이나 빈 아이콘이 아닌 독자 달력 아이콘으로 보이는지 확인한다.
2. 홈 화면 아이콘을 길게 눌렀을 때 `brand_launcher`의 배경과 전경이 함께 표시되고, 아이콘 가장자리나 배경이 잘리지 않는지 확인한다.
3. Android 런처가 단색 아이콘 표시를 지원하는 경우 아이콘을 단색 모드로 표시해도 달력 모양이 식별되는지 확인한다.
4. 앱을 완전히 종료한 뒤 다시 실행할 때 스플래시 배경이 `#4F46E5` 계열로 보이고, 달력 아이콘이 화면 비율에 맞게 표시되는지 확인한다.
5. 알림을 하나 발생시킨 뒤 알림 패널에서 작은 아이콘이 흰색 단색 아이콘으로 보이는지 확인한다.
6. 알림 아이콘이 컬러 앱 아이콘처럼 보이거나 검은 사각형 배경으로 뭉개지지 않는지 확인한다.
7. 설정의 앱 목록과 최근 앱 화면에서 앱 이름이 '채아시간표'로 표시되는지 확인한다.
8. 앱 안의 화면 테마(밝은색/어두운색)를 전환했을 때, 테마 색상만 바뀌고 OS에 등록된 아이콘·알림 아이콘·스플래시는 바뀌지 않는지 확인한다.
9. 다크 모드 또는 시스템 색상 설정을 바꾼 뒤에도 앱 표시 이름과 알림 아이콘이 깨지지 않는지 확인한다. 앱이 라이트 모드만 지원하는 경우 현재 정책에 맞게 표시되는지만 기록한다.

## done_when 확인 방법

다음 근거를 모두 확보하면 P7.1의 done_when을 확인할 수 있다.

- `app.json`에서 앱 아이콘, 스플래시, 단색 알림 아이콘의 파일 연결을 확인한다.
- `app.json`의 adaptive icon 배경·전경·단색 경로와 Android `brand_launcher` 리소스 연결을 확인한다.
- Android manifest가 `@mipmap/brand_launcher` 및 `@mipmap/brand_launcher_round`를 사용하는지 확인한다.
- 패키지명(`applicationId`) 및 앱 표시 이름(`android:label`)이 `com.chaea.timetable` 및 `채아시간표`로 연결되는지 확인한다.
- 앱 내 테마 설정과 OS 자산 설정이 서로 다른 설정 경로를 사용하는지 코드와 설정에서 확인한다.
- Android debug build가 성공하는지 확인한다.
- 위 실기기 목록 1~8의 결과를 사용자 확인 기록으로 남긴다.
