# P7.1 — 앱 꾸미기

## 기준

- 백로그 schema version: `1.1`
- 백로그 SHA-256: `7160996aa2d8e69caa5b2e2747a34e6e6928b74e84eba8d5c01511691739ef29`
- 문서화 대상: P7.1
- 개발 상태: 구현 및 정적 검토 진행, 실기기 확인 필요

## 작업 목적

아이콘, 스플래시, 알림 아이콘, 앱 표시 이름을 앱의 최종 자산으로 정리하고, 앱 안에서 선택하는 테마와 Android OS에 등록되는 자산을 서로 독립적으로 관리한다.

## 쉬운 설명

앱을 설치했을 때 보이는 얼굴을 정한다. 홈 화면 아이콘과 앱을 켤 때의 스플래시에는 컬러 앱 아이콘을 사용하고, Android 알림 영역에는 작은 단색 아이콘을 사용한다. 앱 표시 이름은 기존 제품명인 `TimeTable`로 유지한다.

## 필요한 입력

- 기준 백로그의 P7.1 항목
- 기존 앱 이름과 Expo Android 설정
- 기존 앱 내 테마 설정

백로그에 없는 보상 값이나 별도 운영 값은 이 작업의 입력으로 사용하지 않는다.

## 결과물 및 구현 범위

- 독자 앱 아이콘: `assets/timetable-icon.png`
  - 컬러 달력 모양의 앱 아이콘이다.
  - `app.json`의 `expo.icon` 및 adaptive icon foreground에 연결되어 있다.
  - Android 애플리케이션은 `@mipmap/brand_launcher`와 `@mipmap/brand_launcher_round`를 런처 아이콘으로 사용한다.
- adaptive icon 구성 자산
  - 배경: `assets/adaptive-icon-background.png`
  - 단색 레이어: `assets/adaptive-icon-monochrome.png`
  - `app.json`의 `android.adaptiveIcon.backgroundImage` 및 `monochromeImage`에 연결되어 있다.
  - 생성된 Android 리소스에는 `android/app/src/main/res/drawable/brand_icon_background.xml`, `brand_icon_foreground.xml`, `brand_icon_monochrome.xml`이 있다.
  - adaptive launcher 정의는 `android/app/src/main/res/mipmap-anydpi-v26/brand_launcher.xml` 및 `brand_launcher_round.xml`이다.
- 스플래시: `assets/timetable-icon.png`
  - `expo-splash-screen` 설정에 연결되어 있다.
  - 배경색은 `#4F46E5`, 표시 방식은 `contain`이다.
- 단색 알림 아이콘: `assets/notification-icon.png`
  - `expo-notifications` 설정에 연결되어 있다.
  - Android 알림 영역에서 사용할 수 있도록 투명 배경의 흰색 단색 자산으로 분리했다.
  - Android density 리소스(`android/app/src/main/res/drawable-*/notification_icon.png`)로 생성되어 알림 전용 자산으로 사용된다.
- 앱 표시 이름: `TimeTable`
  - `app.json`의 `expo.name`과 Android 앱 표시 이름에 사용되는 기존 이름을 유지한다.
- 앱 내 테마와 OS 자산 분리
  - 앱 화면의 테마 색상·스타일 선택은 앱 코드의 테마 설정으로 관리한다.
  - 홈 화면 아이콘, 스플래시, 알림 아이콘은 Android/Expo 자산 설정으로 관리한다.
  - 알림 아이콘을 앱 화면의 컬러 아이콘으로 재사용하지 않는다.

## 선행 작업

백로그에 기록된 상위 작업과 deps의 완료 결과를 확인한다.

## 수행 순서

1. 기존 Expo 및 Android 자산 연결을 확인한다.
2. 컬러 앱 아이콘과 스플래시 자산을 연결한다.
3. 알림 전용 단색 아이콘을 연결한다.
4. 앱 표시 이름 `TimeTable`의 연결을 확인한다.
5. 앱 내 테마 설정과 OS 자산 설정이 분리되어 있는지 확인한다.
6. 빌드와 정적 검사를 실행한다.
7. 실기기에서 아래 시각 체크를 수행한 뒤 결과를 기록한다.

## 검사 결과

- Android debug build: 성공.
- 코드·설정 반영: 완료.
- 실기기 시각 확인: 미검증.
- 따라서 이 문서는 구현 및 빌드 확인을 기록하지만 P7.1을 최종 완료로 표현하지 않는다. 실기기 확인 결과를 받은 뒤 백로그 상태를 판단해야 한다.

## 실기기 확인 목록

실제 스마트폰에 설치한 같은 빌드에서 다음 항목을 각각 확인한다.

1. 홈 화면에서 앱 아이콘이 기본 Expo 아이콘이나 빈 아이콘이 아닌 독자 달력 아이콘으로 보이는지 확인한다.
2. 홈 화면 아이콘을 길게 눌렀을 때 `brand_launcher`의 배경과 전경이 함께 표시되고, 아이콘 가장자리나 배경이 잘리지 않는지 확인한다.
3. Android 런처가 단색 아이콘 표시를 지원하는 경우 아이콘을 단색 모드로 표시해도 달력 모양이 식별되는지 확인한다.
4. 앱을 완전히 종료한 뒤 다시 실행할 때 스플래시 배경이 `#4F46E5` 계열로 보이고, 달력 아이콘이 화면 비율에 맞게 표시되는지 확인한다.
5. 알림을 하나 발생시킨 뒤 알림 패널에서 작은 아이콘이 흰색 단색 아이콘으로 보이는지 확인한다.
6. 알림 아이콘이 컬러 앱 아이콘처럼 보이거나 검은 사각형 배경으로 뭉개지지 않는지 확인한다.
7. 설정의 앱 목록과 최근 앱 화면에서 앱 이름이 `TimeTable`로 표시되는지 확인한다.
8. 앱 안의 화면 테마와 색상 표시가 기존 앱 내 테마와 동일하게 동작하고, OS 알림 아이콘이나 홈 화면 아이콘을 바꾸지 않는지 확인한다.
9. 다크 모드 또는 시스템 색상 설정을 바꾼 뒤에도 앱 표시 이름과 알림 아이콘이 깨지지 않는지 확인한다. 앱이 라이트 모드만 지원하는 경우 현재 정책에 맞게 표시되는지만 기록한다.

## done_when 확인 방법

다음 근거를 모두 확보하면 P7.1의 done_when을 확인할 수 있다.

- `app.json`에서 앱 아이콘, 스플래시, 단색 알림 아이콘의 파일 연결을 확인한다.
- `app.json`의 adaptive icon 배경·전경·단색 경로와 Android `brand_launcher` 리소스 연결을 확인한다.
- Android manifest가 `@mipmap/brand_launcher` 및 `@mipmap/brand_launcher_round`를 사용하는지 확인한다.
- `expo.name` 및 Android 앱 표시 이름이 `TimeTable`로 연결되는지 확인한다.
- 앱 내 테마 설정과 OS 자산 설정이 서로 다른 설정 경로를 사용하는지 코드와 설정에서 확인한다.
- Android debug build가 성공하는지 확인한다.
- 위 실기기 목록 1~8의 결과를 사용자 확인 기록으로 남긴다.

## 확인 질문

- 현재 P7.1 범위에서 앱 표시 이름은 기존 이름인 `TimeTable`을 유지하는 것으로 기록했다. 다른 이름이 필요하면 이름과 적용 범위를 정해야 한다.
- 실기기에서 확인한 각 항목의 성공·실패 결과가 필요하다. 실패한 항목은 화면 상태와 재현 절차를 함께 기록해야 한다.
