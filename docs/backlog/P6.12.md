## 작업 목적
Supabase 일시정지 상황에서도 로컬 알림과 위젯을 확인한다.

## 쉬운 설명
쉽게 말해, 일시정지 대비 확인을 백로그 범위에서 수행한다.

## 필요한 입력
기준 백로그 P6.12와 관련 요구사항 문서. 백로그에 없는 값은 임의로 정하지 않는다.

## 결과물
서버 일시정지 시나리오에서 로컬 알림·위젯이 정상 동작함을 확인

## 선행 작업
백로그에 기록된 상위 작업과 deps의 완료 결과를 확인한다.

## 수행 순서
1. 범위와 입력을 확인한다.
2. 선행 작업 결과를 준비한다.
3. 백로그 범위만 수행하고 결과를 기록한다.
4. done_when을 확인한다.
5. 개발 완료와 문서화 완료를 구분해 기록한다.

## done_when 확인 방법
서버 일시정지 시나리오에서 로컬 알림·위젯이 정상 동작함을 확인를 결과와 대조하고 확인 근거를 남긴다.
