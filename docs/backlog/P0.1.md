- 백로그 schema version: `1.1`

- 현재 백로그 상태: `in_review`
- 상위 작업: `P0` (0단계 사전 확인·기술 검증)
- deps: 없음

## 목적

딸 폰의 실제 모델명과 Android 버전을 확인해 이후 APK 설치, 알림, 알람 모드 실기기 검증의 대상 환경을 확정한다.

## 쉬운 설명

딸 폰이 정확히 어떤 기종이고 어떤 Android를 쓰는지 적어 두는 작업이다. 그래야 나중에 설치나 알림 테스트 결과를 다른 기기와 헷갈리지 않는다.

## 필요한 입력

- 딸 폰 실기기
- 기기 설정에서 확인한 모델명
- 기기 설정에서 확인한 Android 버전
- 기준 요구사항: `docs/tasks.md` 0-1(“모델명, 안드로이드 버전”)
- 관련 설계 문서: `docs/research.md`

백로그 항목에 없는 기기 세부 정보나 추가 호환성 기준은 임의로 정하지 않는다.

## 결과물

- 실기기 모델명 기록: `SM-A245N`
- Android 버전 기록: `16`
- 위 두 값이 P0.1의 완료 조건을 충족하는지에 대한 확인 기록

코드, 설정, 원본 백로그 JSON은 이 작업의 결과물이 아니다.

## 선행 작업

- P0.1의 deps는 없으므로 별도 선행 백로그 작업은 없다.
- 다만 이 확인 결과는 상위 P0의 실기기 검증과 이후 P1.2/P1.8 설치 확인에서 대상 기기를 식별하는 데 사용된다.

## 수행 순서

1. 딸 폰 실기기를 준비한다.
2. 설정에서 모델명을 확인하고 기록한다.
3. 설정에서 Android 버전을 확인하고 기록한다.
4. 기록된 두 값을 P0.1의 `done_when`과 대조한다.
5. 확인 근거와 남은 불확실성을 이 문서에 남긴다.

## done_when 확인 방법

P0.1의 완료 조건은 `모델명·안드로이드 버전을 기록함`이다. 다음 두 항목이 모두 구체적인 값으로 기록되어 있는지 확인한다.

| 확인 항목 | 현재 기록 | 판정 |
|---|---|---|
| 모델명 | `SM-A245N` | 충족 |
| Android 버전 | `16` | 충족 |

두 항목이 모두 기록되어 있으므로 완료 조건은 충족된다. 백로그 상태가 `in_review`인 것은 완료 근거 검토 대기 상태이며, 이 문서는 그 근거를 설명하는 문서다.
