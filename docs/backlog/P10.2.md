## 수행 순서

1. 공통 판정 `시작 <= 현재 < 종료`를 사용하는 현재 시각 상태를 만들고, 요일 선택 즉시 기기의 현재 로컬 시각을 다시 읽는다.
   - scheduleClock.scheduleStatus, useNow 훅 구현 완료

2. 요일별 화면은 선택한 요일에서 현재 시각에 해당하는 일정만 강조한다. 다른 요일은 현재 시각 기준 미리보기 문구를 보여 실제 오늘 진행 중 표시와 구별한다.
   - DailyScheduleList, WeekTimeGrid 구현 완료

3. 주간표는 오늘의 실제 진행 중 일정만 강조하고 선택 요일 미리보기 규칙을 주간표 전체로 확대하지 않는다. 과거/미래는 읽을 수 있는 대비의 연한 배경으로 표시한다.
   - WeekOverviewGrid 구현 완료, 색상 대비 확인 완료

4. 시작/종료 경계, 공백, 겹침, 무시각, 요일/탭 전환, 앱 복귀, 자정, 세트 변경과 시간 갱신·타이머 정리를 확인한다. DB·알림·위젯 정책은 유지한다.
   - 구현 완료, 에뮬레이터 동작 확인 완료

5. 폰 S23 Ultra 411dp 세로·가로 및 현재 시각 강조 확인 완료, 360/393dp 직접 확인은 P9·P10 일괄 검증 때 수행.
   - 구현 완료, 폰 S23 Ultra 확인 완료, 360/393dp 직접 확인 예정
