## 작업 목적

딸 폰에서 테스트 APK를 설치할 수 있는지 확인한다. 백로그 요약은 Family Link에서 ‘출처를 알 수 없는 앱’을 허용한 뒤 APK를 설치하는 것이며, 실패하면 Play Console 내부 테스트 대안을 검토하는 것이다.

## 쉬운 설명

딸 폰에 앱 설치 파일을 실제로 넣을 수 있는지 시험한다. 컴퓨터에서 설치 명령이 성공하는 것과 Family Link 설정 화면을 통해 직접 설치하는 것은 서로 다른 확인이므로 각각 기록한다.

## 필요한 입력

- 대상 기기: `SM-A245N`, Android `16`
- 테스트 파일: arm64-v8a debug APK
- 패키지명: `com.sewoong.kidtimetable`
- 확인 기준: P0.2의 summary와 done_when
- 대안 경로: Play Console 내부 테스트 방식 및 `docs/research.md` 4장

## 결과물

- APK 설치 성공 또는 실패 기록
- 대상 기기·APK 아키텍처·패키지명 등 확인 근거
- 실패 시 Play Console 내부 테스트 대안 검토 결과
- Family Link의 허용 UI 경로와 앱 실행 여부의 별도 확인 기록

## 선행 작업

- P0.2의 deps는 없음.
- P0.1에서 대상 기기 정보가 `SM-A245N`, Android `16`으로 기록되어 있다.

## 수행 순서

1. 대상 기기와 테스트 APK의 범위를 확인한다.
2. Family Link 제한 상태에서 APK 설치 경로를 확인한다.
3. 필요한 경우 ‘출처를 알 수 없는 앱’ 허용 후 APK를 설치한다.
4. 설치된 패키지와 앱 실행 여부를 확인한다.
5. 실패하면 Play Console 내부 테스트 대안을 검토하고 결과를 기록한다.
6. 각 결과를 done_when 근거와 대조한다.

## 현재 확인 기록

- `SM-A245N`(Android `16`)에 arm64-v8a debug APK를 ADB로 설치 성공했다.
- 설치 패키지는 `com.sewoong.kidtimetable`이다.
- Family Link 잠금 화면이 전면에 있어 앱 화면 실행은 검증하지 못했다.
- ADB 설치 성공은 Family Link의 ‘출처를 알 수 없는 앱’ 허용 UI 경로를 검증한 결과가 아니다.
- Play Console 내부 테스트 검토 결과는 아직 기록되지 않았다.

## done_when 확인 방법

P0.2의 조건은 (1) 딸 폰에 임의 APK가 설치됨을 확인하거나, (2) 설치 실패 시 내부 테스트 검토 결과를 기록하는 것이다. 현재 (1)은 ADB 설치 근거로 확인되지만 Family Link UI 경로와 앱 실행은 미확인이고, (2)도 미기록이다. 어느 경로를 완료 근거로 인정할지 보강 기록이 필요하다.
