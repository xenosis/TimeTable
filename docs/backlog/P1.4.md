## done_when 확인 방법

기준 조건은 다음과 같다.

> `src/theme/index.ts`에 색상·폰트크기·spacing·과목 팔레트가 정의되고 실제 화면에서 사용됨

확인 시 다음을 대조한다.

- `src/theme/index.ts`에 `colors`, `fontSize`, `spacing`, 과목별 `categoryPalette`가 정의되어 있는지 확인한다.
- 실제 화면이 해당 토큰을 import하고 배경, 글자, 간격, 버튼·칩 최소 크기 등의 스타일에 사용하는지 확인한다.
- `categoryPalette`의 항목별 `backgroundColor`·`textColor`가 실제 과목 표시 UI에 사용되는지 확인한다.

## 현재 확인 기록

- `src/theme/index.ts`에서 `colors`, `fontSize`, `spacing`, 8색 `categoryPalette`, 56dp `touchTarget.minimum`이 확인된다.
- `app/index.tsx`는 `colors`, `fontSize`, `spacing`, `touchTarget`을 import하여 배경, 글자 크기, 간격, 버튼·과목 칩 최소 크기에 사용한다.
- `app/index.tsx`의 과목 색상 미리보기는 `categoryPalette`를 순회해 각 항목의 `backgroundColor`를 배경색으로, `textColor`를 글자색으로 사용하며 8개 과목 라벨을 표시한다.
- 따라서 제공된 코드 기준으로 P1.4의 정의 및 실제 화면 사용 조건은 모두 확인된다. 다만 이 화면은 주석상 P0.4 검증용 미리보기이고, 실제 시간표 화면 적용은 P2 화면 작업에서 교체될 예정이다.
- 백로그 기록상 lint·typecheck·Jest·Android debug build 통과 기록은 있으나, 이 문서 작업에서는 품질 검사를 실행하지 않았다.
