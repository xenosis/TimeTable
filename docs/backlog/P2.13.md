## 목적

사용자 엑셀 시간표(시간표1~3.png)와 동일한 레이아웃으로 주간 시간표를 표시한다. 첫 칼럼은 시간 범위이고 월~금 칼럼에 일정이 시간에 맞게 배치되며, 여러 시간을 차지하는 일정은 하나의 큰 칸으로 표시된다. 가로 화면에서는 표가 화면 높이를 최대한 활용하도록 헤더와 탭을 줄여 일주일치를 한눈에 볼 수 있게 한다.

## 쉬운 설명

시간표 화면의 `주간 한눈에 보기` 탭을 누르면 세로축이 시간(09:00~09:40, 09:50~10:30 등)인 표가 나타난다. 가로축은 월~금 5개 칼럼이고, 각 칸에는 그날 일정을 시간에 맞게 배치한다. 예를 들어 화요일 14:10~16:20 리틀 포레스트는 화 칼럼의 14:10~16:20 행 영역 전체를 차지하고, 세로 스크롤로 전체 시간대를 볼 수 있다. 가로로 폰을 눕히면 표가 화면을 더 넓게 차지해서 칼럼과 행을 더 명확히 볼 수 있다.

## 결과물

- `src/components/WeekTimeGrid.tsx` (신규)
  - 입력: `TimetableItem[]` 배열, `selectedWeekday`, `onDaySelect` 콜백, 현재 테마
  - 출력: 첫 칼럼=시간, 월~금 칼럼의 표 컴포넌트
  - 구현 세부사항:
    - `calculateRowBoundaries`를 호출해 행 경계 배열 계산
    - 각 요일별로 `getTimetableItemsForWeekday`를 호출해 일정 배열 조회
    - 일정을 행 인덱스에 매핑: `(시작 시각 - 첫 경계) / 행 높이`로 셀의 rowSpan 계산
    - 여러 행을 차지하는 일정은 CSS Grid나 FlexBox의 `flex-grow`/`rowSpan` 같은 기법으로 병합 표시
    - 칸 내에 "HH:MM~HH:MM 제목" 텍스트와 과목 색상(배경), 아이콘 표시
    - 시간 경계와 정확히 맞지 않는 시간(예: 14:10~16:20은 14:10과 16:20 사이 행 경계가 없을 수 있음)은 칸 내에 정확한 시각 "14:10~16:20" 추가 표기하고 표 밖에 시각 범위 표시
    - 일정 없는 요일은 "-" 텍스트 표시
    - 요일 머리글·일정 칸 탭 시 `onDaySelect(weekday)` 콜백으로 해당 요일 하루 보기로 이동
  - 가로 레이아웃 대응 (`useWindowDimensions`):
    - 세로 폭(약 360dp): 시간 칼럼 약 50dp, 요일 칼럼 각 약 62dp
    - 가로 폭(약 800dp): 시간 칼럼 약 70dp, 요일 칼럼 각 약 146dp. 가로 모드에서는 앱 헤더와 하단 탭 바를 숨겨 표 영역을 최대화
    - 가로에서는 폰트 크기, 셀 패딩을 기존 유지하되 칼럼 폭이 늘어나 텍스트가 자연스럽게 수용

  - 중복/겹치는 일정 처리 (같은 시간에 여러 일정이 있는 경우)
