## 작업 목적

NEIS(나이스) API를 통해 학교 급식 식단 정보를 가져와 아이의 '오늘' 화면에 카드로 표시합니다.

---

## 쉬운 설명

매일 아침 아이가 앱을 열었을 때, "오늘의 급식 🍚" 카드에 학교 급식 메뉴를 보여줍니다:

1. **식단 조회**: 저장된 학교(가족 설정에서 선택)의 해당 주(월~일) 급식을 NEIS에서 하루 한 번 가져옴
2. **오프라인 대응**: 인터넷이 없으면 폰에 보관된 같은 주 식단을 사용
3. **정보 정제**: 메뉴 이름에서 알레르기 번호('(1.2.5)' 형태)와 학교별 특수 기호('ㅅ', '(a)', '(동)' 등) 제거
4. **화면 표시**:
   - 급식이 있는 날: 메뉴 목록 표시
   - 급식이 없는 날(주말, 공휴일 등): '오늘은 급식이 없어요' 안내
   - 학교 미설정 폰: 카드 미표시
