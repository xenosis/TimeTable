# P8.4 — 아빠용 주간 리포트

## 기준

- 백로그 schema version: `1.1`
- 백로그 SHA-256: `24ee20b4a70678d7dca650cb3eeecf662862f6cc6de2b5bc36ae687ad59b4b58`
- 기준 작업 상태: `needs_info`
- 상위 작업: `P8`

## 목적

아빠 역할 화면에서 동기화된 가족 데이터를 바탕으로 주간 할 일 완료율과 스티커 원장 추이를 확인한다.

## 선행 작업

- P6.6 서버 동기화
- P6.8 아빠 화면

현재 딸 폰의 PIN 영역에 로컬 SQLite 리포트를 미리 넣는 방식은 아빠용 역할 화면 요구사항과 맞지 않아 제거했다.

## 구현 범위

1. 서버 데이터를 기준으로 날짜별 예정·완료 수를 집계한다.
2. `sticker_ledger`의 적립·회수·사용을 포함한 날짜별 변화 또는 누적 추이를 표시한다.
3. 빈 데이터, 주 경계, 동기화 지연, 원장 증감을 검증한다.

## 확인할 결정

- 주간 범위: 일요일~토요일 전체 또는 오늘까지
- 스티커 추이: 날짜별 증감 또는 누적

두 결정과 P6.6·P6.8 완료 뒤 구현을 재개한다.
