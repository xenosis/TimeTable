## 작업 목적

오늘 날짜에 해당하는 할 일을 읽어 화면에 보여 주고, 아이가 각 항목을 체크하거나 취소할 수 있게 한다. 전체 항목 수와 완료 수를 진행률로 함께 표시한다. PIN이 설정된 후에는 실패 카운터가 앱 재진입으로 초기화되지 않도록 보호한다.

## 쉬운 설명

홈 화면의 `오늘의 할 일` 카드에서 오늘 해야 할 일을 한눈에 확인한다. 반복 요일 할 일과 특정 날짜 할 일을 모두 읽으며, 항목을 누르면 완료와 미완료가 전환된다. 완료된 항목은 진행률에 바로 반영되고, 화면을 다시 열어도 완료 기록이 남는다. 테마를 바꾸면 카드와 완료 상태의 색도 함께 바뀐다.

## 필요한 입력

- P4.4 백로그 항목과 `docs/research.md`의 오늘 할 일 요구사항
- P4.2에서 생성한 `tasks` 및 `task_completions` 테이블
- 현재 활성 테마의 색상·카드·강조 토큰
- 오늘 날짜와 요일
- PIN 보안 모듈(src/security/pin.ts)의 잠금 상태 쿼리

보상 수량은 이 화면의 선행 입력으로 사용하지 않는다. 할 일 하나를 체크하는 동작은 완료 기록만 저장하며, 개별 할 일 보상은 지급하지 않는다.

## 결과물

- `src/components/TodayTasksCard.tsx`

  - 완료 수/전체 수와 가로 진행률을 표시한다.
  - 항목을 누르면 완료 또는 취소로 전환한다.

  - 활성 테마의 카드 배경·테두리·본문·강조 색을 사용한다(WCAG AA 4.5:1 대비율 보장).
  - `onChanged` 콜백을 제공해 체크 직후 연속일수·보석판 같은 상관 UI도 즉시 갱신되게 한다.
- `src/db/taskRepository.ts`
  - 오늘 목록을 조회한다.
  - 완료 시 `task_completions`에 날짜별 기록을 저장하고, 취소 시 해당 기록을 삭제한다.
- `app/index.tsx` (아이용 첫 화면) / `app/manage.tsx` (관리자 PIN 뒤 편집)
  - 아이용 첫 화면에는 오늘 시간표·할 일·보석판만 표시한다.
  - 관리자는 PIN 입력 뒤 별도 편집 영역에서 할 일을 수정한다.
  - 완료 이력은 보존하되 일반 편집 목록에는 섞이지 않는다.

## done_when 확인 방법

**구현 완료 조건:**
- 오늘 날짜의 특정 날짜 할 일이 목록에 표시되는지 확인한다.
- 오늘 요일을 포함한 반복 할 일이 목록에 표시되는지 확인한다.
- 미완료 항목을 누르면 체크 상태와 완료 수/진행률이 증가하는지 확인한다.
- 체크된 항목을 다시 누르면 완료가 취소되고 완료 수/진행률이 감소하는지 확인한다.
- 앱을 다시 열었을 때 해당 날짜의 완료 상태가 유지되는지 확인한다.
- 오늘 할 일이 없을 때 빈 상태 문구가 표시되는지 확인한다.
- 테마를 바꿨을 때 카드 배경·테두리·강조 색이 활성 테마에 맞게 바뀌는지 확인한다.
- 체크 직후 보석판(연속일수 등)이 즉시 갱신되는지 확인한다.

**PIN 잠금 관련:**
- PIN이 설정되고 5회 실패한 뒤 잠금이 활성화되면, 앱을 백그라운드→포그라운드로 반복해도 잠금이 해제되지 않는지 확인한다(실패 카운터 초기화 방지).

**색상 대비:**
- 완료 축하 문구(success 녹색)가 흰 카드 배경 위에서 4.5:1 대비를 만족하는지 확인한다.
- 실패/오류 문구(danger 빨강)도 4.5:1 대비를 만족하는지 확인한다.

**코드 검증:**
- `npm run test:ci`: 관련 테스트 모두 통과.
- 최근 `npm run check` 기록에서 지침 동기화, 코드 길이, lint, typecheck, Jest, Android debug build가 모두 통과했는지 확인한다.

## 실기기 확인 절차

실제 스마트폰(갤럭시 A 시리즈)에서 다음 순서로 확인한다. 각 단계는 결과를 `통과` 또는 `실패`로 기록하고, 실패하면 화면 캡처와 재현 순서를 함께 남긴다.

1. 관리자 PIN 뒤에서 오늘 요일 반복 할 일 1개(예: P44check)와 오늘 날짜 할 일 1개를 준비한다.
2. PIN 화면을 닫고 홈 화면의 `오늘의 할 일` 카드에서 두 항목이 모두 보이는지 확인한다.
3. 두 항목 중 하나를 눌러 체크한 뒤 `1/2 완료`와 진행률 절반이 표시되는지 확인한다.
4. 체크한 항목을 다시 눌러 미완료로 되돌리고 `0/2 완료`와 진행률 0%가 되는지 확인한다.
5. 한 항목을 체크한 상태에서 앱을 백그라운드로 보냈다가 다시 열어 체크 상태가 유지되는지 확인한다.
6. 날짜 지정 항목과 반복 항목이 아닌 항목은 오늘 목록에 잘못 나타나지 않는지 확인한다.
7. 할 일을 모두 체크했을 때 전체 완료 수와 진행률 100%가 표시되는지 확인한다. 이 동작만으로 개별 보석이 지급되지 않는 것도 확인한다.
8. 체크 직후 보석판(연속일수) 등 관련 UI가 즉시 갱신되는지 확인한다.
9. 테마 선택에서 다른 테마를 고른 뒤 카드 배경·테두리·완료 상태 색이 함께 바뀌는지 확인한다.
10. 오늘 대상 할 일을 모두 제거하거나 다른 날짜로 바꾼 뒤 `오늘 할 일이 없어요.`가 표시되는지 확인한다.
