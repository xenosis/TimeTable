## 목적

앱이 실행 중이든 백그라운드 상태든, 또는 완전히 종료된 상태든 관계없이, 알림을 탭하면 해당 일정 상세 화면으로 바로 이동하도록 하기 위함.

---

## 쉬운 설명

알림 센터에서 알림을 탭하면:
1. 앱이 켜지고 (또는 이미 켜져 있으면)
2. 그 알림이 나온 일정의 상세 화면으로 이동
3. 관리자 설정 화면에 있던 상태에서도 같은 일정 화면으로 이동
4. 일정이 삭제되었으면 안내 메시지를 표시

## done_when 확인 방법

### 완료 기준

**앱 종료 상태 포함**, 다음 **모든** 조합에서 알림 탭 시 해당 화면으로 이동:

1. **일반 알림 (진행 중 알림)**
   - ✓ 앱 실행 중: 해당 일정 상세 화면 이동 (수정 후 확인)
   - ✓ 앱 백그라운드: 해당 일정 상세 화면 이동
   - ? 앱 종료 (프로세스 kill): 콜드 스타트 후 해당 일정 상세 화면 이동

2. **전용 알람**
   - ✓ 앱 실행 중: 해당 일정 상세 화면 이동 (AlarmActivity → schedule/[id])
   - ✓ 앱 백그라운드: 해당 일정 상세 화면 이동
   - ? 앱 종료: 콜드 스타트 후 해당 일정 상세 화면 이동

3. **할 일 알림**
   - 모든 상태(실행 중, 백그라운드, 종료)에서 **홈 화면**(또는 첫 화면)으로 이동
   - 이유: 할 일 상세 화면이 없음

4. **삭제된 일정**
   - 알림 탭 시 "이 일정이 더 이상 없습니다" 등 안내 메시지 표시

5. **엣지 케이스**
   - 관리자 PIN 화면에 있을 때 일정 알림 탭 → 일정 화면으로 이동 (PIN 화면 건너뜀)

### 실행 방법

**6가지 조합 실기기 검증**:

| 알림 종류 | 앱 상태 | 기대 동작 | 상태 |
|---------|--------|---------|------|
| 일반 알림 | 실행 중 | 일정 상세 | ✓ |
| 일반 알림 | 백그라운드 | 일정 상세 | ✓ |
| 일반 알림 | 종료 | 콜드 스타트 → 일정 상세 | ? |
| 전용 알람 | 실행 중 | 일정 상세 | ✓ |
| 전용 알람 | 백그라운드 | 일정 상세 | ✓ |
| 전용 알람 | 종료 | 콜드 스타트 → 일정 상세 | ? |
| 할 일 알림 | 모든 상태 | 홈 화면 | ✓ |

**구체적 테스트**:
1. 앱에서 오늘 시간표에 여러 일정 생성
2. 예약 알림 목록에서 상태 확인 (rolling 진행 보임)
3. 알림 센터에서 특정 알림 탭
4. 해당 일정 화면이 나타나는지 확인
5. 앱을 백그라운드로 보냈다가 알림 탭 → 같은 화면으로 이동 확인
6. 앱을 완전히 종료 → 알림 탭 → 앱 재시작 후 해당 화면으로 이동 확인

**관리자 화면에서의 테스트**:
- 앱을 열고 관리자 PIN 입력 → PIN 화면 진입
- 이 상태에서 일정 알림 탭
- 일정 상세 화면이 나타나고 PIN 화면은 뒤로 밀림
