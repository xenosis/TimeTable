# P1.3 — 기본 구성: 폴더 구조, Zustand, expo-sqlite

## 기준 입력

- 백로그 schema version: `1.1`
- 백로그 SHA-256: `15af97263a85784bfb3a18b7d19434b0044adbfd7ba229cf46f6b8ea10c8f1b3`
- 기준 작업: `P1.3`
- 기준 상태: `in_review`
- 상위 작업: `P1`
- 선행 작업: `P1.1`

이 문서는 제공된 백로그 입력을 설명하기 위한 문서다. 원본 `backlog.json`, 프로그램 코드, 백로그 상태는 이 문서 작업에서 수정하지 않는다.

## 목적

앱의 로컬 데이터베이스와 상태 관리, 화면·공통 UI 코드를 담을 기본 `src/` 폴더 구조를 준비한다. 이 작업의 범위는 폴더 구조를 만들고 Zustand와 `expo-sqlite` 의존성을 프로젝트에 추가하는 데 있다.

## 쉬운 설명

앱의 파일을 역할별로 정리할 서랍을 먼저 만들고, 앱 상태를 관리하는 Zustand와 휴대폰 안에 데이터를 저장할 SQLite 도구를 준비하는 작업이다. 실제 시간표 테이블이나 화면 기능을 만드는 일은 이 작업의 완료 조건에 포함되지 않는다.

## 필요한 입력

- P1.3의 `summary`, `deps`, `done_when`, `where` 정보
- 선행 작업 P1.1의 완료 결과: Expo SDK 57 + TypeScript 프로젝트 기반
- 프로젝트의 `src/` 구조
- `package.json`의 의존성 목록
- 관련 요구사항 문서: `docs/research.md`, `docs/tasks.md`
- 프로젝트 운영 규칙: `AGENTS.md`, `CLAUDE.md`

백로그에 명시되지 않은 구체적인 DB 스키마, store API, 화면 설계, 마이그레이션 방식은 이 작업의 입력으로 임의 확정하지 않는다.

## 결과물

- `src/db/`
- `src/store/`
- `src/utils/`
- `src/screens/`
- `src/components/`
- `src/theme/`
- `package.json`에 등록된 Zustand 의존성
- `package.json`에 등록된 `expo-sqlite` 의존성
- 위 항목이 P1.3의 `done_when`을 충족하는지에 대한 확인 기록

## 선행 작업

P1.1 `프로젝트 생성 (Expo SDK 57 + TypeScript)`가 선행되어야 한다. 제공된 백로그 입력에서 P1.1은 `done`이며, P1.3의 유일한 의존성으로 기록되어 있다.

## 수행 순서

1. 제공된 기준 백로그 입력에서 P1.3의 범위와 완료 조건을 확인한다.
2. P1.1의 프로젝트 기반이 준비되었는지 확인한다.
3. `src/db`, `src/store`, `src/screens`, `src/components`를 만들고 기존 `src/utils`, `src/theme`을 유지한다.
4. 프로젝트 의존성에 Zustand와 `expo-sqlite`가 존재하는지 확인한다.
5. 각 폴더와 두 의존성이 P1.3의 `done_when` 조건을 충족하는지 항목별로 대조한다.
6. 구현 결과와 확인 근거를 이 문서에 기록하고, 개발 작업의 상태와 문서화 상태를 구분한다.

## done_when 확인 방법

다음 여섯 폴더의 존재를 확인한다.

- `src/db`
- `src/store`
- `src/screens`
- `src/components`
- `src/utils`
- `src/theme`

그 다음 `package.json`의 `dependencies`에서 `zustand`와 `expo-sqlite`가 각각 존재하는지 확인한다. 여섯 폴더와 두 의존성이 모두 확인되면 P1.3의 `done_when` 조건을 충족한 것으로 기록한다. 이 조건에 없는 실제 DB 테이블, store 구현, 화면 구현은 추가 완료 기준으로 취급하지 않는다.

## 현재 확인 기록

- 제공된 백로그 입력의 P1.3 상태는 `in_review`이며, 담당자는 `codex`다.
- 최신 로그에는 `src/db`, `src/store`, `src/screens`, `src/components` 구조와 `expo-sqlite`, Zustand 설치가 완료되었다고 기록되어 있다.
- 현재 작업공간 확인 결과, `src/db`, `src/store`, `src/screens`, `src/components`에 `.gitkeep`이 있고 `src/utils`, `src/theme`에도 파일이 존재한다.
- 현재 `package.json`에는 `expo-sqlite` `~57.0.3`과 Zustand `^5.0.15`가 의존성으로 기록되어 있다.
- 백로그 로그에 Expo 호환성 검사와 전체 품질 검사(Android debug build 포함) 통과가 기록되어 있다. 이 문서 작업에서는 해당 명령을 다시 실행하지 않는다.
- 따라서 문서에 확인된 범위에서는 P1.3의 `done_when` 조건이 충족된 것으로 정리되며, 백로그 상태 변경과 최종 완료 처리는 메인 실행의 책임이다.

## 확인 질문

P1.3의 완료 조건을 판단하는 데 필요한 추가 결정 사항은 기준 입력에 없다. DB 스키마, Zustand store 설계, 폴더별 초기 파일 구성처럼 백로그에 없는 세부사항이 필요해지는 경우에는 별도 결정이 필요하다.
