## 목적

주간 시간표가 앱의 핵심 화면이므로, 사용자가 폰을 눕혀 가로 보기로 전환했을 때 일주일치를 더 넓은 화면에서 한눈에 볼 수 있도록 한다. 현재 앱은 세로(`portrait`) 고정이라 가로로 눕혀도 화면이 회전하지 않으므로, 제약을 해제해 가로 보기를 활성화한다. 다만 잠금 화면 알람 화면(`AlarmActivity`)은 의도적으로 세로 유지한다.

## 쉬운 설명

폰을 옆으로 눕히면 화면이 자동으로 회전해서 가로 긴 화면이 된다. 시간표 화면이 가로로 훨씬 넓어져서 월~금 요일 칼럼이 더 크게 보이고, 오늘 화면도 가로에 맞게 레이아웃이 재조정된다(예: 요일 칩이 한 줄로 나열). 다만 잠금 화면에서 울리는 알람 화면은 계속 세로만 지원한다.

## 필요한 입력

- 현재 설정 상태
  - `app.json`의 `plugins/expo-screen-orientation` 또는 `orientation` 필드
  - `android/app/src/main/AndroidManifest.xml`의 `<activity>` 태그 `android:screenOrientation` 설정
  - 각 화면(`HomeScreen`, `TimetableScreen` 등)의 레이아웃이 가로에 대응하는지 여부
- Expo Router와 React Native의 `useWindowDimensions` 훅

## 결과물

- `app.json`
  - `plugins/expo-screen-orientation` 설정 확인 또는 새로 추가 (필요시)
  - 전체 앱 `orientation` 기본값을 `"default"` 또는 `"portrait"` 유지하되, 동적 설정 가능하도록 준비
  - 또는 `orientation: "default"` 설정으로 시스템의 회전 설정을 따르도록 함
- `android/app/src/main/AndroidManifest.xml`
  - `<activity android:name=".MainActivity" android:screenOrientation="...">` 기존 `portrait` 해제 또는 속성 제거
  - `<activity android:name=".AlarmActivity" android:screenOrientation="portrait">` 유지 (알람 화면은 세로 고정)
  - 필요시 `android:configChanges="orientation|screenSize"` 추가 (화면 회전 시 Activity 재생성 방지)
- 각 화면 컴포넌트 (`app/(tabs)/home.tsx`, `app/(tabs)/timetable.tsx`, `app/(tabs)/gems.tsx`, `app/manage.tsx`)
  - `useWindowDimensions`로 현재 화면 크기 감지
  - 가로 폭 > 세로 폭인 경우 레이아웃 재조정 (예: 여백 감소, 요소 배치 변경)
  - 기존 세로 최적화 UX는 유지하되, 가로에서도 깨지지 않음
- `npm run check` 통과 기준: 지침 동기화, 코드 길이, lint, typecheck, Jest, Android x86_64 debug build
