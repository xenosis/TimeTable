# P1.12 기본 테마 및 대비 테스트

## 기준 입력

- 기준 schema version: `1.1`
- 기준 backlog SHA-256: `45ad75560c4982335726758d28f732f5fe419afe8514af6185ae102ef9a030eb`
- 기준 작업 상태: `in_review`
- 상위 작업: `P1`
- 선행 작업: `P1.9` (`done`)

## 목적

최소 두 개의 독자적인 기본 테마를 등록하고, 필수 텍스트의 색상 대비와 알 수 없는 의미 키의 fallback 동작을 테스트로 확인한다.

## 쉬운 설명

테마를 두 가지 이상 선택할 수 있게 하고, 각 테마에서 글자가 충분히 잘 보이는지 확인한다. 등록되지 않은 색상·아이콘 의미 키가 들어와도 안전한 기본값으로 처리되는지 확인한다.

## 필요한 입력

- `P1.9`에서 정의한 `ThemeDefinition`
- 테마 레지스트리와 `color_key`, `icon_key` 해석 API
- 기본 테마에 필요한 색상, 카테고리 텍스트, 아이콘 glyph 토큰
- 대비 계산 함수와 Jest 테스트 환경
- 관련 요구사항: `docs/research.md` D8

## 결과물

- `src/theme/index.ts`: 서로 다른 ID를 가진 기본 테마 최소 2개와 테마 레지스트리
- `src/theme/contrast.ts`: 대비 계산 및 검증에 필요한 테마 대비 로직
- `__tests__/theme.test.ts`: 테마 수·고유 ID·필수 텍스트 대비·알 수 없는 의미 키 fallback 테스트
- 이 작업의 문서: `docs/backlog/P1.12.md`

## 선행 작업

- `P1.9`의 테마 계약과 테마 레지스트리가 완료되어 있어야 한다.

## 수행 순서

1. `P1.9`의 `ThemeDefinition`과 테마 레지스트리 계약을 확인한다.
2. 서로 다른 ID를 가진 기본 테마를 최소 2개 등록한다.
3. 각 테마의 필수 색상·카테고리 텍스트·아이콘 glyph 토큰을 확인한다.
4. 모든 필수 텍스트 조합의 색상 대비가 기준을 충족하는지 검증한다.
5. 알 수 없는 테마 ID와 `color_key`, `icon_key`가 기본 테마 또는 `other`로 fallback 되는지 테스트한다.
6. `__tests__/theme.test.ts`를 실행하고 결과와 리뷰 반영 여부를 기록한다.

## done_when 확인 방법

- `src/theme/index.ts`의 `themes` 레지스트리에 서로 다른 ID의 테마가 최소 2개 있는지 확인한다.
- 각 테마가 필수 색상·카테고리 텍스트·아이콘 glyph 토큰을 제공하는지 레지스트리 검증으로 확인한다.
- 필수 텍스트의 모든 조합에 대한 대비가 `4.5:1` 이상인지 테스트로 확인한다.
- 알 수 없는 테마 ID는 기본 테마로, 알 수 없는 `color_key`와 `icon_key`는 `other`로 해석되는지 테스트로 확인한다.
- `__tests__/theme.test.ts`가 통과하는지 확인한다.
