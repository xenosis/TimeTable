# P11 — 오늘·내 보석 화면 디자인 개선

## 기준 입력 및 상태

- schema version: 1.1
- 기준 백로그 SHA-256: `7b9b5de91a6d7f0d6d39db4f810e816f641eea77441057fbd76d0118e14a86c7`
- 백로그 상태: `in_review` (기준 CLI 입력, 2026-10-05)
- 담당: claude
- 선행 작업: P13 (의존성)
- 작업 문서: [docs/tasks.md P11](../tasks.md), [P13 자동 지급 중단과 수량 편집](P13.md), [P4.13 실물 보석 자격·요청·지급](P4.13.md)

## 목적

오늘 화면과 내 보석 화면을 새 화면 구성에 맞게 재구성한다. 오늘에는 날짜·인사, 현재/다음 일정의 명암, 할 일 체크 상태를 명확히 보여 주고, 내 보석에는 테마 그림·보유량·목표 진행과 컬렉션을 보여 준다. 기존 체크 저장, 알림 재예약, 테마와 보상 계산 흐름을 보존한다.

## 쉬운 설명

아이가 오늘 일정과 할 일을 쉽게 확인하고, 내 보석 화면에서 실제 가진 보석의 장부와 진행 정보를 읽을 수 있게 화면을 정리하는 작업이다. P13의 최종 정책에 따라 보석 수는 직접 관리하며 체크·취소나 완료 보상으로 자동 변경하지 않는다. 연속 달성 자격·요청·지급은 P4.13 정책을 따른다. 오늘 탭의 전체 배치(날짜·응원·일정·할 일 우선순위)는 P15가 별도 작업으로 진행한다.

## 필요한 입력

- `docs/tasks.md`의 P11 요구와 P13 최종 보석 정책
- [P4.13](P4.13.md)의 장부·자격·요청·지급 정책
- [P15](P15.md) 오늘 탭 정보 우선순위 변경의 배치 결정
- 현재 오늘/내 보석 화면 및 세로·가로·테마 화면 확인 자료
- 전체 검사와 등록 리뷰의 실행 결과

## 결과물

- 재구성된 오늘 및 내 보석 화면
- 기존 체크·알림·테마·완료/보상 계산 흐름의 회귀 확인 결과
- 화면 확인, 검사, 리뷰 결과와 아직 해결되지 않은 조건

## 선행 작업

P13은 자동 보석 지급 중단과 수량 편집을 구현하며, P11의 화면 재구성은 P13의 최종 정책이 확정되어야 한다. P13이 완료(done) 상태이므로 그 정책을 기준으로 P11의 화면 재구성을 진행한다. 오늘 탭의 전체 배치는 P15가 담당하며, 이 작업만으로 P4의 실기기 확인이나 사용자 결정 조건을 완료 처리하지 않는다.

## 수행 순서

1. `docs/tasks.md`의 P11 기준과 P13·P4.13의 보석 정책, P15의 오늘 탭 배치를 확인한다.
2. 오늘/내 보석 화면의 세로·가로·테마 상태를 확인하고, 체크·취소·조회·복귀 갱신 흐름을 대조한다.
3. 자동 보석 지급 중단과 직접 수량 관리 정책을 화면 및 기존 계산 경로에 대조한다. 캐릭터 테마의 그림 변화용 환산은 장부 계산과 구분한다.
4. 화면 근거, 전체 검사, 리뷰 결과를 각각 기록하고 미확인 항목을 분명히 남긴다.

## done_when 확인 방법

오늘과 내 보석 화면 재구성(오늘 탭 배치는 P15가 대체). 오늘: 할 일 체크·취소, 일정 세트 조회 실패 시 오류·재시도, 앱 복귀·자정 갱신 유지. 내 보석: 목표 있음/없음, 꾸미기 테마 전환 유지. 보석 장부·자격 정책 검증은 P13·P4.13 책임으로 구분. 화면 확인(에뮬레이터), 전체 검사 및 리뷰 통과.

완료 판정 기준:
- 오늘 화면: 할 일 체크·취소 동작, 일정 세트 조회 실패 시 오류 표시 및 재시도 버튼 확인, 앱 복귀 및 자정 기준 갱신
- 내 보석 화면: 목표 없음 상태, 테마 꾸미기 선택·전환 동작
- 보석 자동 지급 중단 및 수량 직접 관리: P13의 책임으로 분리
- 보석 자격·요청·지급 정책: P4.13 확정 정책 준용
- 에뮬레이터 화면 확인: 세로·가로·테마 변환 동작
- 전체 검사 통과 (`npm run check`)
- 등록 리뷰 통과 (dispatcher 성공, Critical/High 지적 해결)

실기기·사용자 판단 조건은 이 P11 문서만으로 대체하지 않는다.
