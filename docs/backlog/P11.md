## 목적

변경된 시간표·관리자 디자인을 참고해 오늘의 일정과 할 일, 보석 컬렉션과 목표를 명료하고 매력적으로 구성한다.

## 쉬운 설명

오늘 화면에서 날짜·인사, 현재/다음 일정, 할 일과 보석 요약을 쉽게 보고, 내 보석 화면에서 보유량·목표·컬렉션을 확인할 수 있게 정리한다. 아이가 쓰는 글자 크기와 터치 영역은 유지한다.

## 필요한 입력

- `docs/tasks.md` P11 및 기준 백로그 summary/done_when
- 기존 화면과 연동: `app/(tabs)/index.tsx`, `app/(tabs)/stickers.tsx`, 할 일·보석·테마 관련 컴포넌트
- 현재 테마 및 체크/완료 이력 데이터 흐름
- 확인 화면 및 품질 기록: 아래 진행 근거 참조

## 결과물

- 재구성된 오늘 화면과 내 보석 화면
- 체크 저장·완료 이력·알림 재예약 등 기존 흐름의 동작 확인
- 보석 수동 관리와 자동 지급 중단은 최종 정책 P13을 따른다. P11의 기존 주간·월간 자동 보상 유지 문구는 superseded.
- 화면 비교·전체 검사·리뷰 근거와 미완료 조건의 구분

## 선행 작업

백로그 `deps`는 비어 있다. P4의 `needs_info` 상태는 이 화면 작업으로 해소되거나 완료 처리되지 않는다.

## 수행 순서

1. 오늘·내 보석 화면의 현재 구성과 체크 저장·완료 이력·테마 흐름을 확인한다.
2. 날짜·인사, 현재/다음 일정, 할 일 진행/완료, 보석 합계와 컬렉션·목표가 읽히도록 화면을 재구성한다.
3. 자동 지급 정책은 P13 최종 결정을 따른다: 체크/취소/완료 이력은 칭찬·이력만 바꾸고 보유량을 자동 변경하지 않으며, 실물 보석 수는 아이가 직접 수정한다.
4. 세로·가로와 테마 상태를 포함한 화면 근거를 확인하고 기능/검사/리뷰 결과를 각각 기록한다.

## done_when 확인 방법

> 오늘과 내 보석 화면 재구성, 기존 체크·보상·테마 기능 유지, 화면 확인과 전체 검사 및 리뷰 통과

완료 전 오늘과 보석 화면의 실제 표시를 근거와 대조하고, 기존 체크·테마 동작 및 P13 보석 정책을 분리해 확인한다. 전체 검사와 리뷰는 실제 결과가 확인될 때만 완료 근거로 기록한다.
