## 목적

오늘 화면과 내 보석 화면을 새 화면 구성에 맞게 재구성한다. 오늘에는 날짜·인사, 현재/다음 일정의 명암, 할 일 체크 상태를 명확히 보여 주고, 내 보석에는 테마 그림·보유량·목표 진행과 컬렉션을 보여 준다. 기존 체크 저장, 알림 재예약, 테마와 보상 계산 흐름을 보존한다.

## 쉬운 설명

아이가 오늘 일정과 할 일을 쉽게 확인하고, 내 보석 화면에서 실제 가진 보석의 장부와 진행 정보를 읽을 수 있게 화면을 정리하는 작업이다. P13의 최종 정책에 따라 보석 수는 직접 관리하며 체크·취소나 완료 보상으로 자동 변경하지 않는다. 연속 달성 자격·요청·지급은 P4.13 정책을 따른다. 오늘 탭의 전체 배치(날짜·응원·일정·할 일 우선순위)는 P15가 별도 작업으로 진행한다.
