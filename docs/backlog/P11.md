# P11 — 오늘·내 보석 화면 디자인 개선

## 기준 입력 및 상태

- schema version: 1.1
- 기준 백로그 SHA-256: `1efc75d2e5a3536986545592fdc55ce541f68e04b24e3e290aacd03713655a06`
- 백로그 상태: `in_review` (기준 CLI 입력)
- 담당: codex
- 선행 작업: 없음 (`deps: []`)
- 작업 문서: [docs/tasks.md P11](../tasks.md), [실물 보석 정책 P4.13](P4.13.md)

## 목적

오늘 화면과 내 보석 화면을 새 화면 구성에 맞게 재구성한다. 오늘에는 날짜·인사, 현재/다음 일정의 명암, 할 일 체크 상태, 보석 합계를 명확히 보여 주고, 내 보석에는 테마 그림·보유량·목표 진행과 컬렉션을 보여 준다. 기존 체크 저장, 알림 재예약, 테마와 보상 계산 흐름을 보존한다.

## 쉬운 설명

아이가 오늘 일정과 할 일을 쉽게 확인하고, 내 보석 화면에서 실제 가진 보석의 장부와 진행 정보를 읽을 수 있게 화면을 정리하는 작업이다. P13의 최종 정책에 따라 보석 수는 직접 관리하며 체크·취소나 완료 보상으로 자동 변경하지 않는다. 연속 달성 자격·요청·지급은 P4.13 정책을 따른다.

## 필요한 입력

- `docs/tasks.md`의 P11 요구와 P13 최종 보석 정책
- [P4.13](P4.13.md)의 장부·자격·요청·지급 정책
- 현재 오늘/내 보석 화면 및 세로·가로·테마 화면 확인 자료
- 전체 검사와 등록 리뷰의 실행 결과

## 결과물

- 재구성된 오늘 및 내 보석 화면
- 기존 체크·알림·테마·완료/보상 계산 흐름의 회귀 확인 결과
- 화면 확인, 검사, 리뷰 결과와 아직 해결되지 않은 조건

## 선행 작업

기준 입력에서 `deps`는 비어 있다. P4의 별도 실기기 확인이나 사용자 결정 조건은 이 화면 작업만으로 완료 처리하지 않는다. P13은 기준 입력에서 `in_review`이며, 그 자체의 미완료 상태를 P11의 정책 근거로 완료 처리하지 않는다.

## 수행 순서

1. `docs/tasks.md`의 P11 기준과 P13·P4.13의 보석 정책을 확인한다.
2. 오늘/내 보석 화면의 세로·가로·테마 상태를 확인하고, 체크·취소·조회·복귀 갱신 흐름을 대조한다.
3. 자동 보석 지급 중단과 직접 수량 관리 정책을 화면 및 기존 계산 경로에 대조한다. 캐릭터 테마의 그림 변화용 환산은 장부 계산과 구분한다.
4. 화면 근거, 전체 검사, 리뷰 결과를 각각 기록하고 미확인 항목을 분명히 남긴다.

## done_when 확인 방법

> 오늘과 내 보석 화면 재구성, 기존 체크·보상·테마 기능 유지, 화면 확인과 전체 검사 및 리뷰 통과

오늘/내 보석 재구성 및 체크·보상·테마 기능 보존을 실제 화면과 회귀 자료로 대조한다. 화면 확인, 전체 검사, 등록 리뷰가 모두 성공했는지 결과를 따로 확인한다. 실패한 리뷰 실행이나 dispatcher 오류는 리뷰 통과로 간주하지 않는다. 실기기·사용자 판단 조건은 이 결과로 대체하지 않는다.
