# P7.2 — 양쪽 폰 릴리즈 APK 설치

## 기준

- 백로그 schema version: 1.1
- 백로그 SHA-256: `451e4323fbdcb9f4d78193901a3361acdcafd3315f10d90a602674c214b420c4`
- 현재 백로그 상태: `done`
- 작업: P7.2 설치

## 작업 목적

딸 폰과 아빠 폰에 릴리즈 APK를 설치해 정식 설치본이 양쪽에서 실행될 수 있도록 한다.

## 쉬운 설명

개발용 앱이 아니라 배포용 앱을 딸 폰과 아빠 폰에 각각 설치한다. 설치 뒤 기기에서 실제 앱 버전을 확인해 설치가 끝났는지 확인한다.

## 필요한 입력

- P7.2의 기준 백로그 항목과 `done_when`
- P7.1 앱 꾸미기 완료 결과
- 각 폰에 맞는 릴리즈 APK
- 설치 대상 기기와 ADB 설치 결과 또는 기기에서 확인한 설치 정보
- 같은 앱을 업데이트하는 경우 기존 앱과 APK의 패키지·서명 호환 정보

## 결과물

- 딸 폰에 릴리즈 APK 설치 완료
- 아빠 폰에 릴리즈 APK 설치 완료
- 각 설치본의 기기명, 버전·versionCode, 설치 성공 여부를 뒷받침하는 기록
- 패키지와 APK ABI·서명 호환성 확인 기록

## 선행 작업

- **P7.1 앱 꾸미기** — 완료
- **P7 상위 단계의 선행 P6** — 완료

P7.2의 직접 deps는 P7.1이다. P7.3 빌드·업데이트 문서도 완료 상태다.

## 수행 순서

1. 설치 대상인 딸 폰과 아빠 폰을 구분하고, 각 대상용 릴리즈 APK를 준비한다.
2. APK의 패키지명, 버전·versionCode, 기기 호환 ABI, 기존 설치본과의 서명 호환을 확인한다.
3. 각 폰에 설치 또는 데이터 유지 업데이트를 수행하고 설치 성공 결과를 확인한다.
4. 각 폰에서 실제 설치 버전을 확인한다.
5. 양쪽 폰 각각에 릴리즈 APK가 설치됐다는 기기별 근거를 기록한다.

## done_when 확인 방법

백로그 기준 완료 조건은 **양쪽 폰에 릴리즈 APK 설치 완료**다. 다음을 각각 확인한다.

- 딸 폰의 릴리즈 APK 설치 성공과 실제 설치 버전
- 아빠 폰의 릴리즈 APK 설치 성공과 실제 설치 버전
- 두 설치본의 앱 패키지 및 APK 호환성 근거

로그인, 푸시 수신 같은 후속 기능 확인은 설치 사실을 뒷받침하는 추가 근거가 될 수 있으나, 백로그의 설치 완료 조건을 대신하거나 확대하지 않는다.

## 현재 확인 기록

현재 기준 입력의 작업 로그와 연결된 실기기 기록을 확인했다.

- **아빠 폰 SM-S918N**: 릴리즈 `1.63.2/182`, 설치 결과 `Success`; 실제 로그인 후 완료 푸시를 수신하고 알림을 눌러 이동한 기록이 있다.
- **딸 폰 SM-A245N**: 릴리즈 `1.63.5/185` 설치와 실제 버전 확인 기록이 있다. 앱 화면을 열지 않은 주기 동기화 후 위젯 반영도 확인했다.
- **호환성**: 패키지 `com.chaea.timetable`, ARM64 APK 및 기존 서명이 일치한다는 확인이 작업 로그에 기록돼 있다.
- **최신 아빠 APK**: 사용자가 나중에 설치하기로 보류한 상태다. 현재 `done_when`은 양쪽에 릴리즈 APK가 설치됐는지 묻고 있으므로, 양쪽 버전을 같게 하거나 아빠 최신판 업데이트를 별도 조건으로 추가하지 않는다.
- **근거 문서**: [2026-10-12 실기기 확인](../device-verification-2026-10-12.md)의 아빠 설치·로그인·푸시 수신 확인 및 딸 폰 주기 동기화 절.
- **검토 상태**: 이 문서 작성 기준, 작업 상태는 `done`이며 등록 재리뷰 두 역할 정상 종료 후 설치 완료 근거를 기록했다.

## 확인 질문

현재 `done_when`은 양쪽 폰에 릴리즈 APK가 설치됐는지를 기준으로 한다. 양쪽 기기에 동일 버전을 유지해야 하는 별도 요구가 있다면 확인이 필요하다. 제공된 요구사항에는 동일 버전 조건이 없다.
