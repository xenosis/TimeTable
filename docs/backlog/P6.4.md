## 작업 목적
로그인과 parent/child 역할별 화면 분기를 구현한다.

## 쉬운 설명
쉽게 말해, 로그인 · 역할 분기을 백로그 범위에서 수행한다.

## 필요한 입력
기준 백로그 P6.4와 관련 요구사항 문서. 백로그에 없는 값은 임의로 정하지 않는다.

## 결과물
역할별 화면 분기가 정확히 동작함

## 선행 작업
백로그에 기록된 상위 작업과 deps의 완료 결과를 확인한다.

## 수행 순서
1. 범위와 입력을 확인한다.
2. 선행 작업 결과를 준비한다.
3. 백로그 범위만 수행하고 결과를 기록한다.
4. done_when을 확인한다.
5. 개발 완료와 문서화 완료를 구분해 기록한다.

## done_when 확인 방법
역할별 화면 분기가 정확히 동작함를 결과와 대조하고 확인 근거를 남긴다.

## 확인 질문
백로그에 없는 세부 구현값이나 운영 조건이 필요하면 어떤 값으로 결정할지 확인이 필요하다.
