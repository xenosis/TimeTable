## 목적

위젯과 기본 기능이 완성된 릴리즈 APK를 딸 폰에 설치하고, 1주일 이상 실사용하면서 사용 피드백을 수집합니다. 피드백은 이후 개선 작업의 우선순위 결정 기준이 됩니다.

---

## 쉬운 설명

지금까지 만든 시간표·할 일·위젯 기능을 전부 합쳐 딸 폰에 설치하고, 일상 속에서 실제로 써보면서 뭐가 좋고 뭐가 불편한지 기록합니다. 나중에 그 의견을 반영해 더 개선합니다.

---

- 릴리즈 APK (빌드 완료, P5.3·P5.5·P1.8 완료 기준)
- 딸 폰 (기기 할당 완료)
- 위젯 설정 방법 (홈 화면 추가 안내, 선택 사항)

## 수행 순서

### 1단계: 배포 준비

1. 최신 릴리즈 APK 빌드 (`scripts/build-apk.ps1 -Release -Target Device`)
   - 딸 폰 ABI(arm64-v8a) 대상
   - 릴리즈 서명 확인
2. 버전 및 커밋 확인
   - 앱 버전 (예: v1.45.6 / 112)
   - 최근 기능 커밋 (P5.3, P5.5, P1.8 등)
3. 설치 전 딸 폰 상태 확인
   - 기기 정보 (제조사, 모델, API, 글자 크기)
   - 기존 앱 버전 (있으면 데이터 보존 업데이트)

### 2단계: 딸 폰에 설치 및 초기 설정

1. adb를 이용해 APK 설치 (`adb install -r <APK>`)
   - 데이터 보존 업데이트인 경우 기존 데이터 확인
   - 새 설치인 경우 시간표·할 일 초기 데이터 입력 고려
2. 앱 실행 및 권한 확인
   - 알림 권한 (있으면 허용)
   - 위젯 권한
3. 위젯 추가 (선택 사항, 사용자 판단)
   - 홈 화면 장시간 누르기 → 위젯 추가 → TimeTable 위젯 선택
   - 기본 크기: 일정 4x2, 할 일 2x2 (또는 사용자 선호도)

### 3단계: 실사용 기간 (1주일 이상)

**관찰 항목:**
1. 일상 사용 편의성
   - 홈 위젯으로 확인할 수 있는 정보 충분한가?
   - 앱을 열어야 하는 빈도는?
   - 시간표·할 일 입력·수정은 쉬운가?
2. 알림 및 배터리
   - 알림 시간과 내용이 정확한가?
   - 배터리 소비가 많지는 않은가?
   - 백그라운드 작업(갱신·알림)이 제때 실행되는가?
3. 위젯 안정성
   - 위젯이 자정에 제때 갱신되는가?
   - 위젯 탭·체크가 정상 작동하는가?
   - 화면 잠금·절전·재부팅 뒤에도 알림이 나오는가? (P5.4 미확인 항목)
4. 앱 성능·안정성
   - 앱이 느리거나 자주 닫히지는 않는가?
   - 데이터 손실이 없는가?

**P5.4 미확인 항목 확인 (실사용 기간에 수행):**
- 화면 잠금 상태에서도 알림이 울리는가?
- 절전(Doze) 모드에서도 알림이 제때 울리는가?
- 기기 재부팅 뒤에도 알림이 복구되는가?
- 자정 갱신이 정확하게 이루어지는가?

**피드백 기록:**
- 매일 또는 주 2~3회 관찰 내용 기록
- 예상 외 동작 (버그)와 개선 아이디어 구분
- 스크린샷이나 기기 로그 남기기 (필요시)

### 4단계: 피드백 정리 및 완료

1. 1주일 실사용 후 정리
   - 자주 나온 불편한 점 (우선순위 높음)
   - 추가 기능 요청 (우선순위 낮음)
   - 예상 대로 작동한 것 (안정성 검증)
2. P5.4 미확인 항목 확인 결과 기록
   - 잠금·절전·재부팅·자정 갱신 확인 결과
   - P5.4 문서에 반영
   - 실패한 항목은 P5.4를 blocked로 두거나 새 작업으로 등록
3. 백로그에 반영
   - 버그나 개선 항목을 새 task로 등록
   - P5.6 완료 시 피드백 목록 첨부
