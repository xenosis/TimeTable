# P4.6 — 스티커 적립

## 기준 입력

- schema version: `1.1`
- backlog SHA-256: `5a89b701705d2428a3047128c915602ddd76e4b96fff3765a2c11e9558c35eac`
- 기준 상태: `needs_info`
- 담당: `codex`
- 마지막 갱신: `2026-09-18T19:56:14.281Z`

## 목적

오늘 할 일을 모두 완료했을 때만 전체 완료 기록과 D6 보상을 원장에 반영하고, 체크를 취소하면 해당 기록과 이후 연속 보상을 다시 계산한다. 완료 순간에는 축하 애니메이션과 문구를 보여준다.

## 쉬운 설명

할 일 하나를 끝냈다고 바로 보석을 주지는 않는다. 오늘 할 일을 전부 끝내면 축하 문구가 커지며 나타나고, 조건에 맞는 보석이 한 번만 기록된다. 체크를 취소하면 보상도 다시 맞춘다.

## 필요한 입력

- 완료 조건: `완료/취소 시 sticker_ledger가 정확히 갱신되고 애니메이션이 재생됨`
- P4.4 오늘의 할 일 목록과 완료/취소 흐름
- P4.2의 `task_completions`, `sticker_ledger`, `rewards` 구조
- D6: 개별 할 일 보상 없음, 첫 전체 완료 하루에 일반 보석 1개, 첫 7일 연속 전체 완료에 일반 보석 1개, 이후 매 30일 연속 전체 완료마다 큰 보석 1개
- 사용자 실기기 확인: 전체 체크, 마지막 체크 취소, 재진입, 할 일 추가·수정·삭제 후 갱신

## 결과물

- 완료/취소를 SQLite 트랜잭션으로 처리하는 보상 원장 갱신
- 하루 전체 완료·연속 달성에 대한 중복 없는 보상 재계산
- 전체 완료 시 `Animated.Text` 확대 애니메이션과 축하/보석 문구
- 자동 테스트 및 실기기 확인 기록

## 선행 작업

- 직접 의존성: `P4.4`
- `P4.1`(D6 정책), `P4.2`(로컬 DB)는 기준 입력에서 `done`
- P4.4는 구현·자동 검증·재검토 기록은 있으나 실기기 확인 때문에 기준 입력 상태가 `needs_info`

## 수행 순서

1. 오늘 목록의 완료 상태와 P4.2 원장 구조를 확인한다.
2. 개별 완료, 첫 전체 완료, 7일 연속, 30일 주기의 경계를 분리한다.
3. 완료/취소와 보상 재계산을 `BEGIN IMMEDIATE` 트랜잭션 안에서 처리한다.
4. 중복 체크, 재시도, 취소 후 재완료, 할 일 편집 후 재계산을 자동 검증한다.
5. 전체 완료 결과에 따라 축하·보석 문구와 확대 애니메이션을 표시한다.
6. 실기기에서 화면 동작과 재진입 후 상태를 확인하고 결과를 기록한다.

## done_when 확인 방법

자동 검증에서 완료 기록·원장 갱신, 개별 보상 없음, 전체 완료·7일·30일 보상, 중복 방지, 취소 후 재계산을 확인한다. 실기기에서는 전체 체크 시 애니메이션·문구, 취소·재진입 후 상태, 할 일 편집 직후 목록·완료 비율을 확인한다.

## 현재 확인 기록

- `setTaskCompletionWithRewards`, `revokeTodayCompletion`, `editTaskWithRewards`가 완료/취소와 원장 재계산을 SQLite 트랜잭션으로 처리한다.
- `TodayTasksCard`가 `잘했어요!`, 일반 보석, 큰 보석 문구를 표시하고 `Animated.spring`으로 확대한다. 체크 취소 시 축하 상태를 지운다.
- 자동 테스트에는 첫 전체 완료 중복 방지, 취소 후 원장 제거·재계산, 30일 보상 제거, 편집 트랜잭션 검증이 포함된다.
- 기준 입력의 마지막 기록에 따르면 구현·원장 재계산·자동 검사는 완료되었고 `npm run check`도 통과했다. 이 실행에서는 명령을 다시 실행하지 않았다.
- 실기기에서 애니메이션·보상 문구·재진입 후 상태·할 일 편집 직후 갱신은 아직 확인되지 않았다. 따라서 기준 상태는 `needs_info`이며 `done_when` 완료로 판정하지 않는다.

## 실기기 확인 순서

1. 오늘 할 일을 두 개 이상 준비하고 모두 체크한다. 축하 문구의 확대 애니메이션과 첫 전체 완료 보석 문구를 기록한다.
2. 마지막 체크를 해제한다. 문구가 사라지고 화면 재진입 후 완료·보상 기록이 되돌아가는지 확인한다.
3. 할 일을 추가·수정·삭제한다. 오늘 카드의 목록과 완료 비율이 즉시 일치하는지 확인한다.

## 확인 질문

실기기에서 위 세 시나리오가 모두 통과했는가? 특히 애니메이션 표시, 취소·재진입 후 원장 상태, 할 일 변경 직후 목록·진행률 갱신 결과가 필요하다. 요구사항에 없는 추가 보상 규칙이나 UI 동작은 별도 결정 없이는 확정하지 않는다.
