# P2 — 2단계: 시간표 (로컬) (✓ 완료)

## 기준 입력

- 백로그 schema version: `1.1`
- 백로그 SHA-256: 최신 상태 기준
- 기준 항목: `P2`
- 기준 상태: `done`
- 완료 일자: 2026-09-30
- 선행 작업: `P1` (1단계: 프로젝트 기반)

## 목적

딸 폰에서 학교·학원·생활 일정을 포함한 시간표를 로컬 SQLite 기준으로 보고, 교시 시간과 요일별 항목을 관리할 수 있게 하는 2단계 작업이다.

## 쉬운 설명

아이가 오늘 시간표와 주간 시간표를 보고, 아빠가 PIN을 입력한 뒤 교시 시간과 시간표 항목을 추가·수정·삭제할 수 있게 한다. 월요일 시간표를 다른 요일로 복사할 수도 있다. 데이터는 현재 서버가 아니라 딸 폰 안에 저장된다.

## 구현 결과물

### 데이터베이스
- `periods`: 교시별 시작·종료 시각 저장
- `timetable_items`: 요일별 항목 (제목, 시간, 카테고리, 의미 키, 알림 설정)
- `day_exceptions`: 날짜 기반 예외 사항

### UI 화면
- 오늘 화면 (`app/(tabs)/index.tsx`): 현재 교시·다음 일정
- 주간 화면 (`app/(tabs)/timetable.tsx`): 월~금 요일별 시간표
- 편집 화면 (`src/components/TimetableEditor.tsx`): PIN 뒤 항목 CRUD
- 요일 복사 기능

### 저장소 계층
- `src/db/timetableRepository.ts`: 항목 CRUD, 요일 복사, 시간표 조회
- `src/db/types.ts`: 타입 정의

### 테스트
- `__tests__/today-schedule.test.ts`: 현재·다음 일정, 경계, 공백 등 38개 테스트
- `__tests__/database.test.ts`: DB 마이그레이션·저장소 테스트
