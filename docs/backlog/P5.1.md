# P5.1 — 위젯 크기 · 레이아웃 결정

## 기준
- 백로그 schema: 1.1
- 백로그 sha256: d9c91ca147a6b0cc4a40b4b150265d64c4f839734976ab1603bd010864badb37
- 백로그 bytes: 51194
- 개발 상태: in_review
- 문서화 상태: 작성됨

## 작업 목적
오늘 시간표와 오늘 할 일 체크 리스트를 한 화면에 담는 레이아웃을 정한다.

## 쉬운 설명
쉽게 말해, 홈 화면의 4 x 2 위젯에 오늘 시간표와 할 일을 읽기 쉽게 배치하고,
일정·할 일 상태별 표시 방법과 테마 색 전달 규칙을 정한다.

## 필요한 입력
기준 백로그 P5.1와 관련 요구사항 문서. 백로그에 없는 값은 임의로 정하지 않는다.

## 결과물
위젯 레이아웃 시안 확정: [docs/widget-layout.md](../widget-layout.md)

## 선행 작업
백로그에 기록된 상위 작업과 deps의 완료 결과를 확인한다.

## 수행 순서
1. 범위와 입력을 확인한다.
2. 선행 작업 결과를 준비한다.
3. 백로그 범위만 수행하고 결과를 기록한다.
4. done_when을 확인한다.
5. 개발 완료와 문서화 완료를 구분해 기록한다.

## 확정 내용

- 기준 크기는 홈 화면 4 x 2 칸이다.
- 상단에 오늘 정보, 가운데에 현재·다음 일정, 하단에 미완료 할 일을 배치한다.
- 일정 없음, 쉬는 시간, 할 일 없음, 데이터 읽기 실패를 각각 정해진 문구와 동작으로 표시한다.
- `FrameLayout`, `LinearLayout`, `TextView`, `ImageView`, `Button`으로 RemoteViews를 구성하고,
  할 일별 체크 동작과 앱 열기 동작을 구분한다.
- 위젯에 전달하는 테마 색 토큰을 정하고, 글자색과 배경색의 대비비가 4.5:1 미만이면
  기본 햇살 테마의 같은 토큰으로 되돌린다.
- 상세 시안과 상태별 표시표는 `docs/widget-layout.md`에 기록했다.

## 검증 근거

- `npm run check` 통과: 11 suites, 40 tests, Android debug build 성공.
- 이 기록의 개발 상태는 `in_review`이며, 문서 결과물 작성과 개발 작업의 `done` 상태를 혼동하지 않는다.
