# P4.1 — 결정(D6): 보상 규칙

## 기준
- 백로그 schema: 1.1
- 백로그 sha256: 0048bc00ebff559c1173a1bfee3b906d2f8d640e08f8414a78953fc5280dffdb
- 개발 상태: in_review
- 문서화 상태: 작성됨

## 작업 목적
개별 할 일 완료 보상과 연속 달성 보상을 결정한다.

## 쉬운 설명
개별 할 일에는 보상을 주지 않고, 전체 완료 기록을 기준으로 첫 하루·첫 7일·이후 월간 보상을 지급하는 규칙을 정한다.

## 필요한 입력
기준 백로그 항목 P4.1와 관련 요구사항 문서를 확인한다. 기존 보석 시스템의 일반 보석·큰 보석 종류와 잔액·적립·소비 규칙을 기준으로 보상 수치를 정한다.

## 결과물
D6 결정 기록과 보상 정책 설정 위치를 남긴다. 보상 규칙은 다음과 같이 확정한다.

- 개별 할 일 완료 보상: 없음
- 첫 하루 전체 완료: 일반 보석 1개
- 첫 7일 연속 전체 완료: 일반 보석 1개
- 이후 30일 단위 연속 전체 완료: 큰 보석 1개

위 규칙의 보상 값은 `src/rewards/rewardPolicy.ts`의 설정 변수로 관리하고, P4.2 이후의 보상 기능 작업에서 참조한다. 이 문서에서는 코드 파일을 만들거나 수정하지 않는다.

## 선행 작업
백로그에 기록된 상위 작업과 deps 완료 결과를 확인한다. 이 항목에 명시되지 않은 선행 작업은 추정하지 않는다.

## 수행 순서
1. 요구사항과 백로그 범위를 확인한다.
2. 필요한 입력과 선행 작업 결과를 준비한다.
3. 기존 보석 시스템의 일반 보석·큰 보석 종류와 밸런스 자료를 확인한다.
4. 개별 보상 없음, 첫 하루·첫 7일 일반 보석 각 1개, 이후 30일 단위 큰 보석 1개 규칙을 확정한다.
5. 확정 규칙을 `src/rewards/rewardPolicy.ts`의 설정 변수에서 관리하도록 기록한다.
6. done_when을 확인한다.
7. 개발 완료와 문서화 완료를 각각 기록한다.

## done_when 확인 방법
D6 결정 기록에 개별 보상 없음, 첫 하루·첫 7일 일반 보석 각 1개, 이후 30일 단위 큰 보석 1개가 기록되어 있고, 해당 값을 `src/rewards/rewardPolicy.ts`의 설정 변수에서 관리하도록 명시되어 있는지 확인한다. 이 문서화는 확정된 규칙을 기록하는 작업이며 코드 구현 완료를 의미하지 않는다.

## 확인 질문
보상 기능 구현 시 `src/rewards/rewardPolicy.ts`의 설정 변수를 기존 보석 원장과 연결하고, 첫 하루·첫 7일·30일 단위 달성 판정을 검증해야 한다.


## 확정 규칙
- 개별 할 일 완료에는 보상을 주지 않는다.
- 전체 완료 연속 달성의 최초 1일·최초 7일에는 일반 보석을 각 1개 지급한다.
- 그 뒤에는 30일 연속 완료마다 큰 보석 1개를 지급한다.
