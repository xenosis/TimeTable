## 목적

초등학생이 시간표 항목(예: 등교, 귀가)에 설정한 알림이 울릴 때, 폰이 잠긴 상태에서도 화면이 켜지고 알람음이 반복되어 아이가 확실히 인지할 수 있도록 하기 위함.

---

## 쉬운 설명

폰의 알람 앱처럼, 정해진 시간이 오면:
1. 폰 화면이 꺼져 있어도 자동으로 켜짐
2. 알람음이 계속 울림 (최소 10초)
3. 화면 끝에 **끄기** 버튼이 나타나서 누르면 소리·화면이 꺼짐
4. 끄기 후 애플리케이션 알림도 사라짐
5. 같은 시간에 여러 알람이 있으면 마지막 알람으로 통합됨

---

## 필요한 입력

- **P0.5** (PoC 결과): 전체화면 알림이 Android 9+ 환경에서 필요하다는 결정

### 완료 기준

다음 **모든** 조건을 만족해야 함:

1. **전체화면 + 반복음**
   - P3.4의 롤링 예약으로 일정이 발생할 때
   - 폰이 잠긴 상태에서 화면이 켜짐
   - 알람음이 최소 10초 동안 반복됨 (여러 번 울림)

2. **끄기 후 정리**
   - 화면 끝 **끄기** 버튼을 누르면:
     - 알람음 즉시 중단
     - 전체화면 창 닫힘
     - 진행 중 알림(Android 진행 중 notification) 사라짐

3. **연속 알람 통합**
   - 같은 시간에 여러 일정이 있으면 마지막 알람으로 통합됨 확인

4. **기술 기준**
   - Android 9 이상 모든 기기에서 동작
   - 구성 변경(화면 회전, 다크모드 등) 후에도 알람 지속 여부 확인
