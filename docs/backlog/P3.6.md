## 목적

초등학생이 시간표 항목(예: 등교, 귀가)에 설정한 알림이 울릴 때, 폰이 잠긴 상태에서도 화면이 켜지고 알람음이 반복되어 아이가 확실히 인지할 수 있도록 하기 위함.

---

## 쉬운 설명

폰의 알람 앱처럼, 정해진 시간이 오면:
1. 폰 화면이 꺼져 있어도 자동으로 켜짐
2. 알람음이 계속 울림 (최소 10초)
3. 화면 끝에 **끄기** 버튼이 나타나서 누르면 소리·화면이 꺼짐
4. 끄기 후 애플리케이션 알림도 사라짐
5. 같은 시간에 여러 알람이 있으면 마지막 알람으로 통합됨

---

## 검토 반영 (2026-10-01, critical-reviewer)

- **검증 빌드 ≠ 배포 빌드**: 위 실기기 확인은 v1.38.0(OfflineTest) 기준이다. v1.39.0은 `AlarmSoundService.onStartCommand`에 `AlarmActivity.showLatestIfShowing` 호출을 추가했고(첫 알람에서는 `current == null`이라 즉시 반환), PIN 5분 자동 잠금 제거(사용자 요청, `docs/research.md`)도 같은 버전에 들어 있다. 이 변경분은 코드 검토와 `npm run check`만 거쳤고 실기기 재확인은 하지 않았다(사용자 결정).
- **끄기 뒤 전체화면 제거**: 잠금 상태 전체화면의 `끄기` 버튼을 누른 직후 포커스가 `AlarmActivity`에서 `NotificationShade`로 바뀌었고(전체화면 사라짐), 오디오 플레이어 0·알림 0·서비스 0이었다.
- **기기·OS**: 딸 폰 SM-A245N, Android 16. "Android 9+ 기준"은 이 한 대로 확인했고 다른 OS 버전 기기는 검증하지 않았다.
- **예약 경로**: 알람 항목(`P3.4Last`, `P3.6A/B`)은 모두 앱의 관리자 화면에서 소리·화면 알람으로 저장해 만든 실제 롤링 예약이다(debug 주입 경로 아님).
- **미확인 UX**: 알람이 울리는 중 전원 버튼으로 화면을 끄면 `AlarmActivity.onStop()`이 전체화면을 닫고 소리는 서비스에 남는다(코드상). 이 경우 끄기는 잠금 화면 알림에서 눌러야 한다. 실기기로 확인하지 않았다.
- **알려진 잔여 위험(미조치)**: 예약 뒤 전체화면 알림 권한을 끄면 전체화면 없이 배너와 소리만 나온다(`AlarmSoundService`는 울릴 때 권한을 다시 확인하지 않음).
