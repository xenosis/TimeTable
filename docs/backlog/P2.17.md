## 목적

PIN 뒤 시간표 항목 편집 화면에 짧은 메모 입력 칸을 추가한다. 한글 입력 필드이므로 value={field}를 직접 사용하고 ' ' 폴백이나 빈 문자열 폴백은 쓰지 않는다(CLAUDE.md의 한글 IME 규칙). 저장·수정 시 메모가 함께 저장되고 비우면 메모가 지워진다.

## 쉬운 설명

항목을 편집할 때 제목 아래에 메모 입력칸이 나타난다. "과제 테스트" 또는 "엄마가 데리러옴" 같은 메모를 입력해 저장할 수 있다. 메모를 지우면 메모 없이 저장된다.

## CLAUDE.md 한글 입력 규칙 (필수 준수)

**절대 금지**
```typescript
// 나쁜 예 1: 공백 폴백
value={memo || ' '}  // 자모 분리 버그 유발

// 나쁜 예 2: 빈 문자열 폴백 (한글 필드)
value={labelsReady ? memo : ''}  // IME composition 파괴
```

**올바른 방식**
```typescript
// 좋은 예: 직접 사용
value={memo}
onChangeText={(text) => setMemo(text)}
```
