# P8.1 — NEIS 초등학교 시간표 가져오기

## 기준

- 백로그 schema version: `1.1`
- 백로그 SHA-256: `094d32156c4af4a7141a9c993f8f83a9d8472005029e0a3e59900465c35905fc`
- 기준 작업 상태: `in_progress`
- 상위 작업: `P8`

## 목적

교육정보 개방 포털의 NEIS elsTimetable API를 사용하여 학교 시간표를 가져오고, 앱의 과목 있는 요일만 교체한다.

## 쉬운 설명

학교에서 교육청 나이스(NEIS) 시스템에 등록한 공식 시간표를 앱에 가져올 수 있다. 아빠 화면의 관리자 메뉴에서 학교 이름을 검색하고 학년·반을 정해 이번 주와 다음 주 시간표 초안을 미리 본 뒤, 확인하면 과목이 있는 요일의 '학교' 일정만 앱 시간표에 추가된다. 빈 요일·학원·돌봄 등 기존 일정은 유지된다.

## 필요한 입력

- 나이스 인증키(사용자 발급): 저장소 밖 `.env` 파일의 `EXPO_PUBLIC_NEIS_API_KEY`로 저장됨. 키 값은 이 문서에 기록하지 않는다.
- 학교 정보: 교육청 코드(예: J10, 경기도) + 학교 코드(예: 7591095, 빛가온초등학교)
- 학년(1~6)·반(1~N): 같은 날도 반마다 과목 순서가 달라 반 선택이 필요하다.

백로그에 없는 임의 학교나 인증키로 API 호출하지 않는다.

## 결과물 및 구현 범위

- 관리자 화면(앱의 PIN 영역): "학교 시간표 가져오기(나이스)" 메뉴
  - 학교 이름 검색 필드와 선택 리스트
  - 학년 선택 드롭다운(1~6)
  - 반 선택 드롭다운
  - 이번 주 / 다음 주 미리보기 탭 (월~금 각 요일별 과목 나열)
  - "확인" 버튼 — 과목 있는 요일의 '학교' 일정만 현재 시간표에 추가
- 교시 시간: API 응답에는 교시 번호와 과목명만 있고 시각이 없음. 앱의 "교시 시간 설정"에 등록된 시각을 사용하며, 시간 설정이 없으면 "교시 시간을 먼저 설정하세요" 안내 표시
- 데이터 유효성: 빈 데이터·누락된 요일은 그대로 표시 (서버 답변 기준, 자동 보정 없음)
- 일정 교체 규칙:
  - 과목 있는 요일의 "학교" 분류 일정만 새로 생성 또는 기존 일정 내용 교체
  - 다른 분류(학원, 돌봄, 방과후 등)의 기존 일정은 유지
  - 빈 요일(과목이 없는 요일)은 그대로 비움

## 선행 작업

백로그에 기록된 상위 작업과 deps의 완료 결과를 확인한다.

## 수행 순서

1. 범위와 입력을 확인한다.
2. 선행 작업 결과를 준비한다.
3. 백로그 범위만 수행하고 결과를 기록한다.
4. done_when을 확인한다.
5. 개발 완료와 문서화 완료를 구분해 기록한다.

## done_when 확인 방법

다음 근거를 모두 확보하면 P8.1의 done_when을 확인할 수 있다.

- 나이스 인증키로 학교 선택·학년·반 입력 화면이 표시되고, 이번 주/다음 주 미리보기에 실제 과목이 표시된다.
- API 응답을 기반으로 과목 있는 요일의 "학교" 일정이 시간표에 추가되거나 교체된다.
- 교시 시간이 설정돼 있을 때 과목의 시작·종료 시각이 올바르게 표시된다.
- 교시 시간이 설정돼 있지 않을 때 안내 메시지가 표시된다(코드 확인: SchoolTimetableImport의 missingPeriods 안내와 '바꾸기' 버튼 숨김. 실기기에서는 누락 없는 경로만 확인).
- 실제 학교·학년·반의 다음 주 시간표 가져오기가 성공하여 앱 시간표에 표시된다(딸 폰 또는 확인된 기기에서의 검증).

## 신뢰성 조사 (2026-10-09, 사용자 요청)

- 공식 문서([교육정보 개방 포털 초등학교시간표](https://open.neis.go.kr/portal/data/service/selectServicePage.do?page=1&rows=10&infId=OPEN15020190408160341416743&infSeq=1), [공공데이터포털 15122331](https://www.data.go.kr/data/15122331/openapi.do))는 "학년도·학교·학기·학년·학급·교시별 수업내용, 매일 적재"만 밝히고, 실제 수업과 일치하는지는 적혀 있지 않다. 학교가 나이스에 입력한 계획 시간표다.
- 인증키 없이 맛보기 조회(최대 5건)로 서울 초등학교 4곳 2학년을 확인했다.
  - 경복초·경희초: 이번 주(10/6~8) 평일에 국어·수학·즐거운생활 등 실제 과목이 있고, 다음 주(10/12~)도 있다.
  - 경기초: 다음 주는 과목이 있는데 이번 주 평일은 전부 빈칸이었다(학교가 입력을 비웠거나 갱신이 어긋남).
  - 공휴일(10/5 대체공휴일, 10/9 한글날)은 모든 학교가 빈칸이다.
  - **같은 날도 반마다 들어 있는 교시 수가 달라 일부 반이 빠진 경우가 있다.** (빛가온초 2학년 1~7반 10/13 비교 → 반 선택 필수)
  - 시각(몇 시)은 없고 교시 번호와 과목명만 온다. 앱의 교시 시간 설정과 합쳐야 한다.
- 결론: 학교·주마다 빈칸·누락이 있어 그대로 믿고 자동 반영하기는 어렵다. 쓰려면 "가져오기 초안을 보여 주고 아빠가 확인·수정한 뒤 저장"하는 방식이어야 한다. 딸 학교·반의 실제 데이터 상태는 이미 확인했다.

### 딸 학교 확인 (2026-10-09)

- 사용자가 알려 준 학교: 경기도 빛가온초등학교 → 나이스 코드 교육청 `J10`, 학교 `7591095`(경기도 광명시 양달로10번길 8).
- 2학년을 인증키 없이 맛보기로 조회(날짜별 최대 5건): 이번 주 10/6·10/7·10/8과 다음 주 10/12~10/16 모두 과목이 채워져 있다(국어·수학·슬기로운생활·바른생활·즐거운생활·자율·자치활동). 한글날 10/9만 빈칸. 요일별 과목이 이번 주와 다음 주가 같은 순서로 반복돼 정규 시간표로 보인다. 날짜당 35건 안팎이라 2학년은 7개 반 정도.
- 판단: 이 학교는 다른 학교보다 데이터가 잘 채워져 있어 "가져오기 초안" 용도로 쓸 만하다. 다만 실제 수업과 같은지는 딸의 실제 시간표와 한 번 대조해야 한다.
- 확인된 결과: 딸 폰에서 사용자 제공 인증키로 2학년 반별 비교 — 같은 날도 반마다 과목 순서가 다름을 확인. 구현에 반 선택 필수(학년만으로는 부족).
