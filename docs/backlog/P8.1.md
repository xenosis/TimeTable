# P8.1 — NEIS 초등학교 시간표 가져오기

## 기준
- 백로그 schema: 1.1
- 백로그 sha256: 86894def7f03d9e5155fca3e3ecfbd1a32bb7f6fda8dc9cb25145da30a139496
- 백로그 bytes: 51194
- 개발 상태: todo
- 문서화 상태: 작성됨

## 작업 목적
elsTimetable API와 학교 데이터 존재 여부를 확인하고 시간표에 반영한다.

## 쉬운 설명
쉽게 말해, NEIS 초등학교 시간표 가져오기을 백로그 범위에서 수행한다.

## 필요한 입력
기준 백로그 P8.1와 관련 요구사항 문서. 백로그에 없는 값은 임의로 정하지 않는다.

## 결과물
NEIS API로 시간표를 가져와 timetable_items에 반영

## 선행 작업
백로그에 기록된 상위 작업과 deps의 완료 결과를 확인한다.

## 수행 순서
1. 범위와 입력을 확인한다.
2. 선행 작업 결과를 준비한다.
3. 백로그 범위만 수행하고 결과를 기록한다.
4. done_when을 확인한다.
5. 개발 완료와 문서화 완료를 구분해 기록한다.

## done_when 확인 방법
NEIS API로 시간표를 가져와 timetable_items에 반영를 결과와 대조하고 확인 근거를 남긴다.

## 확인 질문
백로그에 없는 세부 구현값이나 운영 조건이 필요하면 어떤 값으로 결정할지 확인이 필요하다.


## 신뢰성 조사 (2026-10-09, 사용자 요청)

- 공식 문서([교육정보 개방 포털 초등학교시간표](https://open.neis.go.kr/portal/data/service/selectServicePage.do?page=1&rows=10&infId=OPEN15020190408160341416743&infSeq=1), [공공데이터포털 15122331](https://www.data.go.kr/data/15122331/openapi.do))는 "학년도·학교·학기·학년·학급·교시별 수업내용, 매일 적재"만 밝히고, 실제 수업과 일치하는지는 적혀 있지 않다. 학교가 나이스에 입력한 계획 시간표다.
- 인증키 없이 맛보기 조회(최대 5건)로 서울 초등학교 4곳 2학년을 확인했다.
  - 경복초·경희초: 이번 주(10/6~8) 평일에 국어·수학·즐거운생활 등 실제 과목이 있고, 다음 주(10/12~)도 있다.
  - 경기초: 다음 주는 과목이 있는데 이번 주 평일은 전부 빈칸이었다(학교가 입력을 비웠거나 갱신이 어긋남).
  - 공휴일(10/5 대체공휴일, 10/9 한글날)은 모든 학교가 빈칸이다.
  - 같은 날도 반마다 들어 있는 교시 수가 달라 일부 반이 빠진 경우가 있다.
  - 시각(몇 시)은 없고 교시 번호와 과목명만 온다. 앱의 교시 시간 설정과 합쳐야 한다.
- 결론: 학교·주마다 빈칸·누락이 있어 그대로 믿고 자동 반영하기는 어렵다. 쓰려면 "가져오기 초안을 보여 주고 아빠가 확인·수정한 뒤 저장"하는 방식이어야 한다. 먼저 딸 학교·반의 실제 데이터 상태를 확인해야 한다.
- 필요한 정보: 딸 학교 이름(교육청)·학년·반. 맛보기 확인은 인증키 없이 가능하고, 실제 기능에는 나이스 인증키가 필요하다.

### 딸 학교 확인 (2026-10-09)

- 사용자가 알려 준 학교: 경기도 빛가온초등학교 → 나이스 코드 교육청 `J10`, 학교 `7591095`(경기도 광명시 양달로10번길 8).
- 2학년을 인증키 없이 맛보기로 조회(날짜별 최대 5건): 이번 주 10/6·10/7·10/8과 다음 주 10/12~10/16 모두 과목이 채워져 있다(국어·수학·슬기로운생활·바른생활·즐거운생활·자율·자치활동). 한글날 10/9만 빈칸. 요일별 과목이 이번 주와 다음 주가 같은 순서로 반복돼 정규 시간표로 보인다. 날짜당 35건 안팎이라 2학년은 7개 반 정도.

- 남은 것: 딸의 반 번호(해당 반만 골라 가져오기), 나이스 인증키(맛보기는 5건 제한이라 6교시·전체 반 조회에 필요).
