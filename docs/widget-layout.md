# 홈 화면 위젯 레이아웃

## 지원 크기와 구조

첫 위젯은 홈 화면의 4 x 4 칸(대략 250 x 220dp)을 기준으로 만든다. 4 x 2(대략 250 x 110dp) 크기에서는 현재 일정 하나만 보이고 할 일과 다음 일정은 숨긴다. 가로를 넓혀도 같은 정보를 유지하고, 4 x 4 이상에서는 현재·다음 일정과 할 일을 최대 두 개 보인다. 위젯은 다음 순서로 배치한다.

1. 상단: `오늘`만 표시한다. 빈 영역을 탭하면 앱의 오늘 화면으로 이동한다.
2. 가운데: 현재 일정 한 줄과 다음 일정 한 줄을 보인다. 일정이 없으면 `지금은 쉬는 시간이야`를 보인다.
3. 하단: 오늘 할 일 중 최대 두 개를 체크 상자와 함께 보이고, 남은 개수를 `+ N개`로 표시한다.

4 x 4 기준으로 상단은 24dp, 현재·다음 일정은 각각 48dp, 할 일은 각각 48dp, 상단 뒤와 일정 뒤의 여백은 각각 2dp로 배치한다. 합계는 220dp다. 일정 두 줄 사이는 구분선만 두며 추가 높이를 쓰지 않는다. 4 x 2 기준은 상단 24dp, 현재 일정 탭 영역 48dp, 위아래 합계 38dp의 여백으로 110dp를 채운다. 시간표는 현재와 다음 일정만 보여 주므로 글자가 작아지지 않는다. 일정 줄에는 과목 이름과 시작 시각을 함께 보이며, 긴 이름은 한 줄 말줄임표로 처리한다. 할 일도 한 줄 말줄임표로 처리한다. 일정과 할 일의 탭 영역은 최소 48dp로 둔다.

## RemoteViews 구성

Kotlin 위젯은 `FrameLayout`, `LinearLayout`, `TextView`, `ImageView`와 `Button`만 사용한다. 목록은 고정된 두 행으로 만들고 남은 할 일이 없으면 해당 행을 숨긴다. 각 할 일 체크 버튼은 해당 할 일의 날짜와 식별자를 가진 개별 `PendingIntent`를 사용한다. 현재·다음 일정과 빈 상태 영역은 앱 열기 `PendingIntent`를 사용한다.

## 테마 반영 범위

위젯에는 현재 선택된 테마의 아래 색만 파일 데이터로 전달한다.

| 용도 | ThemeDefinition 토큰 |
| --- | --- |
| 위젯 바탕 | `colors.background` |
| 본문 카드 | `colors.surface` 또는 `decorations.cardBackground` |
| 기본 글자 | `colors.text` |
| 보조 글자 | `colors.textMuted` |
| 현재 일정 강조 | `colors.primary`와 `colors.onPrimary` |
| 구분선 | `colors.border` 또는 `decorations.cardBorder` |
| 과목 표식 | 해당 `color_key`의 `backgroundColor`와 `textColor` |

`accentShape`, `stickerShape`, 이미지 장식, 앱 배경 장식은 위젯에 넣지 않는다. RemoteViews에서 모양을 안정적으로 표현하기 어렵고, 작은 위젯에서는 정보 읽기를 방해한다. 현재 테마 계약이 검증한 색 쌍만 전달하며, 전달 전 각 글자색과 배경색의 대비비가 4.5:1 이상인지 검사한다. 기준에 맞지 않으면 기본 햇살 테마의 같은 토큰으로 되돌린다.

## 상태별 표시

| 상태 | 시간표 영역 | 할 일 영역 |
| --- | --- | --- |
| 현재 일정 있음 | 현재와 다음 일정 | 미완료 최대 2개 |
| 쉬는 시간 | `지금은 쉬는 시간이야`와 다음 일정 | 미완료 최대 2개 |
| 오늘 일정 없음 | `오늘 일정이 없어요` | 미완료 최대 2개 |
| 할 일 없음 | 기존 시간표 표시 | `오늘 할 일을 다 했어!` |
| 데이터 읽기 실패 | `앱을 열어 새로고침해 줘` | 체크 동작 숨김 |

위젯은 마지막으로 성공한 데이터를 유지하고, 읽기 실패 시 오래된 일정이나 완료 상태를 새 정보인 것처럼 표시하지 않는다.
