## 2026-10-04 추가 요청: 관리자 화면 컴팩트화 (P9)

세부 작업안과 화면 확인 기준: [`admin-compact-plan.md`](admin-compact-plan.md).
아래 항목은 작업 등록 상태이며 기존 편집 기능의 완료 이력을 되돌리지 않는다.

- [ ] **P9.1 관리자 전용 크기·공통 월~일 선택기**: 아이용 공통 토큰과 분리하고 반복 요일 7개를 한 줄로 통일한다.
- [ ] **P9.2 관리자 영역 메뉴·보조 메뉴 접기**: 시간표/할 일/보상/기타 중 선택 영역만 표시하고 교시·요일 복사·보상·PIN·권한 안내·진단에도 관리자 전용 크기를 적용한다. 상단 알림 준비는 모든 권한 허용 시 기본 접힘, 부족하거나 확인에 실패하면 다시 표시한다.
- [ ] **P9.3 할 일 요약 목록·컴팩트 폼**: 반복 요일, 알림, 완료 이력 항목 종료 기능을 작은 관리 UI로 정리한다.
- [ ] **P9.4 시간표 요일별 편집 목록**: 전체 20개 목록 대신 선택 하루만 시간순 표시하고 추가·편집 폼은 모달로 연다.
- [ ] **P9.5 저장 시간표 작은 선택 목록**: 현재 시간표는 한 줄, 이름 변경·삭제·생성·복제는 필요할 때 연다.
- [ ] **P9.6 색·아이콘·시간·알림 폼 정리**: 선택값 요약과 한 줄 선택 목록, 짧은 버튼 문구로 기본 화면 높이를 줄인다.
- [ ] **P9.7 화면 밀도·입력·기능 회귀 확인**: 작은 화면, 확대 글자, 키보드, 주말, 긴 이름과 세트 전환을 확인한다.

P9는 이미 완료된 PIN/시간표/할 일/시간표 세트 편집 위의 개선 작업으로, 서버 연동 완료를 기다리지 않는다.
P9.2에는 기기 검증용 일반 알림·재부팅 복구·잠금 화면 알람 테스트를 기본 화면에서 빼고 PIN 뒤 `기타 → 기기 테스트` 접힌 영역으로 이동하는 작업도 포함한다.

## 2026-10-04 추가 요청: 시간표 시간축·현재 시각 가독성 (P10)

세부 기준: [`timetable-readability-plan.md`](timetable-readability-plan.md). 기존 P2.13/P2.15 완료 이력을 유지하는 후속 작업이다.

- [ ] **P10.1 모든 시각을 왼쪽 시간 칼럼으로 이동**: 일정 칸의 시간 값을 전부 왼쪽 칼럼에서 표시하고, 일정 칸에는 시간 문자열을 남기지 않는다. 요일별 실제 시작·종료 경계도 보존한다.
- [ ] **P10.2 현재 시각 강조**: 선택한 요일의 해당 시간대만 밝게, 나머지는 연하게 표시하고 전환·앱 복귀·시간 경계에 즉시 갱신한다.

요일별 다른 요일은 현재 시각 기준 미리보기로 구별하고, 주간표는 오늘 실제 진행 중 일정만 강조한다.

## 5단계: 홈 화면 위젯 → MVP

앱을 일일이 열지 않아도 바탕화면에서 바로 오늘 시간표 · 할 일을 볼 수 있게 한다. (Doro `CalendarWidget*.kt` 경험 재사용)

- [x] **5-1 위젯 크기 · 레이아웃 결정**: 오늘 시간표(현재/다음 일정) + 오늘 할 일 체크 리스트를 한 화면에. 활성 테마는 대비가 보장된 색·배경만 위젯에 반영한다
- [x] **5-2 데이터 브릿지**: JS → 파일(`filesDir`) → Kotlin `AppWidgetProvider` (Doro `WidgetDataCache` 패턴)
- [x] **5-3 위젯에서 할 일 체크**: RemoteViews 버튼 탭 → 완료 처리 (Doro는 보기 전용이었으므로 새로 설계 필요)
- [x] **5-4 위젯 자동 갱신**: 시간이 지나 다음 교시로 바뀌면 위젯도 갱신 (주기적 갱신 또는 알림 트리거 시 갱신)
- [x] **5-5 탭하면 앱 이동**: 위젯 탭 → 해당 화면으로 바로 이동 (Expo Router 경로 사용)
- [x] **5-6 MVP 배포**: 릴리즈 APK를 딸 폰에 설치 + 위젯 추가하고 **1주일 실사용** 후 피드백 반영

## P18 시간 비례·정규수업 접기·일정 종류 (2026-10-22)

- 한 표 안에서는 분당 높이를 통일한다. 다른 요일의 시작·종료 경계가 끼어도 40분과 30분 칸은 4:3이며, 일정 사이 빈 시간도 비례해 남긴다. 기존 P2 시간축의 행별 최소·최대 높이 및 빈 구간 압축 기준을 대체한다.

- 주 용도인 하교 이후 흐름에 맞춰 정규수업은 기본 접힘으로 두고 요일별 종료 시각을 요약한다. 펼치기/접기 선택은 앱 실행 중 주간·요일별 전환에 유지된다. 학교만 있는 날에는 접힌 학교 일정임을 안내하며, 데이터·알림·학교 자동 가져오기는 변경하지 않는다.
- 종류는 정규수업(school), 방과후(after_school), 학원(academy), 돌봄(care), 생활(life)이다. 편집에서 종류를 먼저 고른 뒤 세부 과목 색조와 아이콘을 고른다. 각각 파랑·초록·보라·주황·회청 계열이며 오늘 화면·시간표·위젯에 같은 색 규칙을 쓴다. 기존 의미 키를 보존해 과목별 색조를 구분한다.
- 기존 학원/돌봄 항목을 제목으로 추정해 자동 재분류하지 않는다. 실제 방과후 수업은 관리자가 종류를 변경한다. 위젯은 정규수업만 제외한다.
- SQLite V14는 기존 모든 일정 값·메모·ID·인덱스·외래키를 보존하고 방과후를 허용한다. 서버에는 새 CHECK 허용값 마이그레이션을 준비한다. 운영 서버 적용과 폰 설치는 별도 요청 범위다. 서버를 적용하고 양쪽 앱을 업데이트한 뒤 방과후 항목을 사용해야 구버전 SQLite와의 동기화 충돌을 피할 수 있다.

## P19 시간표 밀도·과목 색 구분 보완 (2026-10-27)

- 사용자가 컴팩트한 화면을 재요청했다. P18의 최단 시간 경계에 따른 전체 확대를 대체한다. 같은 표의 분당 배율과 빈 시간은 보존하되 가까운 축 글자만 서로 겹치지 않도록 배치하고 실제 시각 위치의 눈금과 연결한다. 라벨 전체를 넣을 공간이 부족한 경우에만 필요한 전체 높이를 확보한다.
- 기본 배율은 주간 0.8dp/분, 요일별 1dp/분으로 낮춘다. 80분 일정은 주간 64dp·요일별 80dp가 기본이며, 요일별 남는 화면을 채우기 위한 확대는 하지 않는다. 시스템 글자 확대에 필요한 축 라벨 공간은 유지한다.
- 시스템 글자 배율을 키운 경우에는 시간 칼럼 폭·라벨 간격·기본 분당 높이도 같은 배율로 확보하고, 칸 안 보조 줄 수를 실제 글자 크기로 계산한다. 일반 글자 크기의 컴팩트 높이와 확대 글자 상태는 별도로 검증한다.
- 종류별 공통 띠 색(정규수업 파랑·방과후 초록·학원 보라 등)을 유지하고, 그 안의 과목 배경은 명도와 색상을 함께 달리한다. 현재 일정은 테두리로 강조하고 다른 일정도 색을 알아볼 수 있도록 탈색을 줄인다. 각 배경에는 대비가 높은 어두운 글자/흰 글자를 선택한다.
- `other` 기본 색은 공백을 제외한 일정 이름 기준의 안정적인 자동 색으로 표시한다. 색을 직접 고르면 과목 키가 우선한다. 유한 팔레트라 자동 색이 겹칠 수 있으며 편집에서 직접 바꿀 수 있다. 저장 데이터나 서버 스키마는 변경하지 않는다. 편집 미리보기·시간표·오늘·위젯에서 같은 규칙을 사용한다.
- 글자 겹침·80분 일정의 높이·40/30분 비례·화면 채우기 확대 방지·기본 자동 색·수동 색·읽기 대비·현재 강조를 회귀 확인하고 버전·전체 검사·등록된 두 에이전트 리뷰로 마무리한다. 폰 설치는 별도 요청 시 진행한다.
- 검사 안정성: 관리자 UI 첫 초기화 테스트의 실행 제한을 5초→30초, 캐시 없이 실행하는 전체 Jest 단계의 제한을 120초→240초로 조정한다. 실제 120초 시간 초과를 기록한 뒤 실행 여유만 늘린 것이며 테스트 항목·assertion·필수 검사 단계는 생략하지 않는다.
- 리뷰 보완: 이동한 시간 글자와 눈금을 같은 수직선에 합치지 않고 순서가 유지되는 사선으로 연결한다. 실제 5~10분 일정처럼 제목 한 줄이 들어가지 않는 칸은 시간 비례를 유지하고 표 아래 작은 보조 목록에서 요일·시각·제목·메모·현재 상태를 읽을 수 있게 한다. 현재 테두리와 선택한 색 테두리도 실제 배경의 대비색을 사용한다.

- 남은 높이 / 표시 시간 범위로 기본 분당 배율을 구한다. 실제 일정 칸만 두 줄 제목의 최소 높이를 보장하며, 다른 요일의 짧은 경계만으로 전체 표를 늘리지 않는다. 최소 높이가 필요한 짧은 칸에서는 엄격한 분당 비례보다 읽기를 우선하되 모든 요일은 같은 시간축을 공유한다. 일반 화면에서 맞추고 작은 가로 화면·글자 확대처럼 최소 높이 총합이 화면을 넘는 경우만 표 안에서 스크롤한다.
- 일정은 표 안에 두고 제목은 최대 두 줄로 읽는다. 이동 경로는 출발지 / 화살표와 목적지로 나눈다. 시간은 왼쪽 칼럼에 유지한다. 시각이 잘못된 데이터의 별도 안내와 현재 일정 대비 테두리는 유지한다.
- `정규수업 펼치기/접기` 버튼은 유지한다. `수업이 끝난 뒤 일정 보기`와 요일별 종료 시각 요약은 제거한다. 접을 때 오전 수업과 점심까지만 숨기고, 오후 수업(5교시 포함)은 표 안에 남긴다. 펼치면 원본 일정 전체를 복원한다. 표시 필터는 저장 데이터를 수정하지 않는다.
- 신규 `2026년 11월` 세트의 `일루스티`를 `일루스터`로 정정한다. 시간·분류·다른 시간표·적용 상태는 그대로 둔다. 앱은 1.65.2 / 191로 올리고 회귀 검사·전체 검사·두 등록 에이전트 검토를 수행한다. 설치는 별도 요청 범위다.
