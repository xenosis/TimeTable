# TimeTable

초등학교 2학년 딸을 위한 안드로이드 시간표 · 할 일 앱입니다.

## 핵심 기능

| # | 기능 | 내용 |
|---|------|------|
| F1 | 시간표 | 요일별 주간 시간표 보기 · 수정 (최우선) |
| F2 | 오늘의 할 일 | 숙제 등 매일 할 일 체크 + 칭찬 스티커 |
| F3 | 시간 알림 | 항목별로 일반 알림 / 알람(전체화면 + 계속 울림) 선택 |
| F4 | 아빠 관리자 | 아빠 폰에서 원격 수정 + 딸 폰에서 PIN 입력 후 수정 |

## 사용 환경

- 딸: 일반 안드로이드폰 + 구글 패밀리링크
- 아빠: 안드로이드폰
- 배포: APK 직접 설치

## 현재 상태

기획 단계입니다. 아직 코드는 없습니다.
